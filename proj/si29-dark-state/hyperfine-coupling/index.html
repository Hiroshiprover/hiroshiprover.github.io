超精细耦合及均匀耦合近似

1. 电子与核自旋的超精细相互作用​

1.1 超精细耦合​

现在考虑电子与周围的 29Si^{29}\mathrm{Si}29Si 核自旋之间的相互作用。

对于接触超精细相互作用，电子与第 kkk 个核自旋之间的耦合强度与电子在该原子核位置的概率密度有关。

假设核位于 Rk\mathbf R_kRk​，那么相应的耦合系数满足

Ak∝∣Ψ(Rk)∣2.\boxed{ A_k\propto|\Psi(\mathbf R_k)|^2. }Ak​∝∣Ψ(Rk​)∣2.​

其中 Ψ(r)\Psi(\mathbf r)Ψ(r) 是电子的完整空间波函数。

将前面的包络函数近似代入，

Ψ(r)≈F(r)ψck0(r),\Psi(\mathbf r) \approx F(\mathbf r)\psi_{c\mathbf k_0}(\mathbf r),Ψ(r)≈F(r)ψck0​​(r),

就有

Ak∝∣F(Rk)∣2∣ψck0(Rk)∣2.A_k\propto |F(\mathbf R_k)|^2 |\psi_{c\mathbf k_0}(\mathbf R_k)|^2.Ak​∝∣F(Rk​)∣2∣ψck0​​(Rk​)∣2.

这里 Bloch 函数描述晶胞内部的电子分布，而包络函数决定耦合强度在整个量子点内的空间变化。

于是，我们可以把单个电子与许多核自旋之间的相互作用写成

Hhf=∑k=1NAk s⋅Ik,\boxed{ H_{\mathrm{hf}} =\sum_{k=1}^{N}A_k\,\mathbf s\cdot\mathbf I_k, }Hhf​=k=1∑N​Ak​s⋅Ik​,​

其中 s\mathbf ss 是电子自旋算符，Ik\mathbf I_kIk​ 是第 kkk 个核的自旋算符，NNN 是参与耦合的核自旋数。这里采用无量纲角动量算符，将相应的 ℏ\hbarℏ 因子包含在耦合系数中。

这个哈密顿量称为中心自旋模型（central spin model）的一种形式：一个电子自旋与大量周围的核自旋发生耦合。

由于电子的波函数是弥散的，它能够同时与许多核自旋相互作用，但每个核对应的耦合系数通常都很小。

至此，我们终于看到了前面研究包络函数的用途：电子的空间波函数决定了它与不同位置的核自旋之间的耦合强度。

1.2 高斯包络函数​

我们在前面的笔记中讨论过，如果将量子点内的束缚势近似为二维谐振子势，那么电子基态的包络函数就是高斯函数：

F(x,y)=1πℓexp⁡[−(x−x0)2+(y−y0)22ℓ2],F(x,y)=\frac{1}{\sqrt{\pi}\ell} \exp\left[ -\frac{(x-x_0)^2+(y-y_0)^2}{2\ell^2} \right],F(x,y)=π​ℓ1​exp[−2ℓ2(x−x0​)2+(y−y0​)2​],

其中 (x0,y0)(x_0,y_0)(x0​,y0​) 是量子点中心，ℓ\ellℓ 决定电子波函数的空间宽度。

因此，电子在平面内的概率密度为

∣F(x,y)∣2=1πℓ2exp⁡[−(x−x0)2+(y−y0)2ℓ2].|F(x,y)|^2=\frac{1}{\pi\ell^2} \exp\left[ -\frac{(x-x_0)^2+(y-y_0)^2}{\ell^2} \right].∣F(x,y)∣2=πℓ21​exp[−ℓ2(x−x0​)2+(y−y0​)2​].

将电子在垂直方向的分布以及 Bloch 函数在核位置的贡献吸收到有效耦合参数中，并假设这些核处于相同的垂直束缚环境，我们可以考虑如下模型：

Ak=A0exp⁡[−(xk−x0)2+(yk−y0)2ℓ2].\boxed{ A_k=A_0\exp\left[ -\frac{(x_k-x_0)^2+(y_k-y_0)^2}{\ell^2} \right]. }Ak​=A0​exp[−ℓ2(xk​−x0​)2+(yk​−y0​)2​].​

其中 (xk,yk)(x_k,y_k)(xk​,yk​) 是第 kkk 个核的平面坐标，A0A_0A0​ 表示量子点中心附近的耦合系数。

这样，距离量子点中心较近的核具有较大的耦合系数，而远离中心的核与电子的耦合逐渐减弱。这比假设电子在量子点内均匀分布更符合我们之前建立的轨道模型。

实际上，这种模型在数值计算中并不难实现：只要知道核的位置，就能够计算相应的 AkA_kAk​。真正的困难在于得到这些系数之后，如何求解电子与大量核自旋组成的量子系统。

因为每个核的耦合系数都不相同，我们仍然需要处理

Hhf=∑k=1NAk s⋅Ik.H_{\mathrm{hf}} =\sum_{k=1}^{N}A_k\,\mathbf s\cdot\mathbf I_k.Hhf​=k=1∑N​Ak​s⋅Ik​.

当 NNN 很大时，完整多体 Hilbert 空间的维数会随着核数指数增长。这意味着即使哈密顿量本身并不复杂，直接求解它的量子动力学仍然可能非常困难。

我们因此考虑进一步的简化。

1.3 均匀耦合近似​

假设电子与同一量子点内所有参与耦合的核自旋具有相同的耦合系数。

设量子点内共有 NNN 个核自旋，令

Ak=AN,k=1,…,N,A_k=\frac{\mathcal A}{N}, \qquad k=1,\ldots,N,Ak​=NA​,k=1,…,N,

其中 A\mathcal AA 是有效超精细耦合参数，按照这里的定义，它等于所有核的耦合系数之和。

这种模型称为 box model。它相当于将电子在核自旋分布区域内的概率密度近似为均匀分布1。

于是

Hhf=AN∑k=1Ns⋅Ik=ANs⋅∑k=1NIk.\begin{aligned} H_{\mathrm{hf}} &=\frac{\mathcal A}{N} \sum_{k=1}^{N}\mathbf s\cdot\mathbf I_k\\ &=\frac{\mathcal A}{N} \mathbf s\cdot\sum_{k=1}^{N}\mathbf I_k. \end{aligned}Hhf​​=NA​k=1∑N​s⋅Ik​=NA​s⋅k=1∑N​Ik​.​

定义核自旋的总角动量算符

J=∑k=1NIk,\boxed{ \mathbf J=\sum_{k=1}^{N}\mathbf I_k, }J=k=1∑N​Ik​,​

便得到

Hhf=ANs⋅J.\boxed{ H_{\mathrm{hf}} =\frac{\mathcal A}{N}\mathbf s\cdot\mathbf J. }Hhf​=NA​s⋅J.​

这样，电子与所有核自旋的相互作用就可以通过一个集体角动量算符 J\mathbf JJ 表示。

对于双量子点，我们可以分别定义

Ji=∑k=1NiIik,i=1,2.\mathbf J_i=\sum_{k=1}^{N_i}\mathbf I_{ik}, \qquad i=1,2.Ji​=k=1∑Ni​​Iik​,i=1,2.

在两个有效电子分别局域于两个量子点的情况下，如果每个电子主要与自己所在量子点中的核自旋耦合，就得到

Hhf=∑i=12AiNisi⋅Ji.\boxed{ H_{\mathrm{hf}} =\sum_{i=1}^{2} \frac{\mathcal A_i}{N_i} \mathbf s_i\cdot\mathbf J_i. }Hhf​=i=1∑2​Ni​Ai​​si​⋅Ji​.​

其中 Ai\mathcal A_iAi​ 和 NiN_iNi​ 分别是第 iii 个量子点的有效超精细耦合参数和参与耦合的核自旋数。

这就是我们之后要使用的电子—核自旋耦合模型。

1.4 均匀耦合的意义​

现在我们已经有了两个模型：高斯包络函数对应的非均匀耦合模型，以及 box model 对应的均匀耦合模型。

从哈密顿量的形式上看，二者的区别只是能否把 AkA_kAk​ 从求和号中提出来。但这个区别对之后的量子计算相当重要。

我们先考虑均匀耦合。因为 J\mathbf JJ 是多个角动量算符的和，所以它仍然满足角动量的对易关系：

[Jα,Jβ]=i∑γϵαβγJγ.[J^\alpha,J^\beta] =i\sum_\gamma \epsilon_{\alpha\beta\gamma}J^\gamma.[Jα,Jβ]=iγ∑​ϵαβγ​Jγ.

因此，J\mathbf JJ 可以按照通常的角动量理论处理，其平方算符

J2=(Jx)2+(Jy)2+(Jz)2\mathbf J^2=(J^x)^2+(J^y)^2+(J^z)^2J2=(Jx)2+(Jy)2+(Jz)2

与所有 JαJ^\alphaJα 对易。

特别地，对于我们得到的超精细哈密顿量，

[Hhf,J2]=0.[H_{\mathrm{hf}},\mathbf J^2]=0.[Hhf​,J2]=0.

这意味着，如果只考虑均匀超精细耦合，核自旋系统的总角动量量子数 jjj 是守恒的。

我们可以选择 J2\mathbf J^2J2 和 JzJ^zJz 的共同本征态 ∣j,m⟩|j,m\rangle∣j,m⟩，并利用

J2∣j,m⟩=j(j+1)∣j,m⟩,Jz∣j,m⟩=m∣j,m⟩\begin{aligned} \mathbf J^2|j,m\rangle&=j(j+1)|j,m\rangle,\\ J^z|j,m\rangle&=m|j,m\rangle \end{aligned}J2∣j,m⟩Jz∣j,m⟩​=j(j+1)∣j,m⟩,=m∣j,m⟩​

来表示核自旋的量子态。这里仍然采用无量纲角动量。

这就为之后的计算提供了一个可能的简化：我们可以按照不同的总角动量量子数 jjj，将 Hilbert 空间分成多个互不耦合的子空间，分别求解。

再来看非均匀耦合模型。我们虽然仍然可以定义一个加权核自旋算符

B=∑kAkIk,\mathbf B=\sum_k A_k\mathbf I_k,B=k∑​Ak​Ik​,

使得

Hhf=s⋅B,H_{\mathrm{hf}}=\mathbf s\cdot\mathbf B,Hhf​=s⋅B,

但 B\mathbf BB 一般不再满足普通的角动量代数。

例如

[Bx,By]=i∑kAk2Ikz.[B^x,B^y] =i\sum_k A_k^2I_k^z.[Bx,By]=ik∑​Ak2​Ikz​.

这里右边出现的是 Ak2A_k^2Ak2​，因此一般无法将其写成某个常数乘以 BzB^zBz。相应地，原来的总角动量平方 J2\mathbf J^2J2 通常也不再与非均匀耦合哈密顿量对易。

所以采用 box model 之后，我们获得的并不只是一个形式更简单的哈密顿量，还获得了额外的守恒量。这也是均匀耦合模型适合用来研究核自旋量子动力学的原因。

当然，实际能将计算规模降低多少，还取决于核自旋的初态以及系统中是否包含其他相互作用。这个问题留到我们真正进行多体计算时再考虑。

1.5 有效核自旋数​

我们还可以用一个简单的量来比较不同的耦合分布。

对于一组同号的超精细耦合系数 AkA_kAk​，定义有效核自旋数（effective number of nuclei）

Neff=(∑kAk)2∑kAk2.\boxed{ N_{\mathrm{eff}} =\frac{\left(\sum_k A_k\right)^2} {\sum_k A_k^2}. }Neff​=∑k​Ak2​(∑k​Ak​)2​.​

对于均匀耦合模型，Ak=A/NA_k=\mathcal A/NAk​=A/N，立即得到

Neff=N2(A/N)2N(A/N)2=N.N_{\mathrm{eff}} =\frac{N^2(\mathcal A/N)^2} {N(\mathcal A/N)^2} =N.Neff​=N(A/N)2N2(A/N)2​=N.

但对于非均匀耦合模型，不同核的贡献并不相同。利用 Cauchy–Schwarz 不等式，

(∑kAk)2≤N∑kAk2,\left(\sum_k A_k\right)^2 \leq N\sum_k A_k^2,(k∑​Ak​)2≤Nk∑​Ak2​,

便得到

Neff≤N.N_{\mathrm{eff}}\leq N.Neff​≤N.

当全部 AkA_kAk​ 相等时取等号。

因此，高斯包络函数对应的非均匀耦合模型通常具有更小的有效核自旋数。可以理解为虽然电子波函数覆盖了许多原子核，但其中只有部分核对总耦合有比较大的贡献。

这个量还有一个实际用途。例如，在各核自旋相互独立、且均处于无极化状态时，超精细场的涨落强度与 ∑kAk2\sum_k A_k^2∑k​Ak2​ 有关。因此，NeffN_{\mathrm{eff}}Neff​ 可以用来衡量不同耦合分布所产生的核场涨落。

不过它只是一个描述耦合分布的参数，并不能完全决定核自旋的量子动力学。

对于我们的研究，可以先采用 box model，建立核自旋量子化后的动力学模型。等这个模型能够正常工作之后，再考虑引入高斯包络函数对应的非均匀耦合，研究耦合分布对结果的影响。

2. 从单电子到多电子体系​

前面我们一直在讨论单电子的轨道波函数，但实际的双量子点器件可以包含多个电子。

以我们所研究的实验为例，器件工作在 (4,0)(4,0)(4,0) 与 (3,1)(3,1)(3,1) 两种电荷配置附近。这里的两个数字分别表示两个量子点内的电子数，整个体系共有四个电子1。

对于多个电子，哈密顿量中除了单电子的轨道能量，还要加入电子之间的库仑相互作用。例如，暂时忽略自旋相关项，四电子哈密顿量可以写成

He=∑a=14heff(ra)+∑a<bVC(ra−rb),\boxed{ H_{\mathrm e} =\sum_{a=1}^{4}h_{\mathrm{eff}}(\mathbf r_a) +\sum_{a<b}V_C(\mathbf r_a-\mathbf r_b), }He​=a=1∑4​heff​(ra​)+a<b∑​VC​(ra​−rb​),​

其中 heffh_{\mathrm{eff}}heff​ 是前面建立的单电子有效质量哈密顿量，VCV_CVC​ 表示电子之间的有效库仑相互作用。

由于电子是费米子，多电子波函数还必须满足交换反对称性。因此，即使我们已经知道每个量子点中的单电子轨道，也还需要研究多个电子如何占据这些轨道，以及电子之间的相互作用如何改变系统的能级。

在蔡老师的实验中，有两个电子填充第一个量子点的最低能谷能级，形成一个自旋单重态。研究低能自旋动力学时，可以将这个电子对视为已经填满的低能轨道，只显式保留另外两个有效电子的自旋自由度。

这样，原来的四电子体系就可以用一个有效双电子模型来描述。

接下来我们需要研究这两个有效电子的自旋态，以及它们之间的交换相互作用。对于两个自旋 1/21/21/2 的电子，我们已经知道它们的自旋空间可以分解为一个单重态和三个三重态：

12⊗12=0⊕1.\frac12\otimes\frac12=0\oplus1.21​⊗21​=0⊕1.

但这些态具有怎样的能量、如何受到双量子点电荷配置的影响，还需要从电子—电子相互作用出发进行分析。

等我们得到有效双电子哈密顿量后，再加入前面构造的超精细相互作用，就能够建立研究电子—核自旋动力学所需要的基本模型。
