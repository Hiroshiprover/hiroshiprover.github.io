# 只用静态数据的参数实验

拖动质量参数，观察上下能带之间的能隙。当 $m=1$ 时，能隙在 $k=\pm\pi$ 处闭合。

## 这张图如何工作

Python 预先计算 $m\in[0,2]$ 的 41 组能谱。滑块按步长 0.05 选择已保存的数据，浏览器负责绘制；这里没有插值或在线 Python 计算。

这是一个有限参数空间的实验。遇到高维参数或很大的数据集，应先评估文件大小和精度，再决定是否扩大预计算范围。
