# Website

[Web](https://hiroshiprover.github.io)

This repository contains the source code of my personal website, built with [Docusaurus](https://docusaurus.io/) and hosted on GitHub Pages.

## About

This website serves as a collection of my notes on differential geometry, fibre bundles, quantum mechanics, condensed matter physics, and related mathematical topics.

Most articles are written for physics students who wish to understand the underlying geometric and mathematical structures in a more intuitive way.

## Installation

Use Node.js >=20.18.1 and install the locked dependencies:

```bash
npm ci
```

## Local Development

```bash
npm run start
```

This command starts a local development server and opens up a browser window. Most changes will be reflected automatically without restarting the server.

## Build

Generate the static website:

```bash
npm run build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.

## Search and scientific examples

Search is available at `/search/`. Its per-language Pagefind indexes are generated by the production build; `npm start` does not create or refresh them. Preview search with a production build in an isolated directory and `npm run serve -- --host 127.0.0.1 --port 4178 --no-open`, choosing an unused port.

The `/science/` pages render saved Python/Notebook results, a parameter slider and TikZ SVGs. The site build validates saved outputs without running Python or TeX. Generator setup, local tools and regeneration commands are documented in [tools/science/README.md](tools/science/README.md). These workflows are self-contained in this project and do not require old Codex prototype workspaces.

## Math commands

Custom KaTeX macros are defined in `src/config/katex.ts` and shared by Chinese
and English docs, project notes, blog posts, and MDX pages. Use them inside `$...$` or multiline
`$$` blocks. KaTeX styles and fonts are bundled locally with the site.

| Command | Meaning |
| --- | --- |
| `\bra{a}`, `\ket{b}` | Bra and ket |
| `\braket{a}`, `\braket{a}{b}` | Inner product ⟨a∣a⟩ or ⟨a∣b⟩ |
| `\ketbra{a}`, `\ketbra{a}{b}` | Outer product ∣a⟩⟨a∣ or ∣a⟩⟨b∣ |
| `\abs{x}`, `\norm{v}` | Absolute value and norm |
| `\C`, `\F`, `\R`, `\N`, `\Z`, `\Q` | Blackboard bold C, F, R, N, Z, Q |

The delimiters resize to fit their contents. For `\braket` and `\ketbra`,
omitting the second braced argument repeats the first; for example,
`\ketbra{\psi}` equals `\ketbra{\psi}{\psi}`. A following braced group
is treated as the second argument, even after whitespace. To multiply the
single-argument result by a separate group, write `\ketbra{a} \cdot {b}`.
For an operator matrix element, write `\bra{\psi} A \ket{\phi}`.
`\bra`, `\ket`, `\abs`, and `\norm` each take one argument; the
blackboard-bold commands take none.

## Deployment

The website is hosted using GitHub Pages. 

Before deployment, always save source changes to the main branch:

```bash
git add .
git commit -m "..."
git push origin main
```

where "..." can be replaced by any text you prefer. Then deploy the website:

```bash
npm run deploy
```

This command automatically:

1. Builds the website.
2. Generates static files in build/.
3. Pushes the generated site to the gh-pages branch.

GitHub Pages serves the website directly from the gh-pages branch.


## Research projects

`proj/` is an independent Docs plugin instance (`id: proj`) configured in
`docusaurus.config.ts`. Its sidebar is generated by `sidebars.proj.ts` and does
not affect the Contents sidebar. The navbar opens `/proj/`.

To add a project, create `proj/<project>/index.mdx` and add further MDX notes in
that directory. Use `sidebar_position` for ordering and `_category_.json` for
the project label and index link. Add the project to `proj/index.mdx` as well.
Existing notes use explicit slugs so filenames can change without changing URLs.
Math plugins and KaTeX macros are shared with Contents and Blog.

Future English translations belong in
`i18n/en/docusaurus-plugin-content-docs-proj/current/`; until then, Docusaurus
uses the Chinese source for Proj under `/en/proj/` too.

## Note

If Docusaurus shows stale content, clear the cache:

```bash
npm run clear
```

Then rebuild or redeploy:

```bash
npm run build
```
or:
```bash
npm run deploy
```
