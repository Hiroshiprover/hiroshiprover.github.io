Chapter 3: Fields: Tangent Bundle and Sections

3.1 Tangent Bundle​

We use the tangent bundle to motivate the definition of a fibre bundle. The tangent bundle itself is motivated by the need for vector fields.

We have all encountered vector fields in Rn\R^nRn — the electric field of a point charge, the magnetic field of a solenoid, and so on. Intuitively, a vector field assigns a vector to every point in space. Naturally, we can imagine the same definition on a manifold: placing one tangent vector at each point of the manifold yields a tangent vector field.

note

Electric and magnetic fields actually appear as the curvature of the 4‑potential; treating them as genuine vectors is slightly imprecise. The 4‑potential is an even more subtle object, which we will discuss later.

To define a tangent vector field on a manifold rigorously, we must first answer the question: how do we describe such an assignment of vectors? You might think: in a coordinate system (O,ψ)(O,\psi)(O,ψ), a vector has components v=vμ∂μv=v^\mu\partial_\muv=vμ∂μ​. But such a description is local and coordinate‑dependent. We would like a global, canonical description. To this end, we introduce the concept of the tangent bundle.

Tangent Bundle

Recall: at every point ppp of a manifold MMM there is an associated tangent space TpMT_pMTp​M. The tangent bundle is the space obtained by "collecting together" the tangent spaces of all points:

TM:=⋃p∈M{p}×TpM.TM := \bigcup_{p\in M} \{p\} \times T_pM.TM:=p∈M⋃​{p}×Tp​M.
Tangent bundle as a manifold

If the manifold MMM has dimension nnn, then the tangent bundle has dimension 2n2n2n. Let (Oα,ψα)(O_\alpha,\psi_\alpha)(Oα​,ψα​) be a local coordinate system on MMM. This chart induces a coordinate system (Uα,ϕα)(U_\alpha,\phi_\alpha)(Uα​,ϕα​) on TMTMTM, where UαU_\alphaUα​ is defined by

Uα={(p,v)∈TM:p∈Oα, v∈TpM},U_\alpha = \{(p,v)\in TM : p\in O_\alpha,\ v\in T_pM\},Uα​={(p,v)∈TM:p∈Oα​, v∈Tp​M},

and the homeomorphism ϕα\phi_\alphaϕα​ is defined by

ϕα:Uα→R2n,ϕα(p,v)=(xμ,vμ),\phi_\alpha: U_\alpha \to \R^{2n}, \qquad \phi_\alpha(p,v) = (x^\mu, v^\mu),ϕα​:Uα​→R2n,ϕα​(p,v)=(xμ,vμ),

where xμx^\muxμ are the coordinates of the point ppp given by the chart on MMM, i.e. ψα(p)=(x1,…,xn)\psi_\alpha(p)=(x^1,\dots,x^n)ψα​(p)=(x1,…,xn), and vμv^\muvμ are the components of the vector vvv with respect to the coordinate basis, i.e. v=vμ∂μv=v^\mu\partial_\muv=vμ∂μ​.

note

Although we have given a map from the tangent bundle to R2n\R^{2n}R2n, we have not yet specified a topology on TMTMTM, which means the UαU_\alphaUα​ defined above are not yet fully justified. The remedy is straightforward: we declare a subset V⊂TMV\subset TMV⊂TM to be open if and only if for every α\alphaα, the set ϕα(V∩π−1(Oα))\phi_\alpha(V\cap\pi^{-1}(O_\alpha))ϕα​(V∩π−1(Oα​)) is open in R2n\R^{2n}R2n, where π\piπ is the natural projection of the Cartesian product used in constructing the tangent bundle:

π:TM→M,π(p,v)=p.\pi: TM \to M, \qquad \pi(p,v)=p.π:TM→M,π(p,v)=p.

This is precisely the bundle projection of the tangent bundle. We will explain this in greater detail when we discuss fibre bundles later.

The motivation behind this seemingly messy definition is simple: it is designed to make ϕα\phi_\alphaϕα​ a homeomorphism. If we simply take V=π−1(Oα)V=\pi^{-1}(O_\alpha)V=π−1(Oα​), we see that VVV is exactly UαU_\alphaUα​. For ϕα\phi_\alphaϕα​ to be a homeomorphism, at the very least it must map open sets to open sets; hence we declare UαU_\alphaUα​ to be open. For a more general VVV, one simply decomposes it into a union of pieces coming from different charts, and requires each piece to be a homeomorphism.

warning

The construction above only works for the tangent bundle and does not extend naturally to an arbitrary fibre bundle (vector bundle)! The reason is that the tangent bundle inherits a natural local trivialisation from the base manifold — essentially the topology we just described, or equivalently, the local coordinate systems chosen on the base manifold.

We will discuss local trivialisation in greater detail later.

It is easy to see that if MMM is a smooth manifold, then TMTMTM is also a smooth manifold. Its coordinate transformations are

(xμ,vμ)↦(yμ, ∂yμ∂xν vν).(x^\mu, v^\mu) \mapsto \left(y^\mu,\ \frac{\partial y^\mu}{\partial x^\nu}\,v^\nu\right).(xμ,vμ)↦(yμ, ∂xν∂yμ​vν).

The smoothness of yμ=yμ(xμ)y^\mu=y^\mu(x^\mu)yμ=yμ(xμ) is guaranteed by the smoothness of MMM, and ∂yμ∂xνvν\frac{\partial y^\mu}{\partial x^\nu}v^\nu∂xν∂yμ​vν is a linear map, hence also smooth. The smoothness of the Jacobian matrix is likewise guaranteed by MMM.

Tangent Vector Fields​

Now that we have introduced the tangent bundle, we can treat a point on the manifold and a tangent vector as parts of a single object. This immediately suggests how to define a vector field: a vector field is simply a set of points {(p,v)∈TM}\{(p,v)\in TM\}{(p,v)∈TM} where ppp ranges over the entire manifold MMM, and vvv takes exactly one value at each ppp. Of course, just as with curves on a manifold, we prefer to define a vector field as a map. Concretely, we define a section:

Section

A continuous map σ:M→TM\sigma: M\to TMσ:M→TM satisfying

π∘σ=idM\pi\circ\sigma = \mathrm{id}_Mπ∘σ=idM​

is called a section of the tangent bundle, or a vector field on the manifold MMM. Here π\piπ is the bundle projection (the natural projection of the Cartesian product used in constructing the tangent bundle), and idM\mathrm{id}_MidM​ is the identity map on MMM.

note

This condition merely rules out pathological behaviour, such as mapping a tangent vector vpv_pvp​ at p∈Mp\in Mp∈M to a different point q≠pq\neq pq=p. While such a map is formally allowed, it is meaningless.

You will find that defining a vector field as a map is very convenient. After all, it is simply a map from an nnn-dimensional manifold to a 2n2n2n-dimensional manifold, and we have already defined smoothness of maps between manifolds. We denote the set of all smooth vector fields by Γ(TM)\Gamma(TM)Γ(TM).

note

Lest you get lost in the mathematics: up to this point, all we have done is to make rigorous the statement "a vector field assigns a vector to every point in space".

Operations on Tangent Vector Fields​

Now that we have rigorously defined tangent vector fields, let us consider some of their operational properties. Recall that we originally defined a tangent vector as a derivation, so a vector field should have a natural action on scalar fields:

Action of a vector field on a scalar field

Let X∈Γ(TM)X\in\Gamma(TM)X∈Γ(TM). At a point p∈Mp\in Mp∈M, we have proj2∘X(p)=v∈TpM\mathrm{proj}_2\circ X(p)=v\in T_pMproj2​∘X(p)=v∈Tp​M. Since vvv is a derivation, it acts on any scalar field: v(f)∈Rv(f)\in\Rv(f)∈R. We therefore define the action of the vector field XXX on a scalar field by

X′:FM→FM,[X′(f)](p)=[proj2∘X(p)](f).X': \mathscr{F}_M \to \mathscr{F}_M, \qquad [X'(f)](p) = [\mathrm{proj}_2\circ X(p)](f).X′:FM​→FM​,[X′(f)](p)=[proj2​∘X(p)](f).

When no confusion arises, we denote X′X'X′ simply by XXX. In practice, there is little opportunity for confusion.

note

Without introducing the tangent bundle, this is precisely the rigorous definition of a tangent vector field: a tangent vector field is a map FM→FM\mathscr{F}_M\to\mathscr{F}_MFM​→FM​, whose smoothness is determined by the smoothness of the resulting scalar fields.

On the tangent space we defined linear combinations of tangent vectors: αv+βw\alpha v+\beta wαv+βw for v,w∈TpMv,w\in T_pMv,w∈Tp​M and α,β∈R\alpha,\beta\in\Rα,β∈R, yielding another vector in the same tangent space. Can we define similar operations for entire vector fields? The answer is yes, and we can even allow the coefficients to vary from point to point — i.e. be scalar fields.

C∞(M)C^\infty(M)C∞(M)-linearity of vector fields

Define addition and scalar multiplication of vector fields by:

  1. Addition: (X+Y)(p):=X(p)+Y(p)(X+Y)(p) := X(p) + Y(p)(X+Y)(p):=X(p)+Y(p),
  2. Scalar multiplication: (fX)(p):=f(p) X(p)(fX)(p) := f(p)\,X(p)(fX)(p):=f(p)X(p),

where f∈FMf\in\mathscr{F}_Mf∈FM​ is a scalar field and X,Y∈Γ(TM)X,Y\in\Gamma(TM)X,Y∈Γ(TM) are vector fields.

note

The above addition and scalar multiplication should be understood under the projection:

proj2∘(X+Y)(p)=proj2∘X(p)+proj2∘Y(p),\mathrm{proj}_2\circ(X+Y)(p) = \mathrm{proj}_2\circ X(p) + \mathrm{proj}_2\circ Y(p),proj2​∘(X+Y)(p)=proj2​∘X(p)+proj2​∘Y(p),

and

proj2∘(fX)(p)=f(p) proj2∘X(p),\mathrm{proj}_2\circ(fX)(p) = f(p)\,\mathrm{proj}_2\circ X(p),proj2​∘(fX)(p)=f(p)proj2​∘X(p),

because X(p)X(p)X(p), as a point in the tangent bundle, does not have a well‑defined addition or scalar multiplication, whereas proj2∘X(p)∈TpM\mathrm{proj}_2\circ X(p)\in T_pMproj2​∘X(p)∈Tp​M is an element of a vector space, which naturally admits addition and scalar multiplication.

More generally, whenever we speak of addition or scalar multiplication of sections, we implicitly perform the operation pointwise: evaluate the section at each point, perform the operation in the fibre, and define the result as a new section.

C∞(M)C^\infty(M)C∞(M)-Module

Clearly, under the definitions above, vector fields form a structure that resembles a vector space: addition, scalar multiplication, and closure all appear to be satisfied. But this is not a vector space!

The reason is that FM\mathscr{F}_MFM​ is not a field. Concretely, we cannot guarantee that every smooth scalar field fff possesses a multiplicative inverse ggg that is also a smooth scalar field and satisfies f⋅g=If\cdot g = If⋅g=I, where III is the constant scalar field I:M→RI:M\to\RI:M→R, I(p)=1I(p)=1I(p)=1 for all p∈Mp\in Mp∈M. In fact, FM\mathscr{F}_MFM​ forms a ring.

Basic abstract algebra

We first define a group: a group is a set equipped with a multiplication (G,⋅)(G,\cdot)(G,⋅) satisfying:

  1. Identity: there exists an element eee such that ∀ g∈G\forall\,g\in G∀g∈G, g⋅e=e⋅g=gg\cdot e = e\cdot g = gg⋅e=e⋅g=g;
  2. Inverse: for every g∈Gg\in Gg∈G there exists an element g−1g^{-1}g−1 such that g⋅g−1=g−1⋅g=eg\cdot g^{-1}=g^{-1}\cdot g = eg⋅g−1=g−1⋅g=e;
  3. Closure: for any g,h∈Gg,h\in Gg,h∈G there exists a unique element fff with f=g⋅hf=g\cdot hf=g⋅h;
  4. Associativity: for any f,g,h∈Gf,g,h\in Gf,g,h∈G, (f⋅g)⋅h=f⋅(g⋅h)=f⋅g⋅h(f\cdot g)\cdot h = f\cdot(g\cdot h) = f\cdot g\cdot h(f⋅g)⋅h=f⋅(g⋅h)=f⋅g⋅h.

If the multiplication additionally satisfies g⋅h=h⋅gg\cdot h = h\cdot gg⋅h=h⋅g for all g,h∈Gg,h\in Gg,h∈G, the group is called abelian. A typical example is the additive group of real numbers: the group elements are real numbers R\RR, and the group multiplication is ordinary addition +++. A typical non‑abelian group is the matrix multiplication group: the elements are n×nn\times nn×n matrices, and the multiplication is matrix multiplication.

Next we define a ring: a ring is an abelian group (R,+)(R,+)(R,+) (the group operation is written as addition and called ring addition) equipped with a multiplication, i.e. (R,+,⋅)(R,+,\cdot)(R,+,⋅) is called a ring. The ring multiplication must satisfy:

  1. Distributivity: for all a,b,c∈Ra,b,c\in Ra,b,c∈R, a⋅(b+c)=a⋅b+a⋅ca\cdot(b+c)=a\cdot b + a\cdot ca⋅(b+c)=a⋅b+a⋅c and (a+b)⋅c=a⋅c+b⋅c(a+b)\cdot c = a\cdot c + b\cdot c(a+b)⋅c=a⋅c+b⋅c;
  2. Associativity of multiplication: for all a,b,c∈Ra,b,c\in Ra,b,c∈R, (a⋅b)⋅c=a⋅(b⋅c)=a⋅b⋅c(a\cdot b)\cdot c = a\cdot(b\cdot c) = a\cdot b\cdot c(a⋅b)⋅c=a⋅(b⋅c)=a⋅b⋅c;
  3. Multiplicative identity: there exists 1∈R1\in R1∈R such that 1⋅a=a⋅1=a1\cdot a = a\cdot 1 = a1⋅a=a⋅1=a for all a∈Ra\in Ra∈R (strictly speaking, the most general definition of a ring does not require a multiplicative identity, but it is usually assumed).

If the ring multiplication additionally satisfies a⋅b=b⋅aa\cdot b = b\cdot aa⋅b=b⋅a for all a,b∈Ra,b\in Ra,b∈R, the ring is called commutative. A typical example is the ring of integers: the elements are integers Z\ZZ, ring addition is ordinary addition +++, and ring multiplication is ordinary multiplication ⋅\cdot⋅. A typical non‑commutative ring is the matrix ring: the elements are n×nn\times nn×n matrices, ring addition is componentwise addition, and ring multiplication is matrix multiplication.

If a commutative ring additionally satisfies that every non‑zero element (with respect to the additive identity 000) has a multiplicative inverse, and 0≠10\neq 10=1, then it is called a field.

Clearly, the addition and multiplication defined pointwise on scalar fields over a manifold satisfy the definition of a ring, and it is a commutative ring. As for the structure formed by vector fields, mathematicians call such a set — one that admits a linear structure but is not a vector space — a module.

Module

A module is an abelian group (V,+)(V,+)(V,+) together with an action of a ring RRR on VVV, written as a multiplication R×V→VR\times V\to VR×V→V and denoted by ⋅\cdot⋅, satisfying:

  1. Distributivity: for all a,b∈Ra,b\in Ra,b∈R and u,v∈Vu,v\in Vu,v∈V, a(u+v)=au+ava(u+v)=au+ava(u+v)=au+av and (a+b)u=au+bu(a+b)u = au+bu(a+b)u=au+bu;
  2. Compatibility with ring multiplication: for all a,b∈Ra,b\in Ra,b∈R and v∈Vv\in Vv∈V, a⋅(b⋅v)=(a⋅b)⋅v=a⋅b⋅va\cdot(b\cdot v) = (a\cdot b)\cdot v = a\cdot b\cdot va⋅(b⋅v)=(a⋅b)⋅v=a⋅b⋅v;
  3. Identity: there exists 1∈R1\in R1∈R such that 1⋅v=v1\cdot v = v1⋅v=v for all v∈Vv\in Vv∈V.

When the ring RRR is itself a field, this definition reduces to that of a vector space.

Note: a ring RRR is itself an abelian group under its own addition, so a ring can act on itself, forming an RRR-module. Although this returns the same set RRR, it acquires a module structure that is generally non‑trivial. In particular, for non‑commutative rings, left and right actions yield different module structures.

From the definitions above, it is easy to see that under the addition and scalar multiplication defined earlier, the vector fields Γ(TM)\Gamma(TM)Γ(TM) form a C∞(M)C^\infty(M)C∞(M)-module.

3.2 Introduction to Fibre Bundles​

Continuing from the previous section, we now give the rigorous definition of a fibre bundle.

Fibre Bundle

Formally, a quadruple (E,B,π,F)(E,B,\pi,F)(E,B,π,F) is called a fibre bundle if it satisfies the following properties:

  1. E,B,FE,B,FE,B,F are topological spaces;
  2. π:E→B\pi: E\to Bπ:E→B is a continuous surjection;
  3. For every point x∈Bx\in Bx∈B, there exists an open neighbourhood U⊂BU\subset BU⊂B and a homeomorphism φ:π−1(U)⊂E→U×F\varphi: \pi^{-1}(U)\subset E \to U\times Fφ:π−1(U)⊂E→U×F such that π=proj1∘φ\pi = \mathrm{proj}_1\circ\varphiπ=proj1​∘φ, where proj1\mathrm{proj}_1proj1​ is the natural projection of U×FU\times FU×F.
note

The third condition is a requirement on the map π\piπ; a map satisfying this condition is said to be locally trivial. If this condition is not met, the quadruple is not a fibre bundle but merely a fibration of FFF over BBB.

Here EEE is called the total space, BBB the base space, FFF the fibre, and π\piπ the bundle projection.

Let us now explain this in plain language. Under the local triviality condition, we easily observe that

φ(π−1({x}))={x}×F≅F,\varphi(\pi^{-1}(\{x\})) = \{x\}\times F \cong F,φ(π−1({x}))={x}×F≅F,

i.e. once local triviality is satisfied, each point of the base manifold naturally sprouts its corresponding fibre.

Local trivialisation

It may be counterintuitive that the local triviality condition — requiring an open neighbourhood UUU such that π−1(U)≅U×F\pi^{-1}(U)\cong U\times Fπ−1(U)≅U×F — is stronger than the pointwise condition π−1({x})≅{x}×F≅F\pi^{-1}(\{x\})\cong\{x\}\times F\cong Fπ−1({x})≅{x}×F≅F, even though the latter appears more fine‑grained.

Let us make an analogy. Consider a person's hair. Local triviality demands that on every small patch of the scalp, the hair is smooth and dense, while globally the hairstyle may be short, long, permed, in a bun, pigtails, straight, etc. If your scalp is not locally trivial, you might have dreadlocks, a shaved side, or bald patches.

The author offers this analogy merely to aid understanding, with no intention of offending anyone. If this light‑hearted comparison happens to be offensive to you, the author sincerely apologises.

The discussion above also highlights a point made earlier: the definition of the tangent bundle as

TM=⋃x∈M{x}×TxMTM = \bigcup_{x\in M} \{x\}\times T_xMTM=x∈M⋃​{x}×Tx​M

is not fully rigorous! This is clearly a pointwise construction, and could in principle fail the local triviality condition. Fortunately, in retrospect this definition caused no real problems. The reason is that the tangent bundle inherits a natural topology from the base manifold, and the smoothness of the differentiable manifold automatically guarantees the existence of a local trivialisation. The key point is: this method of constructing the tangent bundle cannot be naïvely generalised to the definition of other fibre bundles.

A clear counterexample is the "cylinder": let the base manifold be S1S^1S1 (the circle) and the fibre be [0,1]⊂R[0,1]\subset\R[0,1]⊂R. Place the centre of the circle at the origin of R3\R^3R3 and use cylindrical coordinates ρ,ϕ,z\rho,\phi,zρ,ϕ,z. Define

E=⋃x∈S1{x}×[0,1],E = \bigcup_{x\in S^1} \{x\}\times[0,1],E=x∈S1⋃​{x}×[0,1],

and impose the following rule: when the cylindrical angle ϕ\phiϕ is rational, the fibre [0,1][0,1][0,1] is placed horizontally (i.e. along the radial direction ρ\rhoρ) at the corresponding point on S1S^1S1; when ϕ\phiϕ is irrational, the fibre [0,1][0,1][0,1] is placed vertically (i.e. along the zzz direction). One can imagine that as the angle varies, the fibre oscillates wildly, so that for a given point there is absolutely no open neighbourhood UUU for which π−1(U)≅U×[0,1]\pi^{-1}(U)\cong U\times[0,1]π−1(U)≅U×[0,1]. This is a typical example of a fibration that fails to be a fibre bundle.

We should also clarify one point: although we formally write a quadruple (E,B,π,F)(E,B,\pi,F)(E,B,π,F), we do not actually know EEE in advance. In fact, we use the base space BBB, the fibre FFF, and the bundle projection π\piπ to describe the total space EEE.

Furthermore, for an unknown fibre bundle, our knowledge of the bundle projection π\piπ is limited to the fact that it is, in a suitable sense, equivalent to the natural projection — as expressed in the local triviality condition: π=proj1∘φ\pi = \mathrm{proj}_1\circ\varphiπ=proj1​∘φ. The bundle projection π\piπ is equivalent, up to the homeomorphism provided by local trivialisation, to the natural projection of a Cartesian product. For simple fibre bundles such as the tangent bundle, it is the natural projection.

note

You may wonder: if two of the four components are unclear to us, how do we describe a fibre bundle at all? In fact, we have not yet introduced another crucial ingredient: the transition functions.

What are these? They are analogous to the differentiable structure of a manifold. Suppose that for a point xxx on the base manifold there exist two open neighbourhoods UαU_\alphaUα​ and UβU_\betaUβ​, each equipped with a local trivialisation: π=proj1∘φα=proj1∘φβ\pi = \mathrm{proj}_1\circ\varphi_\alpha = \mathrm{proj}_1\circ\varphi_\betaπ=proj1​∘φα​=proj1​∘φβ​. On the overlap U=Uα∩UβU = U_\alpha\cap U_\betaU=Uα​∩Uβ​, we obtain a map

φα∘φβ−1:U×F→U×F.\varphi_\alpha\circ\varphi_\beta^{-1}: U\times F \to U\times F.φα​∘φβ−1​:U×F→U×F.

By the local triviality condition, points of the base space are left unchanged, so this map acts only on the fibre. It is called a transition function.

We will not delve deeper into this concept for now, as it requires some group theory. Once we have finished with the manifold‑related concepts, we will return to explore this topic in greater depth.

In fact, both the transition functions and the bundle projection serve to describe how a fibre bundle is assembled from local Cartesian products into a global (generally) non‑trivial structure. The bundle projection captures global properties, while the transition functions (together with the structure group) capture local properties. Under suitable conditions, the two can define each other. From an axiomatic viewpoint, the bundle projection is the cleanest; but for concrete computations, specifying the transition functions is indispensable.

If the reader finds the above passage incomprehensible, a sensible option is to take a half‑hour walk, return, skip the preceding paragraph, pretend to have understood it, and continue reading. The discussion above is the kind of axiomatic presentation that mathematicians adore; we were obliged to include it for the sake of rigour. The few bundles we will actually use are all very simple and trivial (at least within the scope of this article), so we shall strive to keep the material accessible while maintaining a sufficiently clean, high‑level definition.

Vector Bundles​

In the special case where the fibre FFF is a vector space, i.e. F≅KnF\cong\mathbb{K}^nF≅Kn with K=\C\mathbb{K}=\CK=\C or R\RR, we call the fibre bundle a vector bundle.
