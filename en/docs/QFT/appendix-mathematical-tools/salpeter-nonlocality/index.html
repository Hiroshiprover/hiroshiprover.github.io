A. Nonlocality of the Salpeter Equation and the Probability Current

Let us discuss in detail the nonlocality mentioned in the main text.

Locality​

Let us first define locality rigorously:

Locality

A translation-invariant linear operator acts on sufficiently well-behaved test functions as

(D^f)(x⃗)=∫d3y K(x⃗−y⃗)f(y⃗),(\hat Df)(\vec x)=\int d^3y\,K(\vec x-\vec y)f(\vec y),(D^f)(x)=∫d3yK(x−y​)f(y​),

where KKK is called the integral kernel; it may be an ordinary function, or a distribution such as the Dirac delta function and its derivatives. If KKK is supported only at the origin (roughly speaking, it is nonzero only at the origin), the operator is called local.

A few examples:

  1. The kernel of the identity operator is δ(3)(x⃗−y⃗)\delta^{(3)}(\vec x-\vec y)δ(3)(x−y​), which is obviously local.
  2. The kernel of a derivative operator is ∂iδ(3)(x⃗−y⃗)\partial_{i}\delta^{(3)}(\vec x-\vec y)∂i​δ(3)(x−y​), which is also local. Hence any linear combination of derivative operators of finite order is local as well.
  3. For a translation, f(x⃗)↦f(x⃗+a⃗)f(\vec x)\mapsto f(\vec x+\vec a)f(x)↦f(x+a), the kernel is δ(3)(x⃗−y⃗+a⃗)\delta^{(3)}(\vec x-\vec y+\vec a)δ(3)(x−y​+a); when a⃗≠0\vec a\ne0a=0 it reads the value of the function at another point, so the operator is nonlocal.

Nonlocality of the square-root operator​

The Salpeter equation reads

i∂tψ=−∇2+m2 ψ,i\partial_t\psi=\sqrt{-\nabla^2+m^2}\,\psi,i∂t​ψ=−∇2+m2​ψ,

In the main text we only wrote down this equation formally and did not give it a rigorous definition. We must first define how the square-root operator acts on functions before we can discuss it further. Recall from finite-dimensional linear algebra that a Hermitian operator has a spectral decomposition:

A^=∑nan∣n⟩⟨n∣,\hat{A}=\sum_n a_n |n\rangle\langle n|,A^=n∑​an​∣n⟩⟨n∣,

If A^\hat{A}A^ is a positive operator, that is, every eigenvalue ana_nan​ is non-negative, then there is a unique positive square-root operator:

A^≡∑nan∣n⟩⟨n∣.\sqrt{\hat{A}} \equiv \sum_n \sqrt{a_n} |n\rangle\langle n|.A^​≡n∑​an​​∣n⟩⟨n∣.

In infinite dimensions the question is much more delicate. But we only consider wave functions that are smooth and decay sufficiently fast at infinity, in which case −∇2+m2-\nabla^2+m^2−∇2+m2 is indeed a positive operator. Given the baby nature of these notes, we will not reproduce the proof and simply use this conclusion. First note that

(−∇2+m2)eik⃗⋅x⃗=(k2+m2)eik⃗⋅x⃗\left(-\nabla^2 +m^2\right)e^{i\vec k\cdot\vec x}= (k^{2}+m^2) e^{i\vec k\cdot\vec x}(−∇2+m2)eik⋅x=(k2+m2)eik⋅x

so −∇2+m2-\nabla^2 +m^2−∇2+m2 has eigenvalues k2+m2k^{2}+m^2k2+m2 with eigenvectors eik⃗⋅x⃗e^{i\vec k\cdot\vec x}eik⋅x. We therefore define the action of the square-root operator by

−∇2+m2 eik⃗⋅x⃗≡k2+m2 eik⃗⋅x⃗.\sqrt{-\nabla^2+m^2}\,e^{i\vec k\cdot\vec x} \equiv\sqrt{k^2+m^2}\,e^{i\vec k\cdot\vec x}.−∇2+m2​eik⋅x≡k2+m2​eik⋅x.

Now expanding ψ\psiψ in a Fourier integral, we obtain

−∇2+m2 ψ(x⃗,t)=∫d3k(2π)3 k2+m2 ψ~(k⃗,t)eik⃗⋅x⃗.\sqrt{-\nabla^2+m^2}\,\psi(\vec x,t) =\int\frac{d^3k}{(2\pi)^3}\, \sqrt{k^2+m^2}\,\widetilde\psi(\vec k,t)e^{i\vec k\cdot\vec x}.−∇2+m2​ψ(x,t)=∫(2π)3d3k​k2+m2​ψ​(k,t)eik⋅x.

Comparing with the expression for locality obtained just now, we have

K~(k⃗)=k2+m2.\widetilde K(\vec k)=\sqrt{k^2+m^2}.K(k)=k2+m2​.

By the lemma proved above, k2+m2\sqrt{k^2+m^2}k2+m2​ is not a polynomial in kkk of finite degree, so KKK cannot be supported only at the origin; hence the square-root operator is nonlocal.

In fact we may also add to the probability current a part with vanishing divergence, so the choice above is not unique. This freedom cannot, however, produce a local bilinear current: if K⃗~(−p⃗,q⃗)\widetilde{\vec K}(-\vec p,\vec q)K(−p​,q​) were a polynomial, then (p⃗−q⃗)⋅K⃗~(−p⃗,q⃗)(\vec p-\vec q)\cdot\widetilde{\vec K}(-\vec p,\vec q)(p​−q​)⋅K(−p​,q​) would also have to be a polynomial, whereas the difference of square roots on the right-hand side of the continuity equation is not. This contradiction shows that, for the density ∣ψ∣2|\psi|^2∣ψ∣2, there is no translation-invariant bilinear probability current satisfying the locality condition above.

So the Salpeter equation does conserve total probability, and it does have a probability current, but that current is not local, which brings us back to the problem discussed in the main text.
