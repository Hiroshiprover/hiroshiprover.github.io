7.6 Equivalence of canonical Ensemble and Grand Canonical Ensemble

If ∂P/∂v<0\partial P/\partial v < 0∂P/∂v<0, nearly all systems in the grand canonical ensemble have the same particle number NNN as the relative density fluctuation remains small. In this case, the equivalence between the grand canonical and canonical ensembles is evident.

To complete our investigation of the equivalence between the canonical and grand canonical ensembles, it is necessary to consider values of vvv for which ∂P/∂v=0\partial P/\partial v = 0∂P/∂v=0. It will be shown that in such cases the function W(N)W(N)W(N) given in Eq. (7.45) no longer has a sharp maximum; nevertheless, the equation of state obtained from the grand canonical ensemble still agrees with that obtained from the canonical ensemble. In this broader sense, the two ensembles are always equivalent.

Physically, the condition ∂P/∂v=0\partial P/\partial v = 0∂P/∂v=0 correspond to the coexistence region of a first-order phase transition. In this region, Eq. (7.44) leads us to expect that the density fluctuations in a given volume of the system will be large. This is also physically reasonable, since in such a region the system consists of two or more phases of different densities. Consequently, the number of particles in any given volume can take a wide range of values, depending on the amounts of each phase present. At the critical point of a gas–liquid system (continuous phase transition), density fluctuations are likewise expected to be large, because throughout the system molecules are spontaneously forming large clusters and breaking up. Clearly, under these conditions the grand canonical ensemble must continue to yield thermodynamic predictions in agreement with those obtained from the canonical ensemble. Otherwise, the validity of either as a description of matter would be in doubt, since it is a basic experimental fact that the same thermodynamic information can be obtained whether we examine the whole system (corresponding to canonical ensemble) or only a subvolume of it (corresponding to grand canonical ensemble).

Mathematically, given the canonical partition function QN(V,T)Q_N(V,T)QN​(V,T), we aim to compute the grand partition function:

Q(z,V,T)=∑N=0∞zNQN(V,T)\mathcal{Q}(z,V,T) = \sum_{N=0}^{\infty} z^N Q_N(V,T)Q(z,V,T)=N=0∑∞​zNQN​(V,T)

for specific values of zzz, VVV, and TTT, and address the following:

(a) For a fixed zzz, does the approximation Q(z,V,T)≈zNQN(V,T)\mathcal{Q}(z,V,T) \approx z^N Q_N(V,T)Q(z,V,T)≈zNQN​(V,T) hold for some NNN?

(b) Does there always exist a value of zzz such that NNN has any given positive value?

Clearly, for an arbitrary function QN(V,T)Q_N(V,T)QN​(V,T), the answers to these questions are generally “no.” However, we are not interested in a general function QN(V,T)Q_N(V,T)QN​(V,T); rather, we are interested in those partition functions that correspond to real physical systems.

To incorporate the salient features of a physical system while keeping the mathematics simple, we assume that our system has the following properties:

  • The molecules are modeled as hard spheres of finite diameter that also interact through a finite-range potential.

  • The Helmholtz free energy has the form

    A(N,V)=−1βln⁡QN(V)=−Vβf(v),f(v)=−βva(v).(7.66)A(N,V) = -\frac{1}{\beta}\ln Q_N(V) = -\frac{V}{\beta}f(v),\quad f(v) = -\frac{\beta}{v}a(v). \tag{7.66}A(N,V)=−β1​lnQN​(V)=−βV​f(v),f(v)=−vβ​a(v).(7.66)

    The temperature TTT will be fixed throughout our discussion and will not be displayed. The function f(v)f(v)f(v) is an intensive quantity. According to Eq. (7.42), P=−∂va(v)P = -\partial_v a(v)P=−∂v​a(v); hence f(v)f(v)f(v) can be written as an integral of the pressure P(v)P(v)P(v) of the canonical ensemble:

    f(v)=−βva(v)=1v∫v0vβP(v′)dv′.(7.67)f(v) = -\frac{\beta}{v}a(v) = \frac{1}{v}\int_{v_0}^{v}\beta P(v')dv'. \tag{7.67}f(v)=−vβ​a(v)=v1​∫v0​v​βP(v′)dv′.(7.67)

    Here, the integration is carried out along an isotherm and v0v_0v0​ is an arbitrary constant corresponding to an arbitrary additive constant in the Helmholtz free energy.

  • It is reasonable to assume (or in other words, we only consider this physical situation)

    ∂P∂v≤0,(7.68)\frac{\partial P}{\partial v} \leq 0, \tag{7.68}∂v∂P​≤0,(7.68)

    which implies

    ∂2f(v)∂(1/v)2=βv3∂P∂v≤0.(7.69)\frac{\partial^2 f(v)}{\partial(1/v)^2} = \beta v^3\frac{\partial P}{\partial v} \leq 0. \tag{7.69}∂(1/v)2∂2f(v)​=βv3∂v∂P​≤0.(7.69)

    The reason for making derivative of f(v)f(v)f(v) w.r.t. 1/v1/v1/v, instead of vvv, will soon be clear.

Recall that the molecules are assumed to be hard spheres; therefore, in a finite volume VVV, the particle number cannot exceed an upper close-packing limit, denoted by N0(V)N_0(V)N0​(V).
