Remark on the first order phase transition.​

As shown in the PPP-vvv diagram of Fig. 7.3, the first-order phase transition occurs over the interval v1≤v≤v2v_1 \leq v \leq v_2v1​≤v≤v2​. Consider a system initially in the pure low-density phase at v=v2v = v_2v=v2​. As additional molecules are gradually introduced into the fixed volume VVV, the system responds by transferring molecules from the low-density phase to the high-density phase. Thus, the pressure stays constant throughout the transition region until the system is entirely in the pure high-density phase. The number of such transfers is proportional to VVV. Each transfer corresponds to a term in the grand partition function, and all these terms have the same value.

In the grand canonical ensemble, the grand partition function is a weighted sum of the partition function with all possible particle number NNN

Q(z,V)=∑N=0∞zNQN(V),Eq. (7.34).\mathcal{Q}(z,V) = \sum_{N=0}^{\infty} z^N Q_N(V),\qquad \text{Eq. }(7.34).Q(z,V)=N=0∑∞​zNQN​(V),Eq. (7.34).

We will show the equivalence between the grand canonical ensemble and the canonical ensemble. For this purpose, a new function ϕ(V/N,z)\phi(V/N,z)ϕ(V/N,z) is introduced to represent the partition function

eVϕ(V/N,z)=zNQN(V)=W(N),Eq. (7.70).e^{V\phi(V/N,z)} = z^N Q_N(V) = W(N),\qquad \text{Eq. }(7.70).eVϕ(V/N,z)=zNQN​(V)=W(N),Eq. (7.70).

where the value of vˉ\bar{v}vˉ is determined by ∂ϕ/∂v∣v=vˉ=0\partial\phi/\partial v|_{v=\bar{v}} = 0∂ϕ/∂v∣v=vˉ​=0. This equation tells us that at a fixed fugacity zzz, the grand canonical ensemble is equivalent to a canonical ensemble with fixed particle number Nˉ=V/vˉ\bar{N} = V/\bar{v}Nˉ=V/vˉ.

If ∂P/∂v<0\partial P/\partial v < 0∂P/∂v<0 (κT\kappa_TκT​ is a finite positive number), the equivalence between the grand canonical and canonical ensembles is readily understood. This is because the relative fluctuation of particle number becomes statistically insignificant in the thermodynamic limit, and the function ϕ(v,z)\phi(v,z)ϕ(v,z) associated with the partition function exhibits a sharp peak at the equilibrium molecular volume v=vˉv = \bar{v}v=vˉ.

When ∂P/∂v=0\partial P/\partial v = 0∂P/∂v=0, as commonly encountered in first-order phase transitions, the peak of ϕ(v,z)\phi(v,z)ϕ(v,z) vanishes. For instance, in the liquid-gas transition, we have shown that the function ϕ(v,z)\phi(v,z)ϕ(v,z) for a particular value of z=z0z = z_0z=z0​ remains flat as the volume varies within the transition region v1<v<v2v_1 < v < v_2v1​<v<v2​. This behavior suggests that different canonical ensembles with varying particle numbers NNN in the range V/v2<N<V/v1V/v_2 < N < V/v_1V/v2​<N<V/v1​ all yield the same value of W(N)W(N)W(N). As an average of these functions, the grand partition function retains the same value as each individual term W(N)W(N)W(N) within the transition region, thereby resulting in the same pressure.

Finally, we have shown that, in all physically relevant cases with ∂P/∂v≤0\partial P/\partial v \leq 0∂P/∂v≤0, the grand canonical ensemble is equivalent to the canonical ensemble.
