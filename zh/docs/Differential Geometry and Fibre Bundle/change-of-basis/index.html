基变换

终于，我们现在有了足够的基础知识，来回答一个最基本的问题：为什么向量的分量指标是上标，对偶向量的分量指标是下标，而基的指标恰好反过来？这一切的悲剧，都是物理学家使用一个对象在基变换下的表现来命名导致的。

四种基本对象的变换​

基向量的变换​

考虑这样的一个线性映射：

Λ:V→V,{eμ}↦{eμ′},\Lambda: V \to V, \quad \{e_\mu \} \mapsto \{e'_\mu\},Λ:V→V,{eμ​}↦{eμ′​},

答案是显然的：Λ\LambdaΛ是一个(1,1)(1, 1)(1,1)型张量（矩阵），并且有：

eμ′=Λνμeν,e'_\mu = \Lambda^\nu{}_\mu e_\nu, eμ′​=Λνμ​eν​,

这里的 eμe_\mueμ​ 和 eμ′e'_\mueμ′​ 都是实际的向量。注意：Λνμ\Lambda^\nu{}_\muΛνμ​ 是 Λ\LambdaΛ 在 {eμ}\{e_\mu\}{eμ​} 下的分量。

备注

事实上，Λ\LambdaΛ 这个字母常被用来指代一个更特殊的变换：洛伦兹变换，它是在要求时空间隔 ds2\mathrm{d} s^2ds2 是坐标变换不变量之下得到的。当然，我们这里并没有这样的限制。

向量分量的变换​

接下来我们来分析任意一个向量 vvv 在基向量的变换 Λ\LambdaΛ 下，其分量的变换规律。考虑向量 vvv 分别在两组基下的展开系数：

v=vμeμ=v′μeμ′,v=v^\mu e_\mu = v'^\mu e'_\mu,v=vμeμ​=v′μeμ′​,

带入基变换的关系，我们可以得到：

v′μΛνμeν=vνeνv'^\mu \Lambda^\nu{}_\mu e_\nu = v^\nu e_\nu v′μΛνμ​eν​=vνeν​

即：

v′μ=(Λ−1)μνvν.v'^\mu = (\Lambda^{-1})^\mu{}_\nu v^\nu.v′μ=(Λ−1)μν​vν.
备注

一个矩阵的逆，在张量语言下，就是满足这样一个条件的张量：

Λμρ(Λ−1)ρν=δμν.\Lambda^\mu{}_\rho (\Lambda^{-1})^\rho{}_\nu = \delta^\mu{}_\nu.Λμρ​(Λ−1)ρν​=δμν​.

对偶基的变换​

我们从对偶基的定义出发。考虑原基的对偶基：

δμν=eμeν,\delta^\mu{}_\nu = e^\mu e_\nu,δμν​=eμeν​,

等式左右两边同时乘以 Λνρe′ρ\Lambda^\nu{}_\rho e'^\rhoΛνρ​e′ρ，得到：

Λμρe′ρ=eμe′ρΛνρeν=eμe′ρeρ′=eμ,\Lambda^\mu{}_\rho e'^\rho = e^\mu e'^\rho \Lambda^\nu{}_\rho e_\nu = e^\mu e'^\rho e'_\rho = e^\mu,Λμρ​e′ρ=eμe′ρΛνρ​eν​=eμe′ρeρ′​=eμ,

因此，同时乘以 (Λ−1)σμ(\Lambda^{-1})^\sigma{}_\mu (Λ−1)σμ​，得到：

e′σ=(Λ−1)σμeμe'^\sigma = (\Lambda^{-1})^\sigma{}_\mu e^\mue′σ=(Λ−1)σμ​eμ

更换一下被求和掉的指标名称，即：

e′μ=(Λ−1)μνeν.e'^\mu = (\Lambda^{-1})^\mu{}_\nu e^\nu.e′μ=(Λ−1)μν​eν.

对偶向量分量的变换​

与向量类似地，从下面这个等式出发：

ω=ωμeμ=ωμ′e′μ\omega = \omega_\mu e^\mu = \omega'_\mu e'^\muω=ωμ​eμ=ωμ′​e′μ

带入基变换的关系，就有：

ωμ′=Λνμων.\omega'_\mu = \Lambda^\nu{}_\mu \omega_\nu.ωμ′​=Λνμ​ων​.

逆变与协变​

至此，我们发现了一个统一的规律：

逆变与协变

基向量的变换与对偶向量的变换是：

eμ′=Λνμeν,ωμ′=Λνμων,e'_\mu = \Lambda^\nu{}_\mu e_\nu, \qquad \omega'_\mu = \Lambda^\nu{}_\mu \omega_\nu,eμ′​=Λνμ​eν​,ωμ′​=Λνμ​ων​,

而对偶基与向量（的分量）的变换是：

e′μ=(Λ−1)μνeν,v′μ=(Λ−1)μνvν.e'^\mu = (\Lambda^{-1})^\mu{}_\nu e^\nu, \qquad v'^\mu = (\Lambda^{-1})^\mu{}_\nu v^\nu.e′μ=(Λ−1)μν​eν,v′μ=(Λ−1)μν​vν.

不难注意到：只要它被上标标记，在基变换下，它就是被基变换矩阵的逆变换的；而被下标标记，在基变换下，它就是被基变换矩阵本身变换的。

因此，我们称上标为逆变指标，下标为协变指标；称向量为逆变向量，对偶向量为协变向量。

这就解释了为什么爱因斯坦求和约定是这样定义的：指标的上下不声明张量类型，而声明变换类型。因此向量（的分量）采用上标，对偶向量（的分量）采用下标。而上下指标重复表示求和是显然的：这就是张量之间如何相互作用（缩并）。

信息

对于更一般的张量，其分量的坐标变换规律是：

Tμ1⋯μkν1⋯νl=(Λ−1)μ1ρ1⋯(Λ−1)μkρkΛσ1ν1⋯ΛσlνlTρ1⋯ρkσ1⋯σl,T^{\mu_1\cdots \mu_k}{}_{\nu_1\cdots \nu_l} = (\Lambda^{-1})^{\mu_1}{}_{\rho_1}\cdots(\Lambda^{-1})^{\mu_k}{}_{\rho_k}\Lambda^{\sigma_1}{}_{\nu_1}\cdots\Lambda^{\sigma_l}{}_{\nu_l} T^{\rho_1\cdots \rho_k}{}_{\sigma_1\cdots \sigma_l},Tμ1​⋯μk​ν1​⋯νl​​=(Λ−1)μ1​ρ1​​⋯(Λ−1)μk​ρk​​Λσ1​ν1​​⋯Λσl​νl​​Tρ1​⋯ρk​σ1​⋯σl​​,

我们略去对这个结果的证明。

备注

许多物理书实际上将此作为张量的定义：一个 (k,l)(k, l)(k,l) 张量为满足上述变换规律的一组数，然后不考虑基的变换。这种定义当然是对的，但是显然是缺乏深度的。
