Linear Algebra for Differential Geometry

We assume the reader already has some basic familiarity with linear algebra, such as the definitions of vector spaces and bases.

There are several concepts that may not appear in an introductory linear algebra course. For those, I will state the basic definitions here. For more detailed discussions, one may consult Linear Algebra Done Right or any standard advanced linear algebra textbook.

Readers may notice that some notation conventions differ from those used in other areas. In most cases they refer to exactly the same mathematical objects, so there is no reason to panic.

Vector Spaces​

In linear algebra, every finite-dimensional vector space admits a basis {eμ}\{e_\mu\}{eμ​}, such that any vector can be expanded with respect to this basis.

Index conventions

Readers may be more familiar with using i,j,ki,j,ki,j,k as indices, or explicitly writing 1,2,3,…1,2,3,\dots1,2,3,….

In differential geometry, Greek letters μ,ν,ρ,…\mu,\nu,\rho,\dotsμ,ν,ρ,… are typically used for vectors and their components. This is purely a convention.

In the context of general relativity (four-dimensional spacetime), one usually assumes:

μ,ν,ρ,⋯=0,1,2,3,\mu,\nu,\rho,\dots = 0,1,2,3,μ,ν,ρ,⋯=0,1,2,3,

where 000 denotes the time component.

Meanwhile, due to historical convention, one often writes

i,j,k,⋯=1,2,3i,j,k,\dots = 1,2,3i,j,k,⋯=1,2,3

for spatial indices.

Ordinary Roman letters such as a,b,ca,b,ca,b,c are often used as abstract indices. They do not take numerical values, but only indicate tensor type. This is a somewhat subtle topic which we will discuss later.

Once a basis is chosen, any vector can be expanded as

v=∑μvμeμ.v=\sum_\mu v^\mu e_\mu.v=μ∑​vμeμ​.

Notice that vector components are written with upper indices here. This is a common convention in differential geometry, and later we will see that it is actually quite natural.

Einstein Summation Convention​

So far everything is just standard linear algebra.

Now we begin preparing for differential geometry. In differential geometry, expressions with four or more summation signs frequently appear (for example, the full contraction of the Riemann curvature tensor into the Ricci scalar). Writing out every summation sign quickly becomes visually exhausting.

To avoid this, we introduce the Einstein summation convention.

Einstein summation convention

Whenever an upper and lower index with the same symbol appears repeatedly, summation over that index is implied.

For example,

vμeμ=∑μvμeμ,v^\mu e_\mu = \sum_\mu v^\mu e_\mu,vμeμ​=μ∑​vμeμ​,

or

Aμνvν≡∑νAμνvν.A^\mu{}_\nu v^\nu \equiv \sum_\nu A^\mu{}_\nu v^\nu.Aμν​vν≡ν∑​Aμν​vν.

At the moment, we do not need to worry too much about what all these symbols mean. Their meaning will become clearer later.

For now, one may simply view this as a symbolic rule.

note

Physicists often suppress the basis entirely and define vectors directly through their components vμv^\muvμ, together with transformation laws.

This approach is often more intuitive, but somewhat less structural.

Here we adopt a more mathematical viewpoint, which is useful when discussing invariants and canonical objects.

In particular, we emphasize:

  1. vμv^\muvμ are the components of the vector vvv in the basis {eμ}\{e_\mu\}{eμ​};
  2. {eμ}\{e_\mu\}{eμ​} are actual vectors.

Dual Vector Spaces​

Definition​

We first define dual vectors.

Dual vector

A dual vector is a linear functional defined on a vector space VVV:

ω:V→R,v↦ω(v).\omega: V\to\mathbb{R}, \qquad v\mapsto\omega(v).ω:V→R,v↦ω(v).

It satisfies linearity:

ω(αv+βw)=αω(v)+βω(w),∀v,w∈V.\omega(\alpha v+\beta w) = \alpha\omega(v)+\beta\omega(w), \qquad \forall v,w\in V.ω(αv+βw)=αω(v)+βω(w),∀v,w∈V.
note

If you are more comfortable with matrix language, you may think of this as a row vector.

Addition and scalar multiplication are naturally defined for dual vectors:

  1. Addition:

    (ω1+ω2)(v)=ω1(v)+ω2(v);(\omega_1+\omega_2)(v)=\omega_1(v)+\omega_2(v);(ω1​+ω2​)(v)=ω1​(v)+ω2​(v);

  2. Scalar multiplication:

    (c⋅ω)(v)=c⋅ω(v).(c \cdot \omega)(v)=c\cdot \omega(v).(c⋅ω)(v)=c⋅ω(v).

Under these operations, the set of all dual vectors forms a vector space, denoted by V∗V^*V∗.

Dual Basis​

Since dual vectors form a vector space, we naturally ask for its basis.

Suppose {eμ}\{e_\mu\}{eμ​} is a basis of VVV. We define the dual basis as follows.

Dual basis

Given a basis {eμ}\{e_\mu\}{eμ​} of VVV, define {eμ}\{e^\mu\}{eμ} in V∗V^*V∗ by

eμ(eν)=δμν.e^\mu(e_\nu)=\delta^\mu{}_\nu.eμ(eν​)=δμν​.
note

Here δμν\delta^\mu{}_\nuδμν​ is the well-known Kronecker delta:

δμν={1,μ=ν,0,μ≠ν.\delta^\mu{}_\nu= \begin{cases} 1,&\mu=\nu,\\ 0,&\mu\neq\nu. \end{cases}δμν​={1,0,​μ=ν,μ=ν.​

In differential geometry it is written with one upper and one lower index, which makes it behave naturally as the identity matrix.

It satisfies

δμνvν=vμ.\delta^\mu{}_\nu v^\nu=v^\mu.δμν​vν=vμ.

That is, it effectively replaces indices.

note

One should verify that {eμ}\{e^\mu\}{eμ} is indeed a basis, meaning that any ω∈V∗\omega\in V^*ω∈V∗ can be expanded as

ω=ωμeμ.\omega=\omega_\mu e^\mu.ω=ωμ​eμ.

Again we are using Einstein summation convention.

Notice that vector components carry upper indices, while dual vector components carry lower indices.

This is not decorative notation. It reflects different transformation laws, which we will later derive.

From this definition, one immediately obtains an important fact:

dim⁡V=dim⁡V∗\dim V=\dim V^*dimV=dimV∗

for finite-dimensional vector spaces.

note

Many linear algebra textbooks write the dual basis as eμ∗e_\mu^*eμ∗​.

Differential geometry usually writes it simply as eμe^\mueμ, which is more convenient once tensors are introduced.

The Dual of the Dual: Natural Isomorphism​

Since V∗V^*V∗ is itself a vector space, we can define its dual space V∗∗V^{**}V∗∗.

This process can clearly be repeated indefinitely, which naturally raises suspicion: do we really need to keep dualizing forever?

Fortunately, there is a canonical relation between VVV and V∗∗V^{**}V∗∗.

Natural isomorphism between VVV and V∗∗V^{**}V∗∗

For any v∈Vv\in Vv∈V, define a linear functional on V∗V^*V∗ by

v′(ω)=ω(v).v'(\omega)=\omega(v).v′(ω)=ω(v).

But linear functionals on V∗V^*V∗ are precisely elements of V∗∗V^{**}V∗∗.

Therefore every vector in VVV naturally determines an element of V∗∗V^{**}V∗∗.

In other words,

V≅V∗∗.V\cong V^{**}.V≅V∗∗.

This isomorphism does not depend on any choice of basis, so it is called a natural isomorphism or canonical isomorphism.

This allows vectors and dual vectors to pair naturally:

ω(v)=ωμvμ.\omega(v)=\omega_\mu v^\mu.ω(v)=ωμ​vμ.

Similarly,

v(ω)=vμωμ.v(\omega)=v^\mu\omega_\mu.v(ω)=vμωμ​.

Hence,

ωμvμ=vμωμ.\omega_\mu v^\mu=v^\mu\omega_\mu.ωμ​vμ=vμωμ​.

This may look trivial, but it illustrates an important principle:

as long as index structure is correct, components may be manipulated like ordinary scalars, without constantly worrying about compositions of maps.

This is one reason why Einstein summation notation is so powerful.

note

If the equations above seem mysterious, write the bases explicitly and examine the interaction between basis vectors and dual basis vectors.

Remember that components are ordinary real numbers, while dual vectors are linear maps.

warning

All discussion above assumes finite-dimensional vector spaces.

For infinite-dimensional spaces, V∗V^*V∗ is typically larger than VVV, and V∗∗V^{**}V∗∗ is usually larger than VVV as well.

Thus in general,

V≇V∗∗.V\not\cong V^{**}.V≅V∗∗.

This is one reason why quantum mechanics, despite involving vectors (kets), dual vectors (bras), and tensors (operators), usually does not directly use Einstein summation convention.

In particular, one must be careful with states such as ∣x⟩|x\rangle∣x⟩ and ∣p⟩|p\rangle∣p⟩.

Interested readers may look into rigged Hilbert spaces.
