Introduction to Tensors

In matrix language, vectors are represented as column vectors, while covectors (another name for dual vectors) are represented as row vectors. Then what exactly is a matrix? We will use this question as motivation to introduce the definition of tensors.

Motivation​

Let us first consider the so-called quadratic form:

xTAx=[x1x2⋯xn][a11a12⋯a1na21a22⋯a2n⋮⋮⋱⋮an1an2⋯ann][x1x2⋮xn].x^TAx=\begin{bmatrix} x_1&x_2&\cdots&x_n \end{bmatrix} \begin{bmatrix} a^1{}_1&a^1{}_2&\cdots&a^1{}_n \\ a^2{}_1&a^2{}_2&\cdots&a^2{}_n \\ \vdots & \vdots & \ddots & \vdots \\ a^n{}_1&a^n{}_2&\cdots&a^n{}_n \end{bmatrix} \begin{bmatrix} x^1\\x^2\\ \vdots \\ x^n \end{bmatrix} .xTAx=[x1​​x2​​⋯​xn​​]​a11​a21​⋮an1​​a12​a22​⋮an2​​⋯⋯⋱⋯​a1n​a2n​⋮ann​​​​x1x2⋮xn​​.

Notice that the object on the left is a covector (row vector), while the object on the right is a vector (column vector), and the entire quadratic form evaluates to a real number.

Therefore, we may think of a matrix as a map sending a covector and a vector to a real number.

note

Of course, we also know that matrices can represent linear maps between vector spaces, or changes of basis. We will return to this perspective later.

More generally, let us allow different vectors on the two sides of the quadratic form. We then observe that matrices are linear in both the covector and vector arguments:

(αxT+βyT)Az=αxTAz+βyTAz,xTA(αy+βz)=αxTAy+βxTAz.(\alpha x^T + \beta y^T)Az = \alpha x^TAz + \beta y^TAz, \qquad x^TA(\alpha y + \beta z) = \alpha x^TAy + \beta x^TAz.(αxT+βyT)Az=αxTAz+βyTAz,xTA(αy+βz)=αxTAy+βxTAz.

Although this observation may seem elementary, it suggests a more general viewpoint: rather than viewing a matrix merely as a map from one vector space to another, we may regard it as a bilinear map defined on a vector space VVV and its dual space V∗V^*V∗.

This naturally leads us to more general constructions.

Definition: Tensor​

Let us first define bilinear maps rigorously, or more generally, multilinear maps.

Multilinear Map

Let V1,V2,⋯ ,VnV_1, V_2, \cdots, V_nV1​,V2​,⋯,Vn​ be vector spaces over R\mathbb RR (or more generally, over the same field). An nnn-linear map is a map

T:V1×V2×⋯×Vn→R,T(v1,v2,⋯ ,vn)=c∈R,T: V_1 \times V_2 \times \cdots \times V_n \to \mathbb R, \qquad T(v_1, v_2, \cdots, v_n)=c\in\mathbb R,T:V1​×V2​×⋯×Vn​→R,T(v1​,v2​,⋯,vn​)=c∈R,

such that for all vi,wi∈Viv_i,w_i\in V_ivi​,wi​∈Vi​, i=1,2,⋯ ,ni=1,2,\cdots,ni=1,2,⋯,n, and all α,β∈R\alpha,\beta\in\mathbb Rα,β∈R,

T(⋯ ,αvi+βwi,⋯ )=αT(⋯ ,vi,⋯ )+βT(⋯ ,wi,⋯ ).T(\cdots,\alpha v_i+\beta w_i,\cdots) = \alpha T(\cdots,v_i,\cdots) + \beta T(\cdots,w_i,\cdots).T(⋯,αvi​+βwi​,⋯)=αT(⋯,vi​,⋯)+βT(⋯,wi​,⋯).
Cartesian Product

The product symbol between vector spaces denotes the Cartesian product. The Cartesian product simply collects elements from two spaces into ordered pairs:

V×W:={(v,w)∣v∈V, w∈W}.V\times W:=\{(v,w)\mid v\in V,\ w\in W\}.V×W:={(v,w)∣v∈V, w∈W}.

Note that "ordered" means (v,w)≠(w,v)(v,w)\neq (w,v)(v,w)=(w,v) in general.

In particular, for repeated Cartesian products of the same vector space, we use exponential notation:

Vn:=V×V×⋯×V⏟n times.V^n:=\underbrace{V\times V\times\cdots\times V}_{n\text{ times}}.Vn:=n timesV×V×⋯×V​​.

This is also the origin of the familiar notation Rn\mathbb R^nRn.

Cartesian products satisfy various basic properties. For example, the Cartesian product of two vector spaces is again a vector space, and the Cartesian product of two subspaces is isomorphic to their direct sum. We will not discuss these facts in detail here.

More generally, Cartesian products can be defined for arbitrary sets, not only vector spaces.

We can now define tensors in a simple way:

Tensor

A tensor of type (k,l)(k,l)(k,l) is a multilinear map defined on V∗k×Vl{V^*}^k\times V^lV∗k×Vl. Equivalently, a (k,l)(k,l)(k,l)-tensor is a multilinear map that takes kkk covectors and lll vectors as inputs, and outputs a real number.

note

You may wonder why the dual space is placed before the vector space. In fact, this is because we are considering the objects on which tensors act, i.e. the domain of the tensor. If we consider what a tensor actually is, we will find that the front becomes vectors and the back becomes covectors. Specifically, any tensor can be written as:

T=Tμ1⋯μkν1⋯νl eμ1⊗⋯⊗eμk⊗eν1⊗⋯⊗eνl,T = T^{\mu_1\cdots\mu_k}{}_{\nu_1\cdots\nu_l} \, e_{\mu_1} \otimes \cdots \otimes e_{\mu_k} \otimes e^{\nu_1} \otimes \cdots \otimes e^{\nu_l},T=Tμ1​⋯μk​ν1​⋯νl​​eμ1​​⊗⋯⊗eμk​​⊗eν1​⊗⋯⊗eνl​,

Here, {eμ}\{e_\mu\}{eμ​} is the basis of the vector space VVV, while {eν}\{e^\nu\}{eν} is the dual basis.

note

A covector maps a vector to a real number, while a vector may also be viewed as mapping a covector to a real number. Therefore, under our definition, covectors and vectors can be regarded as tensors of type (0,1)(0,1)(0,1) and (1,0)(1,0)(1,0) respectively. In particular, a scalar (real number) is called a (0,0)(0,0)(0,0)-tensor.

Tensor Operations​

Tensor Addition and Scalar Multiplication​

From the definition above, we can naturally define tensor addition and scalar multiplication:

  1. (T+S)(ω1,⋯ ,ωk;v1,⋯ ,vl)=T(ω1,⋯ ,ωk;v1,⋯ ,vl)+S(ω1,⋯ ,ωk;v1,⋯ ,vl),(T+S)(\omega^1,\cdots,\omega^k;v_1,\cdots,v_l)=T(\omega^1,\cdots,\omega^k;v_1,\cdots,v_l)+S(\omega^1,\cdots,\omega^k;v_1,\cdots,v_l),(T+S)(ω1,⋯,ωk;v1​,⋯,vl​)=T(ω1,⋯,ωk;v1​,⋯,vl​)+S(ω1,⋯,ωk;v1​,⋯,vl​),

  2. (αT)(ω1,⋯ ,ωk;v1,⋯ ,vl)=α⋅T(ω1,⋯ ,ωk;v1,⋯ ,vl).(\alpha T)(\omega^1,\cdots,\omega^k;v_1,\cdots,v_l)=\alpha\cdot T(\omega^1,\cdots,\omega^k;v_1,\cdots,v_l).(αT)(ω1,⋯,ωk;v1​,⋯,vl​)=α⋅T(ω1,⋯,ωk;v1​,⋯,vl​).

These definitions require tensors to have the same type in order to be added or subtracted. This is natural, since there is no meaningful way to add a matrix and a vector directly.

Under these operations, all tensors of type (k,l)(k,l)(k,l) naturally form a vector space, denoted by TV(k,l)\mathscr T_V(k,l)TV​(k,l).

If the base space VVV has dimension nnn, then

dim⁡TV(k,l)=nk+l.\dim \mathscr T_V(k,l)=n^{k+l}.dimTV​(k,l)=nk+l.

Although this formula looks obvious, proving it rigorously is somewhat tedious. Interested readers may try constructing an explicit basis using a basis {eμ}\{e_\mu\}{eμ​} of VVV together with its dual basis.

Tensor Product​

We begin with some motivation from matrices.

Consider the following fact:

[x1x2⋮xn][y1y2⋯yn]=[x1y1x1y2⋯x1ynx2y1x2y2⋯x2yn⋮⋮⋱⋮xny1xny2⋯xnyn].\begin{bmatrix} x^1\\x^2\\ \vdots \\ x^n \end{bmatrix} \begin{bmatrix} y_1&y_2&\cdots&y_n \end{bmatrix} = \begin{bmatrix} x^1y_1&x^1y_2&\cdots&x^1y_n \\ x^2y_1&x^2y_2&\cdots&x^2y_n \\ \vdots & \vdots & \ddots & \vdots \\ x^ny_1&x^ny_2&\cdots&x^ny_n \end{bmatrix}.​x1x2⋮xn​​[y1​​y2​​⋯​yn​​]=​x1y1​x2y1​⋮xny1​​x1y2​x2y2​⋮xny2​​⋯⋯⋱⋯​x1yn​x2yn​⋮xnyn​​​.

In other words, the tensor product of a (1,0)(1,0)(1,0)-tensor and a (0,1)(0,1)(0,1)-tensor is a (1,1)(1,1)(1,1)-tensor.

Of course, the definition of tensor product itself does not depend on matrices. This motivates the following formal definition.

Tensor Product

Let TTT be a tensor of type (k,l)(k,l)(k,l) and SSS be a tensor of type (k′,l′)(k',l')(k′,l′). Their tensor product is defined to be a tensor of type (k+k′,l+l′)(k+k',l+l')(k+k′,l+l′):

(T⊗S)(ω1,⋯ ,ωk,ωk+1,⋯ ,ωk+k′;v1,⋯ ,vl,vl+1,⋯ ,vl+l′):=  T(ω1,⋯ ,ωk;v1,⋯ ,vl) S(ωk+1,⋯ ,ωk+k′;vl+1,⋯ ,vl+l′).\begin{aligned} &(T\otimes S)(\omega^1,\cdots,\omega^k,\omega^{k+1},\cdots,\omega^{k+k'};v_1,\cdots,v_l,v_{l+1},\cdots,v_{l+l'}) \\ :=\;& T(\omega^1,\cdots,\omega^k;v_1,\cdots,v_l)\, S(\omega^{k+1},\cdots,\omega^{k+k'};v_{l+1},\cdots,v_{l+l'}). \end{aligned}:=​(T⊗S)(ω1,⋯,ωk,ωk+1,⋯,ωk+k′;v1​,⋯,vl​,vl+1​,⋯,vl+l′​)T(ω1,⋯,ωk;v1​,⋯,vl​)S(ωk+1,⋯,ωk+k′;vl+1​,⋯,vl+l′​).​

Although this expression looks intimidating, the idea is simple: feed the first group of arguments into TTT, the second group into SSS, and multiply the resulting real numbers.

Note that tensor products are generally not commutative, since the order of vector and covector inputs matters.

note

There is a special case: the tensor product of a vector and a covector may be rearranged without ambiguity, since each contributes only one slot.

For example,

(eμ⊗eν)⊗(eρ⊗eσ)=eμ⊗eν⊗eρ⊗eσ≡eμ⊗eρ⊗eσ⊗eν.(e_\mu\otimes e^\nu)\otimes(e_\rho\otimes e_\sigma) = e_\mu\otimes e^\nu\otimes e_\rho\otimes e_\sigma \equiv e_\mu\otimes e_\rho\otimes e_\sigma\otimes e^\nu.(eμ​⊗eν)⊗(eρ​⊗eσ​)=eμ​⊗eν⊗eρ​⊗eσ​≡eμ​⊗eρ​⊗eσ​⊗eν.

This is why we may naturally regard the result of tensoring a (k,l)(k,l)(k,l)-tensor and a (k′,l′)(k',l')(k′,l′)-tensor as a (k+k′,l+l′)(k+k',l+l')(k+k′,l+l′)-tensor rather than something strange, say (k,l;k′,l′)(k, l; k', l')(k,l;k′,l′) or other things.

Addition and scalar multiplication interact naturally with tensor products:

  1. T⊗S+T′⊗S=(T+T′)⊗S,T\otimes S + T'\otimes S = (T+T')\otimes S,T⊗S+T′⊗S=(T+T′)⊗S,

  2. T⊗S+T⊗S′=T⊗(S+S′),T\otimes S + T\otimes S' = T\otimes(S+S'),T⊗S+T⊗S′=T⊗(S+S′),

  3. α(T⊗S)=(αT)⊗S=T⊗(αS).\alpha(T\otimes S) = (\alpha T)\otimes S = T\otimes(\alpha S).α(T⊗S)=(αT)⊗S=T⊗(αS).

Tensor Product of Spaces

The tensor product also naturally induces a new vector space:

V⊗W:={v⊗w∣v∈V, w∈W}.V\otimes W := \{v\otimes w\mid v\in V,\ w\in W\}.V⊗W:={v⊗w∣v∈V, w∈W}.

If dim⁡V=m\dim V=mdimV=m and dim⁡W=n\dim W=ndimW=n, then dim⁡(V⊗W)=mn.\dim(V\otimes W)=mn.dim(V⊗W)=mn. We omit the proof of this fact.

note

For a tensor product generating a (1,1)(1,1)(1,1)-tensor, we have

A=v⊗ω=(vμeμ)⊗(ωνeν)=vμων eμ⊗eν.A=v\otimes\omega = (v^\mu e_\mu)\otimes(\omega_\nu e^\nu) = v^\mu\omega_\nu\,e_\mu\otimes e^\nu.A=v⊗ω=(vμeμ​)⊗(ων​eν)=vμων​eμ​⊗eν.

Define

Aμν:=vμων.A^\mu{}_\nu:=v^\mu\omega_\nu.Aμν​:=vμων​.

These are precisely the components of a matrix.

Of course, not every tensor can be written as a single tensor product of this form. In general, one needs linear combinations of such elementary tensors.

note

Mathematicians often prefer a more abstract definition of tensor product using a universal property.

Given any bilinear map

f:V×W→R,f:V\times W\to\mathbb R,f:V×W→R,

there exists a vector space UUU, a map g:V×W→Ug:V\times W\to Ug:V×W→U, and a linear map h:U→Rh:U\to\mathbb Rh:U→R such that

f=h∘g.f=h\circ g.f=h∘g.

Moreover, this factorization is universal in an appropriate sense.

We then define the tensor product space (up to isomorphism) by

V⊗W:=U.V\otimes W:=U.V⊗W:=U.

This definition is elegant but useless, ONLY Mathematicians CAN DO. It does not directly tell us how to construct the space. Since our focus is differential geometry and explicit computation, we only mention this viewpoint briefly.

Contraction​

We again begin with matrices. A matrix acts on a vector and produces another vector. In tensor language, this means that a (1,1)(1,1)(1,1)-tensor can combine with a (1,0)(1,0)(1,0)-tensor to produce a new (1,0)(1,0)(1,0)-tensor.

Write a matrix as A=Aμν eμ⊗eν,A=A^\mu{}_\nu\,e_\mu\otimes e^\nu,A=Aμν​eμ​⊗eν, which is a (1,1)(1,1)(1,1)-tensor. Now, let v=vρeρv=v^\rho e_\rhov=vρeρ​ be a vector, in linear algebra, matrix multiplication produces a new vector:

(Aμνvν)eμ=wμeμ.(A^\mu{}_\nu v^\nu)e_\mu = w^\mu e_\mu.(Aμν​vν)eμ​=wμeμ​.

This shows that after combining a matrix and a vector, one vector-covector pair is "eliminated", leaving only one vector basis. How does this happen?

Well, the most basic way to combine tensors is first to take their tensor product, therefore we consider:

A⊗v=Aμνvρ eμ⊗eν⊗eρ,A\otimes v = A^\mu{}_\nu v^\rho\, e_\mu\otimes e^\nu\otimes e_\rho,A⊗v=Aμν​vρeμ​⊗eν⊗eρ​,

which is a (2,1)(2,1)(2,1)-tensor, still not a vector. Hence we need one further operation: pair one upper index with one lower index and sum over them. This is what we call a contraction:

Contraction Operator

Define

Cji:TV(k,l)→TV(k−1,l−1),C^i_j:\mathscr T_V(k,l)\to\mathscr T_V(k-1,l-1),Cji​:TV​(k,l)→TV​(k−1,l−1),

which contracts the iii-th upper index with the jjj-th lower index.

Explicitly,

Cji(T)=T(⋅,…,eμ,…,⋅;⋅,…,eμ,…,⋅),C^i_j(T) = T(\cdot,\dots,e^\mu,\dots,\cdot;\cdot,\dots,e_\mu,\dots,\cdot),Cji​(T)=T(⋅,…,eμ,…,⋅;⋅,…,eμ​,…,⋅),

where eμe^\mueμ is inserted into the iii-th covector slot, eμe_\mueμ​ into the jjj-th vector slot, and we sum over μ\muμ. Equivalently, contraction uses the fact that eμ(eν)=δμνe^\mu(e_\nu)=\delta^\mu{}_\nueμ(eν​)=δμν​ to eliminate one upper-lower index pair.

Back to our matrix-vector example, we contract the tensor product:

C12(A⊗v)=C12(Aμνvρ eμ⊗eν⊗eρ).C^2_1(A\otimes v) = C^2_1\left( A^\mu{}_\nu v^\rho\, e_\mu\otimes e^\nu\otimes e_\rho \right).C12​(A⊗v)=C12​(Aμν​vρeμ​⊗eν⊗eρ​).

Contracting the second upper index with the first lower index gives

Aμνvνeμ,A^\mu{}_\nu v^\nu e_\mu,Aμν​vνeμ​,

which is exactly the expected result of matrix multiplication.

Thus, matrix multiplication is, in tensor language, tensor product + contraction. This idea generalizes to arbitrary tensors. Although in general, there is no unique multiplication rule between tensors, we can always first take tensor products, and then specify which pairs of upper and lower indices should be contracted. Different contraction choices usually lead to different results.

For example, in the same setting, we do a different contraction:

C11(A⊗v)=Aμμvνeν,C^1_1(A\otimes v)=A^\mu{}_\mu v^\nu e_\nu,C11​(A⊗v)=Aμμ​vνeν​,

which is simply gives the trace of the matrix times the vector, where the trace of a matrix is defined as:

tr(A)=Aμμ.\mathrm{tr}(A)=A^\mu{}_\mu.tr(A)=Aμμ​.

Thus, contraction can be understood as one of the most fundamental interaction rules between tensors: it lowers tensor rank by pairing an upper index with a lower index.

note

In practice, contractions are often not written explicitly. Under Einstein summation convention, repeated upper and lower indices automatically indicate contraction.

For example,

AμνvνA^\mu{}_\nu v^\nuAμν​vν

already implicitly contains a contraction.

note

Besides the explicit operator CjiC^i_jCji​, another common notation is insertion, noted as ι\iotaι. For a tensor T∈TV(k,l)T\in\mathscr T_V(k,l)T∈TV​(k,l) and a vector v∈Vv\in Vv∈V, insertion means plugging vvv into one slot of TTT. This is usually written as:

(ιvT)(ω1,⋯ ,ωk;v1,⋯ ,vl−1):=T(ω1,⋯ ,ωk;v1,⋯ ,vl−1,v).(\iota_v T)(\omega^1,\cdots,\omega^k;v_1,\cdots,v_{l-1}) := T(\omega^1,\cdots,\omega^k;v_1,\cdots,v_{l-1},v).(ιv​T)(ω1,⋯,ωk;v1​,⋯,vl−1​):=T(ω1,⋯,ωk;v1​,⋯,vl−1​,v).

Thus,

ιvT∈TV(k,l−1).\iota_v T\in\mathscr T_V(k,l-1).ιv​T∈TV​(k,l−1).

Similarly, for a covector ω∈V∗\omega\in V^*ω∈V∗, one may define ιωT∈TV(k−1,l).\iota_\omega T\in\mathscr T_V(k-1,l).ιω​T∈TV​(k−1,l).

Insertion may be viewed as a partial contraction: instead of summing over an upper-lower pair, we simply fix one input. For example,

ιvA=A(⋅;v),\iota_v A=A(\cdot;v),ιv​A=A(⋅;v),

which is a (1,0)(1,0)(1,0)-tensor, i.e. a vector. This is exactly matrix action in linear algebra: w=Av=ιvA.w=Av=\iota_v A.w=Av=ιv​A.
