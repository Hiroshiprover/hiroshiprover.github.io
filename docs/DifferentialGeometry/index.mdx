# 宝宝用微分几何与纤维丛

## 前言

众所周知：数学、物理的教材、笔记或讲义等内容，都有一种刻意把内容写的晦涩难懂的传统。这种刻意擦除思考痕迹，而只留下精妙的结果的传统在入门者与数理知识之间建立起了一层深深的厚障壁。这种体会在我尝试自学微分几何、广义相对论、纤维丛与规范理论的时候尤为明显。

出于这种心态，我开始了这篇笔记的写作，尝试用更加基础、简单的语言，把微分几何与纤维丛中抽象凝练的形式语言重新表述，旨在重建前人擦干净的思考痕迹，并对一些难以理解的概念提供一些直觉性的引导。

> 在学习的过程中，笔者发现自己也逐渐失去了用人话表述一些内容的能力，这或许是一种知识的污染吧。也许教材不是故意写的晦涩难懂的。

本文在写作时主要参考了这三篇内容：

- 梁灿彬，周彬，《微分几何与广义相对论》；
- [一文入门微分几何（物理人版）](https://zhuanlan.zhihu.com/p/629852598)；
- [纤维丛，联络和贝里相位](https://switefaster.github.io/blog/fibre-bundle/)。
