J. 一对极点与两种传播子

推迟响应和编时关联在时间上的定义已经确定了两个极点从实轴的哪一侧逼近。现在倒过来，从极点恢复时间依赖。固定 p⃗\vec pp​，记 ω=p⃗ 2+m2\omega=\sqrt{\vec p^{\,2}+m^2}ω=p​2+m2​。两个传播子的分母都能拆成一次因子，只需先算出一个极点的贡献。
