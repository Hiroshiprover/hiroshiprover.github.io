Lorentz 群的数学补充

对应 02 §2–5。返回正文。Lorentz 矩阵满足 ΛTgΛ=g\Lambda^Tg\Lambda=gΛTgΛ=g。下面补充群结构、连通分支及无穷小变换的计算，主线只使用其变换规则。

1. Lorentz 群​

所有可能的洛伦兹变换组成 Lorentz 群 O(3,1)O(3,1)O(3,1)，其中 333 和 111 对应度规的三个正号、一个负号。我们验证其群结构。

单位元为：

Λμν=δμν,x′μ=xμ.\Lambda^\mu{}_\nu=\delta^\mu{}_\nu,\qquad x'^\mu=x^\mu.Λμν​=δμν​,x′μ=xμ.

这里 δμν\delta^\mu{}_\nuδμν​ 是 Kronecker δ\deltaδ。

其次，连续做两个 Lorentz 变换，结果仍然是 Lorentz 变换。若先做 Λ1\Lambda_1Λ1​，再做 Λ2\Lambda_2Λ2​，总变换为 Λ2Λ1\Lambda_2\Lambda_1Λ2​Λ1​，并且

(Λ2Λ1)Tg(Λ2Λ1)=Λ1TΛ2TgΛ2Λ1=Λ1TgΛ1=g.(\Lambda_2\Lambda_1)^Tg(\Lambda_2\Lambda_1) =\Lambda_1^T\Lambda_2^Tg\Lambda_2\Lambda_1 =\Lambda_1^Tg\Lambda_1=g.(Λ2​Λ1​)Tg(Λ2​Λ1​)=Λ1T​Λ2T​gΛ2​Λ1​=Λ1T​gΛ1​=g.

对于逆元，由 ΛTgΛ=g\Lambda^Tg\Lambda=gΛTgΛ=g，左乘 g−1g^{-1}g−1，得到

(g−1ΛTg)Λ=I,(g^{-1}\Lambda^Tg)\Lambda=I,(g−1ΛTg)Λ=I,

所以逆变换为

Λ−1=g−1ΛTg.\Lambda^{-1}=g^{-1}\Lambda^Tg.Λ−1=g−1ΛTg.

把 ΛTgΛ=g\Lambda^Tg\Lambda=gΛTgΛ=g 两边分别左乘 (Λ−1)T(\Lambda^{-1})^T(Λ−1)T、右乘 Λ−1\Lambda^{-1}Λ−1，也得到

(Λ−1)TgΛ−1=g.(\Lambda^{-1})^Tg\Lambda^{-1}=g.(Λ−1)TgΛ−1=g.

因此逆变换本身也是 Lorentz 变换。再加上矩阵乘法本来就满足结合律，这些变换就组成了群。

2. Lorentz 群的结构​

行列式：proper 与 improper​

对 ΛTgΛ=g\Lambda^Tg\Lambda=gΛTgΛ=g 两边取行列式，

(det⁡Λ)2det⁡g=det⁡g⟹det⁡Λ=±1.(\det\Lambda)^2\det g=\det g \quad\Longrightarrow\quad \det\Lambda=\pm1.(detΛ)2detg=detg⟹detΛ=±1.

我们称 det⁡Λ=+1\det\Lambda=+1detΛ=+1 的变换为 proper（正）Lorentz 变换，det⁡Λ=−1\det\Lambda=-1detΛ=−1 的为 improper（非正）Lorentz 变换。正 Lorentz 变换组成子群：

SO(3,1)={Λ∈O(3,1)∣det⁡Λ=1}.SO(3,1)=\{\Lambda\in O(3,1)\mid\det\Lambda=1\}.SO(3,1)={Λ∈O(3,1)∣detΛ=1}.

这是因为单位元的行列式为 111，两个行列式为 111 的矩阵相乘或取逆后，行列式仍为 111。

时间方向：orthochronous 与 non-orthochronous​

在 Lorentz 条件

gμνΛμρΛνσ=gρσg_{\mu\nu}\Lambda^\mu{}_\rho\Lambda^\nu{}_\sigma=g_{\rho\sigma}gμν​Λμρ​Λνσ​=gρσ​

中取 ρ=σ=0\rho=\sigma=0ρ=σ=0，得到

−(Λ00)2+δijΛi0Λj0=−1.-(\Lambda^0{}_0)^2+\delta_{ij}\Lambda^i{}_0\Lambda^j{}_0=-1.−(Λ00​)2+δij​Λi0​Λj0​=−1.

因此

(Λ00)2=1+∑i=13(Λi0)2≥1,(\Lambda^0{}_0)^2 =1+\sum_{i=1}^{3}(\Lambda^i{}_0)^2\ge1,(Λ00​)2=1+i=1∑3​(Λi0​)2≥1,

也就是

Λ00≥1或Λ00≤−1.\Lambda^0{}_0\ge1 \qquad\text{或}\qquad \Lambda^0{}_0\le-1.Λ00​≥1或Λ00​≤−1.

前者称为 orthochronous（保时向）变换，它保持未来指向的类时矢量仍然指向未来；后者则反转这个时间方向。保时向变换组成子群 O+(3,1)O^+(3,1)O+(3,1)。

同时满足 proper 与 orthochronous 的变换组成

SO+(3,1)={Λ∈O(3,1)∣det⁡Λ=1, Λ00≥1},SO^+(3,1) =\{\Lambda\in O(3,1)\mid \det\Lambda=1,\ \Lambda^0{}_0\ge1\},SO+(3,1)={Λ∈O(3,1)∣detΛ=1, Λ00​≥1},

称为正保时 Lorentz 群，它是 O(3,1)O(3,1)O(3,1) 中包含单位元的连通分支。在我们的课程中提到 Lorentz 群时，一般指的都是 SO+(3,1)SO^+(3, 1)SO+(3,1)，而不是整个 O(3,1)O(3, 1)O(3,1)。

完整 Poincaré 群还包括四维平移，其 Lorentz 部分可以取整个 O(3,1)O(3,1)O(3,1)；正文讨论连续生成元时，只取 SO+(3,1)SO^+(3,1)SO+(3,1) 与平移组成的单位元连通分支。

3. Lorentz 群的李代数​

考虑单位元附近的 Lorentz 变换：

Λμν=δμν+ϵΩμν,\Lambda^\mu{}_\nu =\delta^\mu{}_\nu+\epsilon\Omega^\mu{}_\nu,Λμν​=δμν​+ϵΩμν​,

其中 ϵ\epsilonϵ 是无穷小参数。很容易注意到：

(I−ϵΩ)(I+ϵΩ)=I+O(ϵ2),(I-\epsilon\Omega)(I+\epsilon\Omega) =I+O(\epsilon^2),(I−ϵΩ)(I+ϵΩ)=I+O(ϵ2),

因此其逆（在保留到一阶小量的意义下）为：

(Λ−1)μν=δμν−ϵΩμν.(\Lambda^{-1})^\mu{}_\nu =\delta^\mu{}_\nu-\epsilon\Omega^\mu{}_\nu.(Λ−1)μν​=δμν​−ϵΩμν​.

现在降低 Λ\LambdaΛ 的第一个指标：

Λμν=gμν+ϵΩμν,Ωμν≡gμρΩρν.\Lambda_{\mu\nu}=g_{\mu\nu}+\epsilon\Omega_{\mu\nu}, \qquad \Omega_{\mu\nu}\equiv g_{\mu\rho}\Omega^\rho{}_\nu.Λμν​=gμν​+ϵΩμν​,Ωμν​≡gμρ​Ωρν​.

考虑到 Λμν=(Λ−1)νμ\Lambda_\mu{}^\nu=(\Lambda^{-1})^\nu{}_\muΛμ​ν=(Λ−1)νμ​，再降低 ν\nuν，有

Λμν=(Λ−1)νμ,\Lambda_{\mu\nu}=(\Lambda^{-1})_{\nu\mu},Λμν​=(Λ−1)νμ​,

代入展开式，

gμν+ϵΩμν=gνμ−ϵΩνμ.g_{\mu\nu}+\epsilon\Omega_{\mu\nu} =g_{\nu\mu}-\epsilon\Omega_{\nu\mu}.gμν​+ϵΩμν​=gνμ​−ϵΩνμ​.

由于度规对称，得到

Ωμν=−Ωνμ.\Omega_{\mu\nu}=-\Omega_{\nu\mu}.Ωμν​=−Ωνμ​.

也就是说，Ωμν\Omega_{\mu\nu}Ωμν​ 是一个反对称矩阵（注意：不是 Ωμν\Omega^\mu{}_\nuΩμν​ 本身）。一个 4×44\times44×4 反对称矩阵只有 666 个独立分量，因此 Lorentz 群有六个连续参数。其中 Ωij\Omega_{ij}Ωij​ 的三个独立分量对应空间旋转，Ω0i\Omega_{0i}Ω0i​ 的三个分量对应三个空间方向上的 boost。这给定了 Lorentz 群的生成元。原则上，利用指数映射与生成元可以得到单位元附近的群元素。

除了与单位元连续相连的变换，我们还需要两个离散变换来描述整个 Lorentz 群：

Pμν=diag⁡(1,−1,−1,−1),Tμν=diag⁡(−1,1,1,1).P^\mu{}_\nu=\operatorname{diag}(1,-1,-1,-1), \qquad T^\mu{}_\nu=\operatorname{diag}(-1,1,1,1).Pμν​=diag(1,−1,−1,−1),Tμν​=diag(−1,1,1,1).

PPP 是空间反演（parity），将 (t,x⃗)(t,\vec{x})(t,x) 变成 (t,−x⃗)(t,-\vec{x})(t,−x)；TTT 是时间反演（time reversal），将 (t,x⃗)(t,\vec{x})(t,x) 变成 (−t,x⃗)(-t,\vec{x})(−t,x)。

它们都满足 Lorentz 条件，但 det⁡P=det⁡T=−1\det P=\det T=-1detP=detT=−1。PPP 保时向，TTT 不保时向，而 PT=−IPT=-IPT=−I 的行列式为 +1+1+1，却不保时向。完整 Lorentz 群的四个连通分支可以写成：

SO+(3,1),P SO+(3,1),T SO+(3,1),PT SO+(3,1).SO^+(3,1),\qquad P\,SO^+(3,1),\qquad T\,SO^+(3,1),\qquad PT\,SO^+(3,1).SO+(3,1),PSO+(3,1),TSO+(3,1),PTSO+(3,1).

4. 指标变换与张量例子​

Lorentz 条件还给出升降指标后变换矩阵与逆矩阵的关系：

Λμν≡gμρΛρσgσν=(Λ−1)νμ.\Lambda_\mu{}^\nu\equiv g_{\mu\rho}\Lambda^\rho{}_\sigma g^{\sigma\nu} =(\Lambda^{-1})^\nu{}_\mu.Λμ​ν≡gμρ​Λρσ​gσν=(Λ−1)νμ​.

因此对同一事件，逆变矢量 VμV^\muVμ 和协变矢量 WμW_\muWμ​ 的缩并保持不变：

V′μ(x′)Wμ′(x′)=Vμ(x)Wμ(x).V'^\mu(x')W'_\mu(x')=V^\mu(x)W_\mu(x).V′μ(x′)Wμ′​(x′)=Vμ(x)Wμ​(x).

更高阶张量的每个上指标各乘一个 Λ\LambdaΛ，每个下指标各乘一个 Λμν\Lambda_\mu{}^\nuΛμ​ν。例如：

D′μνρστ(x′)=ΛμαΛνβΛργΛσδΛτϵDαβγδϵ(x).D'^{\mu\nu}{}_{\rho\sigma\tau}(x') =\Lambda^\mu{}_\alpha\Lambda^\nu{}_\beta \Lambda_\rho{}^\gamma\Lambda_\sigma{}^\delta \Lambda_\tau{}^\epsilon D^{\alpha\beta}{}_{\gamma\delta\epsilon}(x).D′μνρστ​(x′)=Λμα​Λνβ​Λρ​γΛσ​δΛτ​ϵDαβγδϵ​(x).

5. 加入平移：Poincaré 变换​

本章仍将 Lorentz 部分限于与恒等变换连续相连的正保时分支。加上平移后，得到这里使用的连续 Poincaré 变换：

x′μ=Λμνxν+cμ,x'^\mu=\Lambda^\mu{}_\nu x^\nu+c^\mu,x′μ=Λμν​xν+cμ,

其中 cμc^\mucμ 是常矢量。先施加 (Λ1,c1)(\Lambda_1,c_1)(Λ1​,c1​)、再施加 (Λ2,c2)(\Lambda_2,c_2)(Λ2​,c2​)，合成变换为

(Λ2,c2)(Λ1,c1)=(Λ2Λ1, Λ2c1+c2).(\Lambda_2,c_2)(\Lambda_1,c_1) =(\Lambda_2\Lambda_1,\,\Lambda_2c_1+c_2).(Λ2​,c2​)(Λ1​,c1​)=(Λ2​Λ1​,Λ2​c1​+c2​).

第一段平移也要受第二次 Lorentz 变换作用，因而总平移一般不是 c1+c2c_1+c_2c1​+c2​。本章建立了场在时空变换下的规则；具体运动方程还需由动力学原理给出。
