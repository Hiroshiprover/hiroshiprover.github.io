H. 从 Fock 态回到多体波函数

在粒子态的讨论中，我们用产生算符叠出任意多个相同的玻色子。以前学过的 NNN 体波函数藏在这个态的什么地方？如果只看低动量的粒子，还应当能从自由场的能量还原熟悉的多体 Schrödinger 方程。

位置表象与多粒子波函数​

[a(x⃗),a†(y⃗)]=∫p⃗,q⃗eip⃗⋅x⃗−iq⃗⋅y⃗(2π)3δ(3)(p⃗−q⃗)=δ(3)(x⃗−y⃗).[a(\vec x),a^\dagger(\vec y)] =\int_{\vec p,\vec q} e^{\ii\vec p\cdot\vec x-\ii\vec q\cdot\vec y} (2\pi)^3\delta^{(3)}(\vec p-\vec q) =\delta^{(3)}(\vec x-\vec y).[a(x),a†(y​)]=∫p​,q​​eip​⋅x−iq​⋅y​(2π)3δ(3)(p​−q​)=δ(3)(x−y​).
