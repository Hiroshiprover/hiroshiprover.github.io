M. 三次理论的散射计算

按动量空间的图规则，每个内部顶点都守恒四动量。对四条外腿的树图，这已经确定了内部线动量，出射方向仍要在计数时积分。多接一条外腿并让顶点围成一圈，就还要为圈内未定的动量积分。这是两种不同来源的积分。
