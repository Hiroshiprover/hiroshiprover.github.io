从作用量原理到自由场论

我们现在尝试从作用量原理出发，推导出自由场论的拉格朗日密度形式。

回忆前面推导 Euler–Lagrange 方程时使用的变分方法。给定一个场 ϕ0(x)\phi_0(x)ϕ0​(x)，我们考虑它附近的一族场：

ϕε(x)=ϕ0(x)+εη(x),\phi_\varepsilon(x)=\phi_0(x)+\varepsilon\eta(x),ϕε​(x)=ϕ0​(x)+εη(x),

其中 η(x)\eta(x)η(x) 是任意满足适当边界条件的光滑函数，ε∈R\varepsilon\in\mathbb Rε∈R 是一个参数。 我们研究当 ε\varepsilonε 足够小时，作用量对应的变化。

为了方便，我们可以定义一个关于 ε\varepsilonε 的普通函数：

f(ε)≡S[ϕε]=S[ϕ0+εη].f(\varepsilon)\equiv S[\phi_\varepsilon] =S[\phi_0+\varepsilon\eta].f(ε)≡S[ϕε​]=S[ϕ0​+εη].

假设作用量在我们考虑的场构型附近足够光滑，并且允许交换展开与积分，那么就可以直接对 f(ε)f(\varepsilon)f(ε) 进行 Taylor 展开：

S[ϕ0+εη]=S[ϕ0]+εdS[ϕε]dε∣ε=0+ε22d2S[ϕε]dε2∣ε=0+O(ε3).S[\phi_0+\varepsilon\eta] =S[\phi_0] +\varepsilon\left.\frac{dS[\phi_\varepsilon]}{d\varepsilon}\right|_{\varepsilon=0} +\frac{\varepsilon^2}{2} \left.\frac{d^2S[\phi_\varepsilon]}{d\varepsilon^2}\right|_{\varepsilon=0} +O(\varepsilon^3).S[ϕ0​+εη]=S[ϕ0​]+εdεdS[ϕε​]​​ε=0​+2ε2​dε2d2S[ϕε​]​​ε=0​+O(ε3).

这只是 f(ε)f(\varepsilon)f(ε)的 Taylor 展开，并没有什么特别的。

一阶项​

零阶项显然只是原场的作用量。因此我们先考察展开中的一阶项。我们仍然假设拉格朗日密度只依赖于场及其一阶导数：

S[ϕ]=∫d4x L(ϕ,∂μϕ).S[\phi]=\int d^4x\,\mathcal L(\phi,\partial_\mu\phi).S[ϕ]=∫d4xL(ϕ,∂μ​ϕ).

由于

dϕεdε=η,d(∂μϕε)dε=∂μη,\frac{d\phi_\varepsilon}{d\varepsilon}=\eta, \qquad \frac{d(\partial_\mu\phi_\varepsilon)}{d\varepsilon} =\partial_\mu\eta,dεdϕε​​=η,dεd(∂μ​ϕε​)​=∂μ​η,

根据链式法则，我们有

dS[ϕε]dε=∫d4x [∂L∂ϕεη+∂L∂(∂μϕε)∂μη].\frac{dS[\phi_\varepsilon]}{d\varepsilon} =\int d^4x\,\bigg[ \frac{\partial\mathcal L}{\partial\phi_\varepsilon}\eta +\frac{\partial\mathcal L} {\partial(\partial_\mu\phi_\varepsilon)} \partial_\mu\eta \bigg].dεdS[ϕε​]​=∫d4x[∂ϕε​∂L​η+∂(∂μ​ϕε​)∂L​∂μ​η].

与我们推导 E-L 方程时一样，对第二项进行分部积分，并利用 η\etaη 在边界处为零的条件，就得到

dS[ϕε]dε∣ε=0=∫d4x [∂L∂ϕ−∂μ(∂L∂(∂μϕ))]ϕ=ϕ0η.\left.\frac{dS[\phi_\varepsilon]}{d\varepsilon}\right|_{\varepsilon=0} =\int d^4x\, \bigg[ \frac{\partial\mathcal L}{\partial\phi}-\partial_\mu\left(\frac{\partial\mathcal L}{\partial(\partial_\mu\phi)}\right) \bigg]_{\phi=\phi_0}\eta.dεdS[ϕε​]​​ε=0​=∫d4x[∂ϕ∂L​−∂μ​(∂(∂μ​ϕ)∂L​)]ϕ=ϕ0​​η.

我们还要求 ϕ0\phi_0ϕ0​ 本身满足 E-L 方程，那么

[∂L∂ϕ−∂μ(∂L∂(∂μϕ))]ϕ0=0.\left[ \frac{\partial\mathcal L}{\partial\phi} -\partial_\mu\left( \frac{\partial\mathcal L} {\partial(\partial_\mu\phi)} \right) \right]_{\phi_0}=0.[∂ϕ∂L​−∂μ​(∂(∂μ​ϕ)∂L​)]ϕ0​​=0.

因此，

dS[ϕε]dε∣ε=0=0.\left.\frac{dS[\phi_\varepsilon]}{d\varepsilon}\right|_{\varepsilon=0}=0.dεdS[ϕε​]​​ε=0​=0.

于是，作用量的 Taylor 展开就简化为

S[ϕ0+εη]=S[ϕ0]+ε22d2S[ϕε]dε2∣ε=0+O(ε3).S[\phi_0+\varepsilon\eta] =S[\phi_0] +\frac{\varepsilon^2}{2} \left.\frac{d^2S[\phi_\varepsilon]}{d\varepsilon^2}\right|_{\varepsilon=0} +O(\varepsilon^3).S[ϕ0​+εη]=S[ϕ0​]+2ε2​dε2d2S[ϕε​]​​ε=0​+O(ε3).

这意味着，在一个经典运动方程的解附近，作用量关于扰动的一阶变化为零，最低阶的非平凡变化通常来自二次项。这个结果并不令人意外，毕竟我们要求了最小作用量原理。不过，截止到这里，我们得到的还只是关于参数 ε\varepsilonε 的二次项。它和正文中讨论的关于场的二次型拉格朗日密度有什么关系？我们继续进行计算。

二阶项​

对作用量再求一次关于 ε\varepsilonε 的导数，并在 ε=0\varepsilon=0ε=0 处取值，就有

d2S[ϕε]dε2∣ε=0=∫d4x [∂2L∂ϕ2η2+2∂2L∂ϕ ∂(∂μϕ)η∂μη+∂2L∂(∂μϕ)∂(∂νϕ)∂μη∂νη]ϕ=ϕ0.\left.\frac{d^2S[\phi_\varepsilon]}{d\varepsilon^2}\right|_{\varepsilon=0} =\int d^4x\, \bigg[ \frac{\partial^2\mathcal L}{\partial\phi^2}\eta^2 +2\frac{\partial^2\mathcal L} {\partial\phi\,\partial(\partial_\mu\phi)} \eta\partial_\mu\eta +\frac{\partial^2\mathcal L} {\partial(\partial_\mu\phi)\partial(\partial_\nu\phi)} \partial_\mu\eta\partial_\nu\eta \bigg]_{\phi=\phi_0}.dε2d2S[ϕε​]​​ε=0​=∫d4x[∂ϕ2∂2L​η2+2∂ϕ∂(∂μ​ϕ)∂2L​η∂μ​η+∂(∂μ​ϕ)∂(∂ν​ϕ)∂2L​∂μ​η∂ν​η]ϕ=ϕ0​​.

这里默认对重复的指标求和。尽管这个表达式看起来稍微复杂了一些，但仔细观察就可以发现，其中全都只是 η\etaη 的二次项：

η2,η∂μη,∂μη∂νη.\eta^2,\qquad \eta\partial_\mu\eta,\qquad \partial_\mu\eta\partial_\nu\eta.η2,η∂μ​η,∂μ​η∂ν​η.

前面的偏导数已经在 ϕ=ϕ0\phi=\phi_0ϕ=ϕ0​ 处取值了，只是一些系数。因此，我们将其打包为一个新的拉格朗日密度：

L(2)[η]=12[∂2L∂ϕ2η2+2∂2L∂ϕ ∂(∂μϕ)η∂μη+∂2L∂(∂μϕ)∂(∂νϕ)∂μη∂νη]ϕ=ϕ0.\mathcal L^{(2)}[\eta] =\frac12\bigg[ \frac{\partial^2\mathcal L}{\partial\phi^2}\eta^2+2\frac{\partial^2\mathcal L} {\partial\phi\,\partial(\partial_\mu\phi)} \eta\partial_\mu\eta+\frac{\partial^2\mathcal L} {\partial(\partial_\mu\phi)\partial(\partial_\nu\phi)} \partial_\mu\eta\partial_\nu\eta \bigg]_{\phi=\phi_0}.L(2)[η]=21​[∂ϕ2∂2L​η2+2∂ϕ∂(∂μ​ϕ)∂2L​η∂μ​η+∂(∂μ​ϕ)∂(∂ν​ϕ)∂2L​∂μ​η∂ν​η]ϕ=ϕ0​​.

这样，原来的作用量就可以写成

S[ϕ0+εη]=S[ϕ0]+ε2∫d4x L(2)[η]+O(ε3).S[\phi_0+\varepsilon\eta] =S[\phi_0] +\varepsilon^2\int d^4x\,\mathcal L^{(2)}[\eta] +O(\varepsilon^3).S[ϕ0​+εη]=S[ϕ0​]+ε2∫d4xL(2)[η]+O(ε3).

由于 L(2)\mathcal L^{(2)}L(2) 是关于扰动场及其导数的齐次二次表达式，因而满足

L(2)[εη]=ε2L(2)[η],\mathcal L^{(2)}[\varepsilon\eta] =\varepsilon^2\mathcal L^{(2)}[\eta],L(2)[εη]=ε2L(2)[η],

因此我们可以将 εη\varepsilon\etaεη 整体视为一个新的场：

S[ϕ0+εη]=S[ϕ0]+S(2)[εη]+O(ε3).S[\phi_0+\varepsilon\eta] = S[\phi_0] + S^{(2)}[\varepsilon\eta] + O(\varepsilon^3).S[ϕ0​+εη]=S[ϕ0​]+S(2)[εη]+O(ε3).

于是，当我们只保留二次近似时，就可以直接研究 L(2)\mathcal L^{(2)}L(2)。ε\varepsilonε 本身只是一种标记，它标识着我们的近似是第几阶的。

这就解释了为什么二次型的拉格朗日密度会出现在自由场论中：它其实是原场在微扰下的、最低阶的非零近似。由于 L(2)\mathcal L^{(2)}L(2) 关于扰动场及其导数是二次的，它对应的 E-L 方程就是线性的。因此，不同的扰动满足线性叠加原理，与正文中的讨论完全一致。

不过，虽然我们得到的运动方程是线性的，但如果原场 ϕ0(x)\phi_0(x)ϕ0​(x) 不是常数场，那么 L(2)\mathcal L^{(2)}L(2) 中的系数一般也会依赖于 xxx。此时，理论未必具有时空平移不变性。

自由实标量场​

最后我们来看看以上推导如何与正文中构造的拉格朗日密度联系起来。假设原来的理论满足 Lorentz 不变性和时空平移不变性，并且我们选取的经典背景是一个常数场：

ϕ0(x)=ϕ0.\phi_0(x)=\phi_0.ϕ0​(x)=ϕ0​.

由于 ϕ0\phi_0ϕ0​ 是常数，它的所有导数都为零。因此，L[ϕ0(x),∂μϕ0(x)]=L(ϕ0,0)\mathcal{L}[\phi_0(x), \partial_\mu \phi_0(x)]=\mathcal{L}(\phi_0, 0)L[ϕ0​(x),∂μ​ϕ0​(x)]=L(ϕ0​,0)，也就是一个函数在固定点处的取值，其 Taylor 展开的各项系数（也就是前文那三个偏导数）一定都是常数。进一步地，由于 ϕ0\phi_0ϕ0​ 本身是一个 Lorentz 标量，因此这些系数也应具有 Lorentz 不变性。

回忆刚才得到的三种二次项：

η2,η∂μη,∂μη∂νη.\eta^2,\qquad \eta\partial_\mu\eta,\qquad \partial_\mu\eta\partial_\nu\eta.η2,η∂μ​η,∂μ​η∂ν​η.

其中，第一项本身就是 Lorentz 标量。

第二项带有一个自由的 Lorentz 指标。正如我们正文讨论的那样，我们无法用一个非零的 Lorentz 不变系数将它收缩成标量，我们就只能舍去这一项。即使人为引入一个常矢量（破坏 Lorentz 不变性）作为系数，这一项也只会贡献一个全微分。

至于第三项，我们可以利用 Minkowski 度规收缩两个指标，得到

∂μη∂μη.\partial_\mu\eta\partial^\mu\eta.∂μ​η∂μη.

你也可以认为是前面的偏导数应只是度规的常数倍。

因此满足我们正文限制的、并且二次近似下的拉格朗日密度只能具有如下形式：

L(2)[η]=a ∂μη∂μη+bη2,\mathcal L^{(2)}[\eta] =a\,\partial_\mu\eta\partial^\mu\eta +b\eta^2,L(2)[η]=a∂μ​η∂μη+bη2,

其中 a,ba,ba,b 是实常数。这恰好就是正文中构造的自由实标量场拉格朗日密度！

不过，与正文中最初考虑的一般二次型相比，这里没有出现 cηc\etacη 这样的线性项。原因是我们要求 ϕ0\phi_0ϕ0​ 本身就是 E-L 方程的解，此时作用量的一阶变分必然为零。在正文中我们并没有这个要求，所以才允许拉格朗日密度包含 cϕc\phicϕ。而后面通过场的重定义消去这一项，就是对应这里选取一个满足运动方程的常数场。

为了更直观地理解这个结果，我们还可以考虑一个具体的例子。假设原来的拉格朗日密度为

L=−12∂μϕ∂μϕ−12m2ϕ2−λ4!ϕ4.\mathcal L =-\frac12\partial_\mu\phi\partial^\mu\phi -\frac12m^2\phi^2 -\frac{\lambda}{4!}\phi^4.L=−21​∂μ​ϕ∂μϕ−21​m2ϕ2−4!λ​ϕ4.

其中最后一项描述了场与自身的相互作用。显然，ϕ0=0\phi_0=0ϕ0​=0 是一个满足 E-L 方程的常数背景。因此我们取 ϕε=εη\phi_\varepsilon=\varepsilon\etaϕε​=εη，代入原来的拉格朗日密度：

L[ϕε]=−ε22∂μη∂μη−ε22m2η2−ε4λ4!η4.\mathcal L[\phi_\varepsilon] =-\frac{\varepsilon^2}{2} \partial_\mu\eta\partial^\mu\eta -\frac{\varepsilon^2}{2}m^2\eta^2 -\frac{\varepsilon^4\lambda}{4!}\eta^4.L[ϕε​]=−2ε2​∂μ​η∂μη−2ε2​m2η2−4!ε4λ​η4.

可以看到，原来的四次相互作用项直到 ε4\varepsilon^4ε4 阶才会出现。因此，如果我们只保留到 ε2\varepsilon^2ε2 阶，得到的就是

L(2)=−12∂μη∂μη−12m2η2.\mathcal L^{(2)} =-\frac12\partial_\mu\eta\partial^\mu\eta -\frac12m^2\eta^2.L(2)=−21​∂μ​η∂μη−21​m2η2.

这正是自由实标量场的标准拉格朗日密度。

当然，当扰动逐渐增大时，更高阶的项就可能变得不可忽略，二次近似也会随之失效。因此，自由场论既可以作为一个独立的理论，也可以作为研究一般相互作用场论时的最低阶近似。

最后还有一点值得强调：我们在整个推导过程中，只要求背景场 ϕ0\phi_0ϕ0​ 是作用量的驻点，并没有要求它是稳定的。一个不稳定的经典解同样可以作为展开点，它附近的二次型理论也同样具有线性运动方程。只不过，此时某些微小扰动可能随时间指数增长，使得二次近似只能在有限的时间范围内适用。这正是我们在正文中讨论的快子不稳定性的一种来源。
