经典场论（0）：场与 Lorentz 变换

1. 为什么要引入场​

我们借助一个 toy model 来引入场的概念。考虑一个 NNN 粒子、长度为 lll 的一维单原子晶体，晶格常数为 aaa。粒子之间用弹簧相互连接，劲度系数为 KKK。定义第 nnn 个粒子偏离平衡位置的位移为 un(t)u_n(t)un​(t)，并采用周期性边界条件 uN+1=u1u_{N+1} = u_1uN+1​=u1​，那么整个晶体的拉格朗日量就可以写作

L=T−V=∑n=1N12mu˙n2−12K(un+1−un)2.L = T - V = \sum_{n = 1}^{N} \frac{1}{2}m\dot{u}_n^2 - \frac{1}{2}K(u_{n+1}-u_{n})^2.L=T−V=n=1∑N​21​mu˙n2​−21​K(un+1​−un​)2.

不同于固体物理处理声子的方式，我们现在来考虑 N→∞N \to \inftyN→∞，同时 l=Na=constl = Na = \text{const}l=Na=const 的极限情况，此时 a→0a\to 0a→0，粒子均匀且稠密地分布在长度为 lll 的空间上。仿照热力学极限的思想，我们定义：

ρ=ma,k=Ka,\rho = \frac{m}{a}, \qquad k = Ka,ρ=am​,k=Ka,

并要求它们在 a→0a\to 0a→0 时都存在极限，这是为了避免密度和势能发散。现在我们重写拉格朗日量：

L=∑n=1Na[12ρu˙n2−12k(un+1−una)2],L = \sum_{n = 1}^{N}a\left[ \frac{1}{2}\rho\dot{u}_n^2 - \frac{1}{2}k\left(\frac{u_{n+1}-u_{n}}{a}\right)^2\right],L=n=1∑N​a[21​ρu˙n2​−21​k(aun+1​−un​​)2],

可以看到现在拉格朗日量具有一种黎曼和的形式。我们现在引入一个连续函数 ϕ(t,x)\phi(t, x)ϕ(t,x)，满足性质：

un=ϕ(t,na),u_n = \phi(t, na),un​=ϕ(t,na),

这是总可以做到的，只需要用拉格朗日插值就可以显式构造。现在令 a→0a\to 0a→0，记 xn=nax_n =naxn​=na，我们就有：

L=lim⁡a→0∑n=1Na[12ρ(∂tϕ(t,xn))2−12k(ϕ(t,xn+a)−ϕ(t,xn)a)2]=lim⁡a→0∑n=1Na[12ρ(∂tϕ(t,xn))2−12k(∂xϕ(t,xn))2]=∫0ldx 12ρ(∂tϕ)2−12k(∂xϕ)2,\begin{aligned} L &= \lim_{a\to 0} \sum_{n=1}^N a\left[ \frac{1}{2}\rho\left(\partial_t \phi(t, x_n)\right)^2 - \frac{1}{2}k\left(\frac{\phi(t, x_n + a)-\phi(t, x_n)}{a}\right)^2\right]\\ &=\lim_{a\to 0} \sum_{n=1}^N a\left[ \frac{1}{2}\rho\left(\partial_t \phi(t, x_n)\right)^2 - \frac{1}{2}k\left(\partial_x \phi(t, x_n)\right)^2\right]\\ &= \int_0^l dx\, \frac{1}{2}\rho\left(\partial_t \phi \right)^2 - \frac{1}{2}k\left(\partial_x \phi \right)^2, \end{aligned}L​=a→0lim​n=1∑N​a[21​ρ(∂t​ϕ(t,xn​))2−21​k(aϕ(t,xn​+a)−ϕ(t,xn​)​)2]=a→0lim​n=1∑N​a[21​ρ(∂t​ϕ(t,xn​))2−21​k(∂x​ϕ(t,xn​))2]=∫0l​dx21​ρ(∂t​ϕ)2−21​k(∂x​ϕ)2,​

这里第二个等号不算很严谨，它只在 ϕ\phiϕ 满足足够好的连续性条件时成立，不过对于物理考虑的问题而言不大。定义这块晶体的拉格朗日密度为：

L[ϕ]=12ρ(∂tϕ)2−12k(∂xϕ)2,\mathcal{L}[\phi] = \frac{1}{2}\rho\left(\partial_t \phi \right)^2 - \frac{1}{2}k\left(\partial_x \phi \right)^2,L[ϕ]=21​ρ(∂t​ϕ)2−21​k(∂x​ϕ)2,

于是这块晶体的拉格朗日量可以写作：

L=∫0ldx L[ϕ],L=\int_0^l dx\, \mathcal{L}[\phi],L=∫0l​dxL[ϕ],

更一般地，我们考虑三维空间，并且将积分区域扩展到全空间（如果系统分布在有限范围内，拉格朗日密度在系统范围之外取 000 即可）

L=∫d3x L[ϕ].L = \int d^3x\, \mathcal{L}[\phi].L=∫d3xL[ϕ].

可以看到，我们用 ϕ\phiϕ（的导数）确定了这块晶体的拉格朗日量，因此根据最小作用量原理，晶体的动力学将完全由这个 ϕ\phiϕ 决定。我们称 ϕ\phiϕ 为描述这个晶体的场。当然，这里的讨论目前都是非相对论的，但给出一个相对论性的拉格朗日密度并不困难，我们将在后面详细讨论。

这看起来只是一种符号游戏，但它给了我们一个很深刻的暗示：正如分析力学具有远胜于牛顿力学的泛用性与拓展性；场对于粒子与连续系统的动力学给出的描述，也远胜于经典的质点描述。形式上，我们每给出一个场，并给出拉格朗日密度的限制，就确定了一类粒子（系统）。

在对场的动力学进行更深刻的讨论之前，我们先来确定相对论对于我们使用的场的要求。

2. 时空坐标、度规与指标​

相对论习惯把时间和三个空间坐标合写为 xμ=(t,x⃗)x^\mu=(t,\vec x)xμ=(t,x)。在相对论的框架下，我们定义时空间隔：

ds2=−dt2+dx2+dy2+dz2,ds^2 = -dt^2 + dx^2 + dy^2 + dz^2,ds2=−dt2+dx2+dy2+dz2,

为了更方便地表述，我们引入度规1与爱因斯坦求和约定，将时空间隔写作：

ds2=gμνdxμdxν,gμν=diag⁡(−1,1,1,1).ds^2=g_{\mu\nu}dx^\mu dx^\nu,\qquad g_{\mu\nu}=\operatorname{diag}(-1,1,1,1).ds2=gμν​dxμdxν,gμν​=diag(−1,1,1,1).

其中希腊字母 μ,ν=0,1,2,3\mu, \nu = 0, 1, 2, 3μ,ν=0,1,2,3，000 代表时间，1,2,31, 2, 31,2,3 代表空间，重复的一个上指标和一个下指标表示求和。我们有时候也会用罗马字母 i,j,k=1,2,3i, j, k=1, 2, 3i,j,k=1,2,3 来代指空间坐标。

这里我们实际上是默认选取了笛卡尔坐标系来描述时空，实际上，我们有很多种坐标选取，它们之间可以通过一组坐标变换 x′μ=Λμνxνx'^\mu=\Lambda^\mu{}_\nu x^\nux′μ=Λμν​xν 联系起来。

对于惯性系而言，我们发现，这组坐标变换必须保持时空间隔不变：

gμνΛμρΛνσ=gρσ,或 ΛTgΛ=g.g_{\mu\nu} \Lambda^\mu{}_\rho \Lambda^\nu{}_\sigma = g_{\rho \sigma},\qquad \text{或}\, \Lambda^Tg\Lambda=g.gμν​Λμρ​Λνσ​=gρσ​,或ΛTgΛ=g.

我们还需要处理矢量与张量。在指标的语言下，我们有两种向量：VμV^\muVμ 称为逆变矢量、WνW_\nuWν​ 称为协变矢量，张量则是具有多个指标的数组，比如 TμνρσT^{\mu\nu}{}_{\rho \sigma}Tμνρσ​。而度规可以用来升降指标，例如 Vμ=gμνVνV_\mu=g_{\mu\nu}V^\nuVμ​=gμν​Vν。

我们还约定：矢量与张量的分量变换通过 Lorentz 变换联系起来：

(V′)μ=ΛμνVν,(W′)μ=ΛμνWν,ΛμρΛνρ=δμν,Λνμ≡(Λ−1)μν.(V')^\mu = \Lambda^\mu{}_\nu V^\nu, \qquad (W')_\mu = \Lambda_\mu{}^\nu W_\nu, \qquad \Lambda^{\mu}{}_\rho \Lambda_{\nu}{}^{\rho} = \delta^\mu{}_\nu, \qquad \Lambda_{\nu}{}^\mu \equiv (\Lambda^{-1})^\mu{}_\nu.(V′)μ=Λμν​Vν,(W′)μ​=Λμ​νWν​,Λμρ​Λν​ρ=δμν​,Λν​μ≡(Λ−1)μν​.

其中 δμν\delta^\mu{}_\nuδμν​ 是 Kronecker delta，指标相同时取 111，不同时取 000，你也可以认为它就是单位矩阵。更高阶的张量变换是类似的，每一个上标都仿照 VμV^\muVμ，每一个下标都仿照 WμW_\muWμ​。

更详细的内容，可以参考我的 blog 线性代数的张量表述，这里我们只是非常不严谨地把最低限度的内容交代了。我个人推荐把这篇 blog 读完再继续看，会清晰很多。虽然只靠上面这些介绍也够用了。

备注

细心的读者可能发现了，我们这里说的逆变矢量和协变矢量和我的 blog 里面说的完全反过来了。实际上这只是物理学家的一种记号滥用导致的误会（）

我们先前写的 x′μ=Λμνxνx'^\mu = \Lambda^\mu{}_\nu x^\nux′μ=Λμν​xν，看起来很对是不是？但是仔细思考发现，这是一种分量的记法，严格来说应该写成 x=xμeμx=x^\mu e_\mux=xμeμ​ 才对，其中 eμe_\mueμ​ 是一组基。也就是说位矢 xxx 是一个向量。而我们在 blog 里面给出的关系是

fμ=Λνμeν,f_\mu = \Lambda^\nu{}_\mu e_\nu, fμ​=Λνμ​eν​,

也就是说，Λμν\Lambda^\mu{}_\nuΛμν​ 是基变换矩阵。在这样的定义下，向量的分量用其逆变换，因此叫逆变；对偶向量的分量用其本身变换，因此叫协变。这样逆变与协变的称呼含义是很明确的。而我们这里给出的关系 x′μ=Λμνxνx'^\mu = \Lambda^\mu{}_\nu x^\nux′μ=Λμν​xν，也即向量的分量用变换矩阵本身变换，那自然整个逆变与协变就会反过来：逆变的反而不用“逆”变，协变却要用“逆”变。

类似的问题我们在微分几何里也会遇到。数学家和物理学家真是一对苦命鸳鸯啊（）

出于简便性考虑，有时候对于四维的向量内积我们会简单记为

k⋅x=kμxμ=gμνkμxμ=−k0x0+k1x1+k2x2+k3x3,k \cdot x = k^\mu x_\mu = g_{\mu\nu} k^\mu x^\mu = - k^0x^0 + k^1x^1 + k^2x^2 + k^3x^3,k⋅x=kμxμ​=gμν​kμxμ=−k0x0+k1x1+k2x2+k3x3,

而三维的向量内积则记为

k⃗⋅x⃗=kixi=δijkixj=k1x1+k2x2+k3x3,\vec k \cdot \vec x = k^i x_i = \delta_{ij}k^i x^j =k^1x^1 + k^2x^2 + k^3x^3,k⋅x=kixi​=δij​kixj=k1x1+k2x2+k3x3,

然后用 kkk 代指 kkk 的（三维）模长。四维向量的内积并非正定，因此模长的定义可能存在问题，如果用到了我们一般会显式写出来。

所有的 Lorentz 变换实际上构成一个群 O(3,1)O(3, 1)O(3,1)，再加上时空平移，还能构成一个更大的群：Poincaré 群。我们主要讨论与恒等变换连续相连的 Lorentz 变换，也即 SO+(3,1)SO^+(3, 1)SO+(3,1)，它是 Lorentz 群的一个子群，收录了全部保证时间正向、空间正向的 Lorentz 变换。因此再配备上空间反演与时间反演，我们就可以用 SO+(3,1)SO^+(3, 1)SO+(3,1) 拼出整个 O(3,1)O(3, 1)O(3,1)。

完整的讨论可以参考 Lorentz 群的结构，正文部分我们就不再展开了。

3. 场的变换​

我们已经知道， Lorentz 变换构成一个群。当我们讨论场在 Lorentz 变换下如何变化时，实际上是在考虑这个群如何作用在场构成的函数空间上。更具体地说，我们希望为每个 Lorentz 变换 Λ\LambdaΛ 找到一个作用在场空间上的线性算符 U(Λ)U(\Lambda)U(Λ)，并且要求这些算符满足群的乘法关系：

U(Λ1Λ2)=U(Λ1)U(Λ2).U(\Lambda_1\Lambda_2)=U(\Lambda_1)U(\Lambda_2).U(Λ1​Λ2​)=U(Λ1​)U(Λ2​).

这正是我们在群论中所说的群表示。不过，我们的宝宝教程里还不需要研究这么具体，只需要知道不同类型的场有不同的变换规律。

我们先从最简单的标量场开始。

标量场​

正如我们最开始的例子给出的提示一样：场 ϕ\phiϕ 是时空坐标的函数。在我们选取不同的参考系时，两组坐标被 Lorentz 变换联系起来：x′=Λxx'=\Lambda xx′=Λx。那么 ϕ(x)\phi(x)ϕ(x) 的取值会怎么变化呢？这里有两种观点：主动变换和被动变换。

主动变换的意思是：场本身被 Lorentz 变换改变了，而坐标其实没动：我们真的得到了一个新的场 ϕ′(x)\phi'(x)ϕ′(x)。同时，我们还希望用原来的场 ϕ(x)\phi(x)ϕ(x) 来描述新的场。这听起来有点抽象，我们来想象一个旋转：比如原来在位置 xxx 的场被旋转到了 Λx\Lambda xΛx 处，那就是说：

ϕ′(Λx)=ϕ(x),\phi'(\Lambda x)=\phi(x),ϕ′(Λx)=ϕ(x),

也就是：

ϕ′(x)=ϕ(Λ−1x).\phi'(x)=\phi(\Lambda^{-1}x).ϕ′(x)=ϕ(Λ−1x).

而被动变换的意思是：坐标被 Lorentz 变换改变了，而场本身没动：我们用不同的方式描述同一个场，只是新的描述方式记作 ϕ′(x′)\phi'(x')ϕ′(x′)。我们还是考虑一个旋转：原来的位置 xxx 在旋转后变成了 x′=Λxx' = \Lambda xx′=Λx，而场本身是不变的，因此

ϕ′(x′)=ϕ(x),\phi'(x')=\phi(x),ϕ′(x′)=ϕ(x),

再代入 x=Λ−1x′x=\Lambda^{-1}x'x=Λ−1x′，我们可以发现等式两边都是 x′x'x′，因此可以重新命名 x′x'x′ 为 xxx，就得到：

ϕ′(x)=ϕ(Λ−1x)\phi'(x) = \phi(\Lambda^{-1}x)ϕ′(x)=ϕ(Λ−1x)

可以看到不管怎么考虑，我们得到的结果是一样的。这实际上和量子力学里面海森堡绘景和薛定谔绘景是非常类似的：可以把薛定谔绘景类比成主动变换、海森堡绘景类比成被动变换。我们之后会详细探讨这个问题。

矢量场​

逆变矢量场​

我们知道场也可以是矢量值的函数，比如电磁场中的四维矢势 Aμ(x)A^\mu(x)Aμ(x)。那么，矢量场在 Lorentz 变换下又会怎样变化呢？这里我们需要考虑两个方面：一方面，和标量场一样，Lorentz 变换会改变时空坐标，因此场的自变量需要相应地改变；另一方面，矢量本身也会在 Lorentz 变换下发生变化，因此我们还需要考虑场的分量如何变换。

我们采用被动变换的方式来解释，因为这样在公式推导上比较方便，而且我们已经看到了：两种方式给出相同的答案。

我们考虑同一个矢量场在不同坐标系下的描述。对于同一个时空点，其坐标满足 x′=Λxx'=\Lambda xx′=Λx，而矢量的分量按照 Lorentz 变换规律变化：

A′μ(x′)=ΛμνAν(x).A'^\mu(x')=\Lambda^\mu{}_\nu A^\nu(x).A′μ(x′)=Λμν​Aν(x).

代入 x=Λ−1x′x=\Lambda^{-1}x'x=Λ−1x′，再将自变量重新命名为 xxx，就得到：

A′μ(x)=ΛμνAν(Λ−1x).A'^\mu(x)=\Lambda^\mu{}_\nu A^\nu(\Lambda^{-1}x).A′μ(x)=Λμν​Aν(Λ−1x).

和标量场的变换规律相比，我们只是在右边多出了一个 Lorentz 变换矩阵 Λμν\Lambda^\mu{}_\nuΛμν​。这个矩阵作用在矢量的分量上，而 Λ−1\Lambda^{-1}Λ−1 则作用在场的自变量上。

协变矢量场​

对于协变矢量场是类似的，我们有：

Aμ′(x′)=ΛμνAν(x)=(Λ−1)νμAν(x),A'_\mu(x') = \Lambda_{\mu}{}^\nu A_\nu(x) =(\Lambda^{-1})^\nu{}_\mu A_\nu(x),Aμ′​(x′)=Λμ​νAν​(x)=(Λ−1)νμ​Aν​(x),

同样地，将两边的自变量统一，就得到：

Aμ′(x)=ΛμνAν(Λ−1x).A'_\mu(x) =\Lambda_{\mu}{}^\nu A_\nu(\Lambda^{-1}x).Aμ′​(x)=Λμ​νAν​(Λ−1x).

我们可以发现：对于一个逆变矢量场 Vμ(x)V^\mu(x)Vμ(x) 和一个协变矢量场 Wμ(x)W_\mu(x)Wμ​(x)，我们总有：

V′μ(x′)Wμ′(x′)=Vμ(x)Wμ(x).V'^\mu(x')W'_\mu(x') =V^\mu(x)W_\mu(x).V′μ(x′)Wμ′​(x′)=Vμ(x)Wμ​(x).

因此，缩并得到的 VμWμV^\mu W_\muVμWμ​ 是一个标量场，其变换规律也就回到了我们最初讨论的情况。

缩并得到标量场的例子

四动量是一个常用例子。对 pμ=(E,p⃗)p^\mu=(E,\vec p)pμ=(E,p​)，其自身缩并为

pμpμ=gμνpμpν=−E2+∣p⃗∣2=−m2,p_\mu p^\mu= g_{\mu\nu} p^\mu p^\nu =-E^2+|\vec p|^2=-m^2,pμ​pμ=gμν​pμpν=−E2+∣p​∣2=−m2,

因此在 Lorentz 变换下物体的质量是一个不变量。我们称之为“质量壳条件”。这是因为它实际上相当于在四维时空中画出了一个“球壳”（其实是双曲面），Lorentz 变换只能在这个“球壳”上“转动”四动量，而不能改变四动量的“长度”。

更抽象地说，这个质量壳实际上是 Lorentz 群 SO+(3,1)SO^+(3,1)SO+(3,1) 的一个轨道。我们暂时不详细展开说明。

类似地，对于更一般的张量场，我们只需要分别考虑每个指标的变换。例如一个二阶逆变张量场：

T′μν(x)=ΛμρΛνσTρσ(Λ−1x).T'^{\mu\nu}(x) =\Lambda^\mu{}_\rho\Lambda^\nu{}_\sigma T^{\rho\sigma}(\Lambda^{-1}x).T′μν(x)=Λμρ​Λνσ​Tρσ(Λ−1x).

对于同时具有上指标和下指标的张量场，变换规律也是类似的。我们在这里就不再逐一列举了。

导数​

最后，我们来考虑一个稍微特殊的例子：标量场的梯度。对于标量场 ϕ(x)\phi(x)ϕ(x)，我们知道它在 Lorentz 变换下满足 ϕ′(x′)=ϕ(x)\phi'(x')=\phi(x)ϕ′(x′)=ϕ(x)。那么，它的一阶偏导数应该怎样变换呢？

注意到偏导数本身也依赖于坐标的选取。根据链式法则：

∂μ′ϕ′(x′)=∂xν∂x′μ∂ϕ(x)∂xν=(Λ−1)νμ∂νϕ(x).\begin{aligned} \partial'_\mu\phi'(x') &=\frac{\partial x^\nu}{\partial x'^\mu} \frac{\partial\phi(x)}{\partial x^\nu}\\ &=(\Lambda^{-1})^\nu{}_\mu\partial_\nu\phi(x). \end{aligned}∂μ′​ϕ′(x′)​=∂x′μ∂xν​∂xν∂ϕ(x)​=(Λ−1)νμ​∂ν​ϕ(x).​

我们发现，这恰好就是协变矢量的变换规律！因此，标量场的梯度 ∂μϕ\partial_\mu\phi∂μ​ϕ 构成一个协变矢量场。进一步地，由于 Lorentz 变换是线性的，其变换矩阵与时空坐标无关，因此对张量场继续求偏导数时，也可以得到类似的结果。例如：

∂μ′A′ν(x′)=(Λ−1)ρμΛνσ∂ρAσ(x).\partial'_\mu A'^\nu(x') =(\Lambda^{-1})^\rho{}_\mu \Lambda^\nu{}_\sigma \partial_\rho A^\sigma(x).∂μ′​A′ν(x′)=(Λ−1)ρμ​Λνσ​∂ρ​Aσ(x).

这说明，在 Lorentz 变换下，张量场的普通偏导数仍然按照张量的规律变换。

备注

这个结论依赖于我们讨论的是惯性参考系之间的 Lorentz 变换。对于一般的非线性坐标变换，其变换的 Jacobian 矩阵也将依赖于坐标，因此普通偏导数不再具有这样的性质。这就是我们在广义相对论（或者涉及非惯性系的讨论）中需要引入协变导数的原因。

4. 方程与 Lorentz 协变性​

前面我们讨论了标量场、矢量场以及一般张量场在 Lorentz 变换下的行为。那么，为什么我们要关心这些变换规律呢？一个很重要的原因是我们希望物理规律在所有惯性参考系中都保持不变。

假设某个场方程可以写成

F[ϕ](x)=0,F[\phi](x)=0,F[ϕ](x)=0,

其中 F[ϕ]F[\phi]F[ϕ] 表示由场 ϕ\phiϕ 及其导数等构造出的某个量。如果 F[ϕ]F[\phi]F[ϕ] 是标量场，那么在 Lorentz 变换下，它满足

F[ϕ′](x′)=F[ϕ](x),F[\phi'](x')=F[\phi](x),F[ϕ′](x′)=F[ϕ](x),

其中 x′=Λxx'=\Lambda xx′=Λx。因此，如果原来的场满足 F[ϕ](x)=0F[\phi](x)=0F[ϕ](x)=0，变换后的场自然也满足 F[ϕ′](x′)=0F[\phi'](x')=0F[ϕ′](x′)=0。

例如我们之前得到的 Klein–Gordon 方程：

(∂μ∂μ−m2)ϕ(x)=0.(\partial_\mu\partial^\mu-m^2)\phi(x)=0.(∂μ​∂μ−m2)ϕ(x)=0.

注意到 ϕ\phiϕ 是标量场，而 ∂μϕ\partial_\mu\phi∂μ​ϕ 是协变矢量场，再通过缩并又回到标量场 ∂μ∂μϕ\partial^\mu\partial_\mu\phi∂μ∂μ​ϕ。这样一来，Klein–Gordon 方程的左边就是一个标量场。

我们也可以直接验证这一点。根据前面得到的偏导数变换规律：

∂μ′=(Λ−1)νμ∂ν.\partial'_\mu =(\Lambda^{-1})^\nu{}_\mu\partial_\nu.∂μ′​=(Λ−1)νμ​∂ν​.

由于 Lorentz 变换保持 Minkowski 度规不变，我们有

∂μ′∂′μ=gμν∂μ′∂ν′=gμν(Λ−1)ρμ(Λ−1)σν∂ρ∂σ=gρσ∂ρ∂σ=∂μ∂μ.\begin{aligned} \partial'_\mu\partial'^\mu &=g^{\mu\nu}\partial'_\mu\partial'_\nu\\ &=g^{\mu\nu} (\Lambda^{-1})^\rho{}_\mu (\Lambda^{-1})^\sigma{}_\nu \partial_\rho\partial_\sigma\\ &=g^{\rho\sigma}\partial_\rho\partial_\sigma\\ &=\partial_\mu\partial^\mu. \end{aligned}∂μ′​∂′μ​=gμν∂μ′​∂ν′​=gμν(Λ−1)ρμ​(Λ−1)σν​∂ρ​∂σ​=gρσ∂ρ​∂σ​=∂μ​∂μ.​

因此，

(∂μ′∂′μ−m2)ϕ′(x′)=(∂μ∂μ−m2)ϕ(x)=0.(\partial'_\mu\partial'^\mu-m^2)\phi'(x') =(\partial_\mu\partial^\mu-m^2)\phi(x)=0.(∂μ′​∂′μ−m2)ϕ′(x′)=(∂μ​∂μ−m2)ϕ(x)=0.

这就说明 Klein–Gordon 方程在 Lorentz 变换下保持形式不变，我们称它具有 Lorentz 协变性（Lorentz covariance）。

更一般地，场方程的 Lorentz 协变性并不要求等式两边一定是标量。我们再来看一个熟悉的例子：Maxwell 方程。引入电磁场张量 FμνF^{\mu\nu}Fμν 和四电流 jνj^\nujν，非齐次 Maxwell 方程可以写成

∂μFμν=jν.\partial_\mu F^{\mu\nu} = j^\nu.∂μ​Fμν=jν.

这里等式两边都是逆变矢量场。在 Lorentz 变换下，电磁场张量满足

F′μν(x′)=ΛμρΛνσFρσ(x).F'^{\mu\nu}(x') =\Lambda^\mu{}_\rho\Lambda^\nu{}_\sigma F^{\rho\sigma}(x).F′μν(x′)=Λμρ​Λνσ​Fρσ(x).

因此，根据偏导数的变换规律：

∂μ′F′μν(x′)=(Λ−1)αμ∂α(ΛμρΛνσFρσ(x))=(Λ−1)αμΛμρΛνσ∂αFρσ(x)=Λνσ∂ρFρσ(x)=Λνσjσ(x)=j′ν(x′).\begin{aligned} \partial'_\mu F'^{\mu\nu}(x') &=(\Lambda^{-1})^\alpha{}_\mu \partial_\alpha \left( \Lambda^\mu{}_\rho\Lambda^\nu{}_\sigma F^{\rho\sigma}(x) \right)\\ &=(\Lambda^{-1})^\alpha{}_\mu \Lambda^\mu{}_\rho\Lambda^\nu{}_\sigma \partial_\alpha F^{\rho\sigma}(x)\\ &=\Lambda^\nu{}_\sigma \partial_\rho F^{\rho\sigma}(x)\\ &=\Lambda^\nu{}_\sigma j^\sigma(x)\\ &=j'^\nu(x'). \end{aligned}∂μ′​F′μν(x′)​=(Λ−1)αμ​∂α​(Λμρ​Λνσ​Fρσ(x))=(Λ−1)αμ​Λμρ​Λνσ​∂α​Fρσ(x)=Λνσ​∂ρ​Fρσ(x)=Λνσ​jσ(x)=j′ν(x′).​

其中第二步利用了 Lorentz 变换矩阵是常数矩阵的性质（这也提示我们在曲线系中要谨慎考虑这个问题）。这样一来，我们就证明了非齐次 Maxwell 方程同样具有 Lorentz 协变性。

对于另一组 Maxwell 方程，我们可以利用电磁场张量写成

∂λFμν+∂μFνλ+∂νFλμ=0.\partial_\lambda F_{\mu\nu} +\partial_\mu F_{\nu\lambda} +\partial_\nu F_{\lambda\mu}=0.∂λ​Fμν​+∂μ​Fνλ​+∂ν​Fλμ​=0.

等式左边是一个三阶协变张量场，因此它在 Lorentz 变换下仍然为零。这说明齐次 Maxwell 方程也具有 Lorentz 协变性。

通过这两个例子，我们可以发现：只要场方程两边的对象具有相同的 Lorentz 变换规律，那么方程在一个惯性参考系中成立，就意味着它在其他惯性参考系中也成立。这也为我们之后构造相对论性场论提供了一个基本要求：描述物理规律的场方程应当具有 Lorentz 协变性。

当然，我们不能仅仅因为一个方程写成了 F[ϕ]=0F[\phi]=0F[ϕ]=0，就认为它具有 Lorentz 协变性，还要验证 F[ϕ]F[\phi]F[ϕ] 是否真的满足相应的 Lorentz 变换规律。
