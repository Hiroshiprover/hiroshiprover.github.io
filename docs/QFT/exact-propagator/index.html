精确传播子与物理质量

在 LSZ 公式中，外波的质量由单粒子极点决定。可是画图时，每一根自由线的质量 mmm 都是从拉格朗日量的二次项中读出来的。如果相互作用能把质量从 mmm 移到 mphm_{\rm ph}mph​，一叠在同一个位置有极点的自由线，怎么会相加出一个位置不同的极点？

把二点图拆成一条链​

先取 ⟨Ω∣ϕ∣Ω⟩=0\langle\Omega|\phi|\Omega\rangle=0⟨Ω∣ϕ∣Ω⟩=0。任何连通二点图都有两条外腿。沿两条外腿之间的路线看，有些内部线只要切断一条，就能把图分成各含一个外点的两部分。沿所有这样的线切开，剩下的二点部分再也不能靠切断一根内部线分开，称为单粒子不可约（1PI）插入。对于两点之间的传播，一张图就是这些插入和单根自由线交替组成的一条链。两个顶点间有两根平行线的三次理论圈图是一个插入，把这样的图用一根线串起来则还可以切开。

定义 iΣ(p2)\ii\Sigma(p^2)iΣ(p2) 为所有截去外线的 1PI 二点插入之和，包括二次反项。这个 i\iii 固定了这里自能 Σ\SigmaΣ 的符号。由于平移不变，每一段传递的动量相同。从左边的外点出发，一张连通图要么只有一根自由线，要么在这根线后遇到第一个 1PI 插入。摘掉这个插入，右边仍然可以是任意一张连通二点图。这样就直接得到精确传播子的方程

G~2=D~F+D~F(iΣ)G~2,G~2−1=D~F−1−iΣ.\widetilde G_2=\widetilde D_F+ \widetilde D_F(\ii\Sigma)\widetilde G_2,\qquad \widetilde G_2^{-1}=\widetilde D_F^{-1}-\ii\Sigma .G2​=DF​+DF​(iΣ)G2​,G2−1​=DF−1​−iΣ.

逐张图展开，原极点处出现二阶、三阶等高阶极点，它们恰好是移动后的分母按 Σ\SigmaΣ 展开的各项。
