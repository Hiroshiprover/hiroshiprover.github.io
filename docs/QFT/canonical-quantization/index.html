不同粒子数的态​

作用两次产生算符，得到的能量和动量分别是两次增量之和。又因为产生算符彼此对易，交换两个标签得到同一个态。这些激发是全同玻色子。连续作用 nnn 次张成对称的 nnn 粒子空间 Hn\mathcal H_nHn​，把真空以及所有可能的粒子数放在一起，就得到 Fock 空间

F=H0⊕H1⊕H2⊕⋯ ,N=∫p⃗ap⃗†ap⃗,[N,ap⃗†]=ap⃗†.\mathcal F=\mathcal H_0\oplus\mathcal H_1\oplus\mathcal H_2\oplus\cdots,\qquad N=\int_{\vec p}a^\dagger_{\vec p}a_{\vec p},\qquad [N,a^\dagger_{\vec p}]=a^\dagger_{\vec p}.F=H0​⊕H1​⊕H2​⊕⋯,N=∫p​​ap​†​ap​​,[N,ap​†​]=ap​†​.

在固定的 Hn\mathcal H_nHn​ 中换到位置表象，就能找回通常的多体 Schrödinger 方程。含有不同数目升降算符的相互作用会怎样改变粒子数，也可以用同一套代数计算。
