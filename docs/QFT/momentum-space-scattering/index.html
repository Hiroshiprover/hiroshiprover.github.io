动量空间的图与树级散射

散射实验指定的是外粒子的动量，而在坐标空间的图中，每一个内部顶点的位置都要积分。只要把每条线作 Fourier 变换，这些位置积分会替我们做掉大部分动量积分。

在一个顶点积分会发生什么​

用 D~F(k)=−i/(k2+m2−i0)\widetilde D_F(k)=-\ii/(k^2+m^2-\ii0)DF​(k)=−i/(k2+m2−i0) 写 DF(x−y)=∫ ⁣d4k (2π)−4eik⋅(x−y)D~F(k)D_F(x-y)=\int\dd^4k\,(2\pi)^{-4}e^{\ii k\cdot(x-y)}\widetilde D_F(k)DF​(x−y)=∫d4k(2π)−4eik⋅(x−y)DF​(k)。给每条内部线任选一个方向。一个顶点处，若流进的动量之和为 PPP、流出的为 QQQ，那么所有相位合在一起，对顶点位置的积分就是 (2π)4δ(4)(P−Q)(2\pi)^4\delta^{(4)}(P-Q)(2π)4δ(4)(P−Q)。因而每个顶点都守恒四动量。

拿三次理论的二阶二点图来试。它的两个内部顶点之间有两条线，可以相互交换，对称因子为二。先把两条外线的传播子留下，设外部动量为 p,p′p,p'p,p′，内部动量为 q,rq,rq,r。两个顶点给出 δ(4)(p−q−r)\delta^{(4)}(p-q-r)δ(4)(p−q−r) 和 δ(4)(q+r−p′)\delta^{(4)}(q+r-p')δ(4)(q+r−p′)。用第一个做掉 rrr 积分，第二个就只要求 p=p′p=p'p=p′。取出总守恒因子和两段外部传播子，图的中间部分是

(−ig)22∫ ⁣d4q(2π)4 D~F(q)D~F(p−q).\frac{(-\ii g)^2}{2}\int\frac{\dd^4q}{(2\pi)^4} \,\widetilde D_F(q)\widetilde D_F(p-q).2(−ig)2​∫(2π)4d4q​DF​(q)DF​(p−q).

给定外部动量，还有一个内部四动量不能由守恒条件固定。这就是一个圈要积的动量。此式描述二点函数的一次修正。两条外腿属于同一个粒子，它们之间的传播本身不会给出一场碰撞的截面。

一般的连通图也可以这样消去动量。从一个顶点出发，每次沿一条线接入一个尚未到过的顶点，直到 VVV 个顶点都连起来。选出的 V−1V-1V−1 条线组成一棵树。把其他线的动量暂时固定，从树梢向内用每个顶点的守恒条件，恰好能逐条确定这 V−1V-1V−1 条线。最后一个顶点只剩总外动量守恒。于是 III 条内部线中还有 I−V+1I-V+1I−V+1 个独立圈动量。没有圈的连通图叫树图，每条内部线的动量都已由外态固定。用单位极点留数的场时，LSZ 对每条外线的 iK\ii KiK 抵消外部传播子。于是计算 iM\ii\mathcal MiM 时，直接写内部线 D~F\widetilde D_FDF​、每个顶点的 −ig-\ii g−ig 或相应耦合、每个独立圈的  ⁣d4q/(2π)4\dd^4q/(2\pi)^4d4q/(2π)4，再除以图的对称因子。外部动量放在质量壳上，内部动量仍由守恒和积分决定。一个完全不参与碰撞的旁观粒子会留下独立的态内积。求连通振幅时，所有外腿须在同一个连通部分中。
