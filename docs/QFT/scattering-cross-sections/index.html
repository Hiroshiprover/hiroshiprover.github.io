散射振幅、截面与衰变率

让两个相隔很远的粒子波包相向运动，碰撞后再等到它们充分分离，探测器就能分别测量出射粒子的动量。对于稳定的有质量粒子和短程相互作用，这给了我们两套标记态的办法。可以说一个态是由哪些粒子入射得到的，也可以说它在将来会分成哪些粒子。这两套渐近态之间的重叠定义了散射矩阵

Sfi=⟨f,out∣i,in⟩.S_{fi}=\langle f,\mathrm{out}|i,\mathrm{in}\rangle .Sfi​=⟨f,out∣i,in⟩.

取完备的散射通道，概率守恒给出 S†S=1S^\dagger S=1S†S=1。即使什么都没发生，SSS 中仍有自由态之间的重叠，因此写 S=1+iTS=1+\ii TS=1+iT。时空平移不改变碰撞，把整个实验平移 aaa 只会给矩阵元乘上总四动量差所决定的相位。对任意 aaa 都不变就要求 Pf=PiP_f=P_iPf​=Pi​。将这个守恒因子从连通跃迁矩阵元中提出来，余下的系数定义了散射振幅 Mfi\mathcal M_{fi}Mfi​，即

⟨f∣iT∣i⟩conn=i(2π)4δ(4)(Pf−Pi) Mfi.\langle f|\ii T|i\rangle_{\rm conn} =\ii(2\pi)^4\delta^{(4)}(P_f-P_i)\,\mathcal M_{fi}.⟨f∣iT∣i⟩conn​=i(2π)4δ(4)(Pf​−Pi​)Mfi​.

守恒条件固定的是总四动量。即使总动量已经固定，粒子仍可以向不同方向散射，M\mathcal MM 就可以依赖散射角。
