# 宝宝用量子场论

## 前言

本文是我个人在上量子场论的笔记，课程是南方科技大学 Sebastian Gracia Sanez 老师开设的《量子场论导论》。据 Seb 说，课程内容没有具体的参考教材，只有几本推荐书目。但就我目前看来，应该是主要参考了 Schwartz 的那本，除了去掉了一些引言性质的内容，以及度规符号约定相反之外，基本的逻辑顺序都是一样的。附上一个中译本的[链接](https://zhuanlan.zhihu.com/p/2044797724638413585)。

笔记的初稿实际上是用 ChatGPT 和 DeepSeek 直接从 Seb 上课的板书提取出来的，在这个基础上我再人工润色（重写），并填补了一些自己的理解和例子。目前的进度到了实标量场。
