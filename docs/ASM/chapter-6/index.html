6.1 经典统计力学的公设​

时间平均与系综平均​

一般的力学定律着眼于在给定初始条件下，预测系统的动力学行为。与其截然不同的是：热力学的主要目的在于描述宏观系统的平衡性质。在某种意义上，它首先关心的是定态。

从测量的角度看，任何测量都有时间分辨率与空间分辨率。例如，室温下空气的分子密度约为每升 102310^{23}1023 个粒子，平均分子速率约为 400m/s400 m/s400m/s。若测量的空间分辨率为 1μ1\mu1μm、测量持续时间为 1ms1 ms1ms，那么实验中涉及的分子数约为 10810^{8}108，每个粒子在实验过程中与另一个分子碰撞约 10710^{7}107 次1。因此，一次热力学测量可以看作是对时间 TTT 与体积 VVV 的平均，而二者都显著大于微观特征尺度。

事实上，我们可以让 TTT 与 VVV 都趋于无穷——毕竟，热力学测量可以如我们所愿地扩展到更大的体积、持续比上述例子更长的时间。唯一需要注意的是，当取体积 VVV 趋于无穷时，我们也需要让粒子总数 NNN 趋于无穷

V→∞,N→∞,VN=v(6.1)V \to \infty,\quad N \to \infty,\quad \frac{V}{N} = v \tag{6.1}V→∞,N→∞,NV​=v(6.1)

其中单粒子体积 vvv 保持不变。式 (6.1) 定义了热力学极限。

在经典力学中，物理量 fff 被表示为哈密顿变量 qqq 与 ppp 的函数。于是，经典统计力学的主要任务就是计算下述时间平均2

fˉ=lim⁡T→∞1T∫0Tf[q(t′),p(t′)]dt′.(6.2)\bar{f} = \lim_{T\to\infty}\frac{1}{T}\int_0^T f[q(t'),p(t')]dt'. \tag{6.2}fˉ​=T→∞lim​T1​∫0T​f[q(t′),p(t′)]dt′.(6.2)

哈密顿变量 q(t),p(t){q(t), p(t)}q(t),p(t) 由哈密顿方程，即式 (0.1) 决定。随着时间演化，系统的状态在相空间（由 3N3N3N 个正则坐标与 3N3N3N 个正则动量张成）中形成一条轨迹。由于我们处理的是无整体运动的 NNN 个分子的热平衡，我们有理由假设：只要 TTT 足够大，这条轨迹会多次穿过位于 (q,p)(q, p)(q,p) 处的体积元 d3Nqd3Npd^{3N}qd^{3N}pd3Nqd3Np。设相点在该体积元内停留的时间为 τ\tauτ，那么我们可以定义一个密度函数（未归一化）

ρ(q,p) d3Nq d3Np=lim⁡T→∞τT.(6.3)\rho(q,p)\,d^{3N}q\,d^{3N}p = \lim_{T\to\infty}\frac{\tau}{T}. \tag{6.3}ρ(q,p)d3Nqd3Np=T→∞lim​Tτ​.(6.3)

它表征系统处在 (q,p)(q, p)(q,p) 状态的概率。接下来，我们设想这个 6N6N6N 维相空间中充满了密度为 ρ(q,p)\rho(q, p)ρ(q,p) 的流体，其中每个点 (q,p)(q, p)(q,p) 都对应所研究系统的一个假想复本。所有这些假想的复本被称为一个系综。于是，物理量 fff 的时间平均 fff 也可以通过系综平均来表示

⟨f⟩=∫d3Nq d3Np ρ(q,p)f(q,p)∫d3Nq d3Np ρ(q,p).(6.4)\langle f\rangle = \frac{\int d^{3N}q\,d^{3N}p\,\rho(q,p)f(q,p)}{\int d^{3N}q\,d^{3N}p\,\rho(q,p)}. \tag{6.4}⟨f⟩=∫d3Nqd3Npρ(q,p)∫d3Nqd3Npρ(q,p)f(q,p)​.(6.4)

现在我们回顾刘维尔定理，它指出相空间中的这种假想流体是不可压缩的 (dρ/dt=0)(d\rho/dt= 0)(dρ/dt=0)

dρdt=∂ρ∂t+∑i=13N(∂ρ∂qi∂H∂pi−∂ρ∂pi∂H∂qi)=0.(6.5)\frac{d\rho}{dt} = \frac{\partial\rho}{\partial t} + \sum_{i=1}^{3N}\left(\frac{\partial\rho}{\partial q_i}\frac{\partial\mathscr{H}}{\partial p_i} - \frac{\partial\rho}{\partial p_i}\frac{\partial\mathscr{H}}{\partial q_i}\right) = 0. \tag{6.5}dtdρ​=∂t∂ρ​+i=1∑3N​(∂qi​∂ρ​∂pi​∂H​−∂pi​∂ρ​∂qi​∂H​)=0.(6.5)

由于平衡态下密度函数 ρ\rhoρ 不显含时间，式 (6.5) 表明泊松括号 {ρ,H}\{\rho,\mathscr{H}\}{ρ,H} 为零。因此，ρ\rhoρ 必须是运动积分（守恒量）的函数。在具体模型中可能存在许多相互独立的运动积分（对可积系统而言，这类积分的数目是 3N3N3N）。然而对现实系统来说，动力学可能足够复杂，以至于只有动量、角动量与能量可以确定地作为运动积分。进一步地，通过取质心系并只关注总动量与总角动量为零的状态，我们可以有效地认为密度函数 ρ(q,p)\rho(q, p)ρ(q,p) 只依赖于能量：

ρ(q,p)=ϱ[H(q,p)].(6.6)\rho(q,p) = \varrho[\mathscr{H}(q,p)]. \tag{6.6}ρ(q,p)=ϱ[H(q,p)].(6.6)

需要强调的是，如果允许分子数 NNN 变化，密度函数也可能依赖于它。

要进一步确定 ρ\rhoρ 的形式，还需要其他考虑。

等概率（先验概率相等）公设​

在由 102310^{23}1023 个分子组成的孤立系统中，其轨迹位于相空间中能量为常数的曲面上。由于不可避免的扰动（例如测量带来的扰动），这个曲面可能会展宽为一个夹在固定能量 EEE 与 E+ΔE+\DeltaE+Δ 的两个曲面之间的壳层。对于足够弱的扰动，我们可以假设

Δ≪E.(6.7)\Delta \ll E. \tag{6.7}Δ≪E.(6.7)

此外，从量子力学的角度看，存在能量-时间不确定关系，因此由于实验的有限时长，Δ\DeltaΔ 是不可避免的。所以 Δ\DeltaΔ 应当被视为一个真实的小而有限的量，而不是纯数学意义上的无穷小。

鉴于分子运动错综复杂且混沌，我们可以假设：能量壳层内的“每个状态”在足够长的时间 TTT 内都曾被经历3。这一原理被称为遍历性假设4，它正是等概率（先验概率相等）公设的基础。讨论遍历性假设的细节超出了本课程的范围。相反，我们将把它作为出发点，去探讨它如何能与实验观测相协调——毕竟，一个正确的物理理论只能由实验来确认。于是，密度函数 ρ\rhoρ 被假设为具有如下形式

ρ(q,p)={常数,若 E<H(q,p)<E+Δ,0,其他.(6.8)\rho(q,p) = \begin{cases} \text{常数}, & \text{若 } E < \mathscr{H}(q,p) < E+\Delta, \\ 0, & \text{其他}. \end{cases} \tag{6.8}ρ(q,p)={常数,0,​若 E<H(q,p)<E+Δ,其他.​(6.8)

相应的系综被称为微正则系综。

热学量的涨落​

式 (6.4) 给出的系综平均实际上是被假定对应了某些热力学量的真实值，它们可以在实验中被测量，并与相函数 f(q,p)f(q, p)f(q,p) 相联系。与确定性的经典量不同，热力学量是随机变量，具有均方涨落（方差）

⟨(Δf)2⟩=⟨(f−⟨f⟩)2⟩=⟨f2⟩−⟨f⟩2.(6.9)\langle(\Delta f)^2\rangle = \langle(f-\langle f\rangle)^2\rangle = \langle f^2\rangle - \langle f\rangle^2. \tag{6.9}⟨(Δf)2⟩=⟨(f−⟨f⟩)2⟩=⟨f2⟩−⟨f⟩2.(6.9)

在由大量粒子组成的热力学系统中，涨落相对于平均值通常可以忽略不计，从而使得统计力学有意义。

涨落可忽略的证明

事实上，我们可以证明

⟨(Δf)2⟩⟨f⟩≈1N.(6.10)\frac{\sqrt{\langle(\Delta f)^2\rangle}}{\langle f\rangle} \approx \frac{1}{\sqrt{N}}. \tag{6.10}⟨f⟩⟨(Δf)2⟩​​≈N​1​.(6.10)

本质上，这种小的相对涨落来自概率论中的中心极限定理。下面我们将给出一个简单的论证来支持这一表达式。

设物理量 fff 具有可加性。当我们把整个系统分解为 NNN 个小的部分时，我们发现

⟨f⟩=∑i=1N⟨fi⟩.(6.11)\langle f\rangle = \sum_{i=1}^{N}\langle f_i\rangle. \tag{6.11}⟨f⟩=i=1∑N​⟨fi​⟩.(6.11)

假设这些小部分虽然相对于整个系统很小，但仍足够大从而统计上相互独立，那么对 j≠kj \ne kj=k，

⟨ΔfjΔfk⟩=⟨Δfj⟩⟨Δfk⟩=0.(6.12)\langle\Delta f_j\Delta f_k\rangle = \langle\Delta f_j\rangle\langle\Delta f_k\rangle = 0. \tag{6.12}⟨Δfj​Δfk​⟩=⟨Δfj​⟩⟨Δfk​⟩=0.(6.12)

因此，

⟨(Δf)2⟩=∑i=1N⟨(Δfi)2⟩+∑j=1N∑k≠j,k=1N⟨(Δfj)(Δfk)⟩=∑i=1N⟨(Δfi)2⟩,(6.13)\langle(\Delta f)^2\rangle = \sum_{i=1}^{N}\langle(\Delta f_i)^2\rangle + \sum_{j=1}^{N}\sum_{k\neq j,k=1}^{N}\langle(\Delta f_j)(\Delta f_k)\rangle = \sum_{i=1}^{N}\langle(\Delta f_i)^2\rangle, \tag{6.13}⟨(Δf)2⟩=i=1∑N​⟨(Δfi​)2⟩+j=1∑N​k=j,k=1∑N​⟨(Δfj​)(Δfk​)⟩=i=1∑N​⟨(Δfi​)2⟩,(6.13)

这表明 ⟨(Δf)2⟩\langle(\Delta f)^{2}\rangle⟨(Δf)2⟩ 与 NNN 成正比。注意到 ⟨f⟩\langle f\rangle⟨f⟩ 也与 NNN 成正比，于是我们得到

⟨(Δf)2⟩⟨f⟩∝1N.(6.14)\frac{\sqrt{\langle(\Delta f)^2\rangle}}{\langle f\rangle} \propto \frac{1}{\sqrt{N}}. \tag{6.14}⟨f⟩⟨(Δf)2⟩​​∝N​1​.(6.14)

由于涨落小到可以忽略，我们可以用物理量最可能的值——也就是系综中包含系统数目最多、或者概率最大的那个值——来代替系综平均。
