6.2 微正则系综

微正则系综具有固定的分子数 NNN、体积 VVV，以及介于 EEE 与 E+ΔE+ \DeltaE+Δ 之间的能量。下面我们在这个系综中定义其他的热力学量，其中最重要的一个是熵。

设 Ω(E)\Omega(E)Ω(E) 为密度函数（式 6.8）在全相空间的积分，也即相空间中被等能面 EEE 所包围的体积，

Ω(E)≡1h3N∫H(q,p)<Ed3Nq d3Np.(6.15)\Omega(E) \equiv \frac{1}{h^{3N}}\int_{\mathscr{H}(q,p)<E} d^{3N}q\,d^{3N}p. \tag{6.15}Ω(E)≡h3N1​∫H(q,p)<E​d3Nqd3Np.(6.15)

它同时依赖于 VVV 与 NNN。注意 d3Nq d3Npd^{3N}q\,d^{3N}pd3Nqd3Np 以 h3Nh^{3N}h3N 为单位给出，其中 hhh 是普朗克常数，因此 Ω(E)\Omega(E)Ω(E) 是无量纲的。于是，微正则系综所占据的相体积为

Σ(E)=Ω(E+Δ)−Ω(E)=ω(E)Δ,(6.16)\Sigma(E) = \Omega(E+\Delta) - \Omega(E) = \omega(E)\Delta, \tag{6.16}Σ(E)=Ω(E+Δ)−Ω(E)=ω(E)Δ,(6.16) ω(E)≡∂Ω∂E=∫d3Nq d3Nph3N δ[E−H(q,p)],(6.17)\omega(E) \equiv \frac{\partial\Omega}{\partial E} = \int \frac{d^{3N}q\,d^{3N}p}{h^{3N}}\,\delta[E-\mathscr{H}(q,p)], \tag{6.17}ω(E)≡∂E∂Ω​=∫h3Nd3Nqd3Np​δ[E−H(q,p)],(6.17)

其中我们引入了态密度 ω(E)\omega(E)ω(E)。仿照玻尔兹曼，熵被形式地定义为

S(E,V)=kln⁡Σ(E),(6.18)S(E,V) = k\ln\Sigma(E), \tag{6.18}S(E,V)=klnΣ(E),(6.18)

其中 kkk 是玻尔兹曼常数。式 (6.15)、(6.16) 与 (6.17) 中定义的这些量都随 NNN 指数增长，这一点稍后将在一些具体系统（如理想气体）中展示。

我们将说明关于如此定义的熵的以下陈述

  • 熵是广延量。
  • 在孤立系统中，熵永不减少。

让我们通过插入一个隔板，把处于平衡态的孤立系统分成两个子系统。两个子系统分别含有 N1N_{1}N1​ 与 N2N_{2}N2​ 个粒子，分别占据体积 V1V_{1}V1​ 与 V2V_{2}V2​。子系统 1 的能量介于 E1E_{1}E1​ 与 E1+ΔE_{1}+\DeltaE1​+Δ 之间，而子系统 2 的能量介于 E2E_{2}E2​ 与 E2+ΔE_{2}+ \DeltaE2​+Δ 之间。这两个子系统及其各自的能量区间如图 6.1 所示。

图 6.1：由两个子系统组成的微正则系综。

这两个子系统的相应相体积记为 Σ1(E1)\Sigma_{1}(E_{1})Σ1​(E1​) 与 Σ2(E2)\Sigma_{2}(E_{2})Σ2​(E2​)，那么它们的熵可以表示为

S1(E1)=kln⁡Σ1(E1),S2(E2)=kln⁡Σ2(E2).(6.19)S_1(E_1) = k\ln\Sigma_1(E_1),\quad S_2(E_2) = k\ln\Sigma_2(E_2). \tag{6.19}S1​(E1​)=klnΣ1​(E1​),S2​(E2​)=klnΣ2​(E2​).(6.19)

为方便起见，我们在这些表达式中省略体积 V1V_{1}V1​ 与 V2V_{2}V2​。整个系统的总能量介于 E=E1+E2E=E_{1}+E_{2}E=E1​+E2​ 与 E+2ΔE+ 2\DeltaE+2Δ 之间。它的相体积可以写成

Σ(E)=∑E1/Δ=0E/ΔΣ1(E1)Σ2(E−E1),(6.20)\Sigma(E) = \sum_{E_1/\Delta=0}^{E/\Delta}\Sigma_1(E_1)\Sigma_2(E-E_1), \tag{6.20}Σ(E)=E1​/Δ=0∑E/Δ​Σ1​(E1​)Σ2​(E−E1​),(6.20)

其中所有能量都以 Δ\DeltaΔ 为单位度量。出于方便考虑，两个子系统的能量展宽被取为同一个 Δ\DeltaΔ，原则上它们可以不同，但可以证明这并不会影响我们对于熵的讨论。

求和项中存在一个最大项；设对应的子系统能量为 Eˉ1\bar{E}_{1}Eˉ1​ 与 Eˉ2\bar{E}_{2}Eˉ2​，且 Eˉ2=E−Eˉ1\bar{E}_{2}=E-\bar{E}_{1}Eˉ2​=E−Eˉ1​。于是我们得到如下关于子系统相体积与熵的不等式：

Σ1(Eˉ1)Σ2(Eˉ2)<Σ(E)<EΔΣ1(Eˉ1)Σ2(Eˉ2)⇒ln⁡[Σ1(Eˉ1)Σ2(Eˉ2)]<ln⁡[Σ(E)]<ln⁡[Σ1(Eˉ1)Σ2(Eˉ2)]+ln⁡(E/Δ).(6.21)\begin{aligned} &\Sigma_1(\bar{E}_1)\Sigma_2(\bar{E}_2) < \Sigma(E) < \frac{E}{\Delta}\Sigma_1(\bar{E}_1)\Sigma_2(\bar{E}_2)\\ \Rightarrow &\ln[\Sigma_1(\bar{E}_1)\Sigma_2(\bar{E}_2)] < \ln[\Sigma(E)] < \ln[\Sigma_1(\bar{E}_1)\Sigma_2(\bar{E}_2)] + \ln(E/\Delta). \end{aligned} \tag{6.21}⇒​Σ1​(Eˉ1​)Σ2​(Eˉ2​)<Σ(E)<ΔE​Σ1​(Eˉ1​)Σ2​(Eˉ2​)ln[Σ1​(Eˉ1​)Σ2​(Eˉ2​)]<ln[Σ(E)]<ln[Σ1​(Eˉ1​)Σ2​(Eˉ2​)]+ln(E/Δ).​(6.21)

注意 Δ\DeltaΔ 是一个固定的小常量，并且

ln⁡Σ1(Eˉ1)∝N1,ln⁡Σ2(Eˉ2)∝N2,E∝N1+N2,(6.22)\ln\Sigma_1(\bar{E}_1) \propto N_1,\quad \ln\Sigma_2(\bar{E}_2) \propto N_2,\quad E \propto N_1 + N_2, \tag{6.22}lnΣ1​(Eˉ1​)∝N1​,lnΣ2​(Eˉ2​)∝N2​,E∝N1​+N2​,(6.22)

因此我们得出结论

S(E,V)=S1(Eˉ1,V1)+S2(Eˉ2,V2)+O(ln⁡(N))→N→∞S1(Eˉ1,V1)+S2(Eˉ2,V2).(6.23)\begin{aligned}S(E,V) &= S_1(\bar{E}_1,V_1) + S_2(\bar{E}_2,V_2) + O(\ln(N))\\ &\xrightarrow{N\to\infty} S_1(\bar{E}_1,V_1) + S_2(\bar{E}_2,V_2).\end{aligned} \tag{6.23}S(E,V)​=S1​(Eˉ1​,V1​)+S2​(Eˉ2​,V2​)+O(ln(N))N→∞​S1​(Eˉ1​,V1​)+S2​(Eˉ2​,V2​).​(6.23)

换句话说，式 (6.18) 所定义的熵在热力学极限下是一个广延量。

备注

以上关于广延量的部分是叶飞老师给出的原文，我没有进行修改。我个人认为这段内容有一些误导性：这里只是声明了 Σ\SigmaΣ 是按照 NNN 指数增长的，这等价于声明 ln⁡Σ\ln \SigmalnΣ 正比于 NNN，也就等价于说单系统的熵是正比于 NNN 的。

换句话说，我们并没有证明熵是 O(N)O(N)O(N) 的，这是一个假设。我们真正证明的事情是两个子系统混合时，总系统的熵主项是 O(N)O(N)O(N) 的，而修正项是 O(ln⁡(N))O(\ln(N))O(ln(N)) 的，因此在 N→∞N\to \inftyN→∞ 时，修正项相对于主项而言可忽略。

通过与导出不等式 (6.21) 相类似的论证，我们还可以建立不等式 Σ(E)<Ω(E)<(E/Δ)Σ(E)\Sigma(E)\lt \Omega(E)\lt (E/\Delta) \Sigma(E)Σ(E)<Ω(E)<(E/Δ)Σ(E)，它在热力学极限下给出恒等式

S(E,V)=kln⁡Σ(E)=kln⁡Ω(E)=kln⁡ω(E).(6.24)S(E,V) = k\ln\Sigma(E) = k\ln\Omega(E) = k\ln\omega(E). \tag{6.24}S(E,V)=klnΣ(E)=klnΩ(E)=klnω(E).(6.24)

我们注意到 ω(E)\omega(E)ω(E) 的量纲在这个极限下无关紧要。这类恒等式在统计力学中是很典型的。1

因为根据等概率假设，某一给定能量分配的权重正比于相应的微观状态数 Σ1(E1)Σ2(E2)\Sigma_{1}(E_{1})\Sigma_{2}(E_{2})Σ1​(E1​)Σ2​(E2​)，不等式 (6.21) 表明：在所有可能的能量分配中，最可能的那个——即子系统能量为 Eˉ1\bar{E}_{1}Eˉ1​ 与 Eˉ2=E−Eˉ1\bar{E}_{2}=E-\bar{E}_{1}Eˉ2​=E−Eˉ1​ 的分配——比所有其他分配都压倒性地更加可能。换句话说，当隔板插入后，最可能的能量分配以实际上等于 1 的概率实现，而所有其他分配出现的概率实际上等于 0。我们可以计算与某个非典型分配——比如一个满足 E1≠Eˉ1E_{1} \ne \bar{E}_{1}E1​=Eˉ1​ 且 E2=E−E1E_{2}=E-E_{1}E2​=E−E1​ 的分配——相对应的熵，如下：

Σ1(E1)Σ2(E−E1)<Σ1(Eˉ1)Σ2(Eˉ2)\Sigma_1(E_1)\Sigma_2(E-E_1) < \Sigma_1(\bar{E}_1)\Sigma_2(\bar{E}_2)Σ1​(E1​)Σ2​(E−E1​)<Σ1​(Eˉ1​)Σ2​(Eˉ2​) ⇒S1(E1,V1)+S2(E2,V2)<S1(Eˉ1,V1)+S2(Eˉ2,V2)=S(E,V).(6.25)\Rightarrow S_1(E_1,V_1) + S_2(E_2,V_2) < S_1(\bar{E}_1,V_1) + S_2(\bar{E}_2,V_2) = S(E,V). \tag{6.25}⇒S1​(E1​,V1​)+S2​(E2​,V2​)<S1​(Eˉ1​,V1​)+S2​(Eˉ2​,V2​)=S(E,V).(6.25)

由此得到的熵小于最可能分配的熵。因此我们发现，孤立系统的熵不会减少（出现这种减少的概率几乎为零）。这就是热力学第二定律。

注意在子系统能量的最可能取值处，乘积 Σ1(E1)Σ2(E2)\Sigma_{1}(E_{1})\Sigma_{2}(E_{2})Σ1​(E1​)Σ2​(E2​) 在约束 E1+E2=EE_{1}+E_{2}=EE1​+E2​=E 下取极大，于是

δ[Σ1(E1)Σ2(E2)]=0,δE1+δE2=0.(6.26)\delta[\Sigma_1(E_1)\Sigma_2(E_2)] = 0,\quad \delta E_1 + \delta E_2 = 0. \tag{6.26}δ[Σ1​(E1​)Σ2​(E2​)]=0,δE1​+δE2​=0.(6.26)

这给出条件

[∂∂E1ln⁡Σ1(E1)]E1=Eˉ1=[∂∂E2ln⁡Σ2(E2)]E2=Eˉ2,(6.27)\left[\frac{\partial}{\partial E_1}\ln\Sigma_1(E_1)\right]_{E_1=\bar{E}_1} = \left[\frac{\partial}{\partial E_2}\ln\Sigma_2(E_2)\right]_{E_2=\bar{E}_2}, \tag{6.27}[∂E1​∂​lnΣ1​(E1​)]E1​=Eˉ1​​=[∂E2​∂​lnΣ2​(E2​)]E2​=Eˉ2​​,(6.27)

或者等价地，

[∂∂E1S1(E1,V1)]E1=Eˉ1=[∂∂E2S2(E2,V2)]E2=Eˉ2.(6.28)\left[\frac{\partial}{\partial E_1}S_1(E_1,V_1)\right]_{E_1=\bar{E}_1} = \left[\frac{\partial}{\partial E_2}S_2(E_2,V_2)\right]_{E_2=\bar{E}_2}. \tag{6.28}[∂E1​∂​S1​(E1​,V1​)]E1​=Eˉ1​​=[∂E2​∂​S2​(E2​,V2​)]E2​=Eˉ2​​.(6.28)

让我们通过下式定义系统的温度

∂S(E,V)∂E=1T.(6.29)\frac{\partial S(E,V)}{\partial E} = \frac{1}{T}. \tag{6.29}∂E∂S(E,V)​=T1​.(6.29)

于是，式 (6.28) 就等价于说两个子系统在平衡时具有相同的温度，这一结果被称为热力学第零定律。如果它们的能量偏离最可能值，两个温度一般会不同，两个子系统便不处于热平衡。当允许它们之间交换能量时，热量会从一个子系统流向另一个，驱动整个系统趋向热平衡，从而使熵达到极大。
