经典理想气体与吉布斯佯谬

6.5 经典理想气体​

本节我们以经典理想气体模型为例，说明统计力学是如何运作的。前面几节中的一些令人困惑之处将在这个具体的例子中得到澄清。

考虑一个体积为 VVV、含有 NNN 个单原子分子的气体，忽略分子间的相互作用。该气体的相体积为

Ω(E)=VNh3N∫∑i=13Npi22m<Ed3Np=(2πmE)3N/2VNh3NΓ[(3N/2)+1].(6.38)\Omega(E) = \frac{V^N}{h^{3N}}\int_{\sum_{i=1}^{3N}\frac{p_i^2}{2m}<E} d^{3N}p = \frac{(2\pi mE)^{3N/2}V^N}{h^{3N}\Gamma[(3N/2)+1]}. \tag{6.38}Ω(E)=h3NVN​∫∑i=13N​2mpi2​​<E​d3Np=h3NΓ[(3N/2)+1](2πmE)3N/2VN​.(6.38)

利用 Γ\GammaΓ 函数的性质，

Γ(z+1)=2πz ez(ln⁡z−1)(1+112z+⋯ )\Gamma(z+1) = \sqrt{2\pi z}\,e^{z(\ln z-1)}\left(1 + \frac{1}{12z} + \cdots\right)Γ(z+1)=2πz​ez(lnz−1)(1+12z1​+⋯)

我们发现

ln⁡[Γ(3N/2+1)]=(3N2)ln⁡(3N2e)+ln⁡3πN+o(1/N).(6.39)\ln[\Gamma(3N/2+1)] = \left(\frac{3N}{2}\right)\ln\left(\frac{3N}{2e}\right) + \ln\sqrt{3\pi N} + o(1/N). \tag{6.39}ln[Γ(3N/2+1)]=(23N​)ln(2e3N​)+ln3πN​+o(1/N).(6.39)

于是熵为

S(E,V)=Nkln⁡[(4πmE3Nh2)3/2V]+32Nk+o(ln⁡N).(6.40)S(E,V) = Nk\ln\left[\left(\frac{4\pi mE}{3Nh^2}\right)^{3/2}V\right] + \frac{3}{2}Nk + o(\ln N). \tag{6.40}S(E,V)=Nkln[(3Nh24πmE​)3/2V]+23​Nk+o(lnN).(6.40)

我们认出，这个结果正是我们在本科热力学中学过的经典理想单原子气体的熵。利用式 (6.38)，容易证明

ω(E)=dΩdE=(3N2E)Ω(E),Σ(E)=ω(E)Δ.(6.41)\omega(E) = \frac{d\Omega}{dE} = \left(\frac{3N}{2E}\right)\Omega(E),\quad \Sigma(E) = \omega(E)\Delta. \tag{6.41}ω(E)=dEdΩ​=(2E3N​)Ω(E),Σ(E)=ω(E)Δ.(6.41)

显然，对 Σ(E)\Sigma(E)Σ(E) 取对数所定义的熵与式 (6.40) 相差一个 ln⁡(NΔ/E)\ln(N\Delta/E)ln(NΔ/E) 项，对于足够大的 NNN 这一项可以安全地忽略。因为 Δ\DeltaΔ 是一个常数能量，我们也可以把下面的表达式作为热力学极限下熵的一个合理定义

S(E,V)=kln⁡ω(E),(6.42)S(E,V) = k\ln\omega(E), \tag{6.42}S(E,V)=klnω(E),(6.42)

尽管态密度 ω(E)\omega(E)ω(E) 具有能量的量纲。于是，式 (6.24) 被证明对经典理想气体成立。它还进一步表明，Ω(E)\Omega(E)Ω(E) 的概率权重主要集中在能量边缘 ∼E\sim E∼E 处，这反映了统计力学的一个基本性质，即使在存在相互作用时也依然成立。

由式 (6.40)，我们可以解出理想气体的内能

U(S,V)=(3h24πem)NV2/3e2S3Nk.(6.43)U(S,V) = \left(\frac{3h^2}{4\pi em}\right)\frac{N}{V^{2/3}}e^{\frac{2S}{3Nk}}. \tag{6.43}U(S,V)=(4πem3h2​)V2/3N​e3Nk2S​.(6.43)

温度由下式给出

T=(∂U∂S)V=2U3Nk,或U=32NkT,(6.44)T = \left(\frac{\partial U}{\partial S}\right)_V = \frac{2U}{3Nk},\quad \text{或}\quad U = \frac{3}{2}NkT, \tag{6.44}T=(∂S∂U​)V​=3Nk2U​,或U=23​NkT,(6.44)

由此得到

CV=(∂U∂T)V=32Nk.(6.45)C_V = \left(\frac{\partial U}{\partial T}\right)_V = \frac{3}{2}Nk. \tag{6.45}CV​=(∂T∂U​)V​=23​Nk.(6.45)

最后，压强计算为

p=−(∂U∂V)S=2U3V=NkTV.(6.46)p = -\left(\frac{\partial U}{\partial V}\right)_S = \frac{2U}{3V} = \frac{NkT}{V}. \tag{6.46}p=−(∂V∂U​)S​=3V2U​=VNkT​.(6.46)

这就是众所周知的理想气体状态方程。

6.6 吉布斯佯谬​

令

u≡EN=32kT,且s0=3k2(1+ln⁡4πm3h2).(6.47)u \equiv \frac{E}{N} = \frac{3}{2}kT,\quad \text{且}\quad s_0 = \frac{3k}{2}\left(1 + \ln\frac{4\pi m}{3h^2}\right). \tag{6.47}u≡NE​=23​kT,且s0​=23k​(1+ln3h24πm​).(6.47)

式 (6.40) 给出的熵可以改写为

S=Nkln⁡(Vu3/2)+Nkln⁡(4πm3h2)3/2+32Nk=Nkln⁡(Vu3/2)+Ns0.(6.48)\begin{aligned}S &= Nk\ln(Vu^{3/2}) + Nk\ln\left(\frac{4\pi m}{3h^2}\right)^{3/2} + \frac{3}{2}Nk\\ &= Nk\ln(Vu^{3/2}) + Ns_0.\end{aligned} \tag{6.48}S​=Nkln(Vu3/2)+Nkln(3h24πm​)3/2+23​Nk=Nkln(Vu3/2)+Ns0​.​(6.48)

考虑一个容器中最初被隔板分开的两种理想气体。两种气体具有相同的温度与密度，但分别含有 N1N_{1}N1​ 与 N2N_{2}N2​ 个粒子、分别占据体积 V1V_{1}V1​ 与 V2V_{2}V2​。随后移除隔板，让两种气体在整个容器中混合。混合后温度保持不变。

如果这两种气体是不同类型的，原子质量分别为 m1m_{1}m1​ 与 m2m_{2}m2​，则它们的熵增分别为

ΔSi=[Nikln⁡(Vu3/2)+Nis0i]−[Nikln⁡(Viu3/2)+Nis0i]=Nikln⁡(VVi)(6.49)\Delta S_i = \left[N_ik\ln(Vu^{3/2}) + N_is_{0i}\right] - \left[N_ik\ln(V_iu^{3/2}) + N_is_{0i}\right] = N_ik\ln\left(\frac{V}{V_i}\right) \tag{6.49}ΔSi​=[Ni​kln(Vu3/2)+Ni​s0i​]−[Ni​kln(Vi​u3/2)+Ni​s0i​]=Ni​kln(Vi​V​)(6.49)

其中 s0i=(3k/2)[1+ln⁡(4πmi/3h2)]s_{0i}= (3k/2)[1 + \ln(4\pi m_{i}/3h^{2})]s0i​=(3k/2)[1+ln(4πmi​/3h2)]，i=1,2i= 1,2i=1,2。整个孤立系统的熵变由下式给出

ΔSk=N1ln⁡(VV1)+N2ln⁡(VV2).(6.50)\frac{\Delta S}{k} = N_1\ln\left(\frac{V}{V_1}\right) + N_2\ln\left(\frac{V}{V_2}\right). \tag{6.50}kΔS​=N1​ln(V1​V​)+N2​ln(V2​V​).(6.50)

这一结果在实验上是正确的。注意两种不同理想气体的混合过程是不可逆的。

当两种气体全同的时候，吉布斯佯谬就出现了。虽然套用同一公式仍然会给出由式 (6.50) 给出的熵变 ΔS\Delta SΔS，但这一结果在物理上是不可接受的。气体的热力学性质——包括粒子密度、温度与压强——在隔板存在或移除时保持不变。因此，有限的熵变将是不物理的。

吉布斯通过修改状态计数规则解决了这个佯谬，在 Ω(E)\Omega(E)Ω(E) 的表达式中引入了一个额外的因子 1/N!1/N!1/N!

Ω(E)=1h3NN!∫H<Ed3Nq d3Np.(6.51)\Omega(E) = \frac{1}{h^{3N}N!}\int_{\mathscr{H}<E}d^{3N}q\,d^{3N}p. \tag{6.51}Ω(E)=h3NN!1​∫H<E​d3Nqd3Np.(6.51)

确实，在玻尔兹曼的熵定义中引入置换因子 N!N!N! 对于保证熵的广延性是必不可少的。考虑把一个由全同原子组成的气体分成两个子系统，N1N_{1}N1​ 个粒子在体积 V1V_{1}V1​ 中， N2N_{2}N2​ 个粒子在体积 V2V_{2}V2​ 中，使得两个子系统具有相同的密度与温度。如果把原子视为可分辨的——也就是说，把每个置换都看作一个不同的微观状态——那么式 (6.21) 中的不等式必须修改如下：

N!Σ1′(Eˉ1)N1!Σ2′(Eˉ2)N2!<Σ′(E)<EΔ[N!Σ1′(Eˉ1)N1!Σ2′(Eˉ2)N2!],(6.52)N!\frac{\Sigma_1'(\bar{E}_1)}{N_1!}\frac{\Sigma_2'(\bar{E}_2)}{N_2!} < \Sigma'(E) < \frac{E}{\Delta}\left[N!\frac{\Sigma_1'(\bar{E}_1)}{N_1!}\frac{\Sigma_2'(\bar{E}_2)}{N_2!}\right], \tag{6.52}N!N1​!Σ1′​(Eˉ1​)​N2​!Σ2′​(Eˉ2​)​<Σ′(E)<ΔE​[N!N1​!Σ1′​(Eˉ1​)​N2​!Σ2′​(Eˉ2​)​],(6.52)

其中 Σ′\Sigma'Σ′ 表示可分辨原子的相体积。显然，如果把熵定义为 kln⁡Σ′k\ln\Sigma'klnΣ′，这一形式并不能给出广延的熵。

一种解决方式是假设全同粒子之间的置换不产生新的微观状态。在这种情况下，相体积由 Σ′(E)/N!≡Σ(E)\Sigma'(E)/N! \equiv \Sigma(E)Σ′(E)/N!≡Σ(E) 给出。这一推理给出了式 (6.51) 中正确的玻尔兹曼计数因子。在这一假设下，式 (6.52) 变为：

Σ1′(Eˉ1)N1!Σ2′(Eˉ2)N2!<Σ′(E)N!<EΔ[Σ1′(Eˉ1)N1!Σ2′(Eˉ2)N2!],(6.53)\frac{\Sigma_1'(\bar{E}_1)}{N_1!}\frac{\Sigma_2'(\bar{E}_2)}{N_2!} < \frac{\Sigma'(E)}{N!} < \frac{E}{\Delta}\left[\frac{\Sigma_1'(\bar{E}_1)}{N_1!}\frac{\Sigma_2'(\bar{E}_2)}{N_2!}\right], \tag{6.53}N1​!Σ1′​(Eˉ1​)​N2​!Σ2′​(Eˉ2​)​<N!Σ′(E)​<ΔE​[N1​!Σ1′​(Eˉ1​)​N2​!Σ2′​(Eˉ2​)​],(6.53) 或Σ1(Eˉ1)Σ2(Eˉ2)<Σ(E)<EΔΣ1(Eˉ1)Σ2(Eˉ2)(6.54)\text{或}\quad \Sigma_1(\bar{E}_1)\Sigma_2(\bar{E}_2) < \Sigma(E) < \frac{E}{\Delta}\Sigma_1(\bar{E}_1)\Sigma_2(\bar{E}_2) \tag{6.54}或Σ1​(Eˉ1​)Σ2​(Eˉ2​)<Σ(E)<ΔE​Σ1​(Eˉ1​)Σ2​(Eˉ2​)(6.54)

这恰是式 (6.21)。熵的广延性成立。

利用斯特林公式 ln⁡N!=Nln⁡N−N\ln N! = N\ln N-NlnN!=NlnN−N，我们得到熵的修正表达式

SST(N,V,T)=Nkln⁡(VNu3/2)+32Nk(53+ln⁡4πm3h2).(6.55)S_{ST}(N,V,T) = Nk\ln\left(\frac{V}{N}u^{3/2}\right) + \frac{3}{2}Nk\left(\frac{5}{3} + \ln\frac{4\pi m}{3h^2}\right). \tag{6.55}SST​(N,V,T)=Nkln(NV​u3/2)+23​Nk(35​+ln3h24πm​).(6.55)

这是高温下理想气体的正确熵，被称为萨库尔–特特罗德方程。

当气体被隔板分开时，它们的熵分别由 SST(N1,V1,T)S_{ST}(N_{1}, V_{1}, T)SST​(N1​,V1​,T) 与 SST(N2,V2,T)S_{ST}(N_{2}, V_{2}, T)SST​(N2​,V2​,T) 给出——这一结果不依赖于气体的种类。移除隔板后，两种不同气体的熵分别变为 SST(N1,V,T)S_{ST}(N_{1}, V, T)SST​(N1​,V,T) 与 SST(N2,V,T)S_{ST}(N_{2}, V, T)SST​(N2​,V,T)，总熵增仍由式 (6.50) 描述。

然而对于全同气体，总熵不能像不同气体那样通过简单相加各自的贡献得到。相反，我们必须把混合后的系统看作一个由 SST(N,V,T)S_{ST}(N, V, T)SST​(N,V,T) 描述的单种气体。由于粒子密度保持不变 (N/V=N1/V1=N2/V2)(N/V=N_{1}/V_{1}=N_{2}/V_{2})(N/V=N1​/V1​=N2​/V2​)，熵在混合下保持不变——这正是全同气体应有的行为。

吉布斯给出的状态计数规则（见式 (6.51)）被称为“正确的玻尔兹曼计数”。它既不能在经典统计力学中被理解，也不能在经典统计力学中被推导出来。事实上，它是全同粒子不可分辨性的结果，而这是一种纯粹的量子效应。稍后我们将说明，由量子统计导出的熵在取高温极限时，会约化为带有“正确的玻尔兹曼计数”的式 (6.55) 的形式。

统计力学与量子力学之间存在某种神秘的联系。
