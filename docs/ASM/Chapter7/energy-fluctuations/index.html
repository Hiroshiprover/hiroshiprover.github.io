7.2 正则系综中的能量涨落

尽管正则系综在原则上允许能量涨落，但对宏观热力学系统而言这些涨落可以忽略。因此，系综中的绝大多数系统都处在一个极窄的能量范围内，该范围以温度 TTT 所确定的能量为中心。于是，正则系综与微正则系综等价。

考虑如下表达式

∫d3Nq d3NpN!h3N [U−H(q,p)] eβ[A(V,T)−H(q,p)]=0,(7.15)\int\frac{d^{3N}q\,d^{3N}p}{N!h^{3N}}\,[U-\mathscr{H}(q,p)]\,e^{\beta[A(V,T)-\mathscr{H}(q,p)]} = 0, \tag{7.15}∫N!h3Nd3Nqd3Np​[U−H(q,p)]eβ[A(V,T)−H(q,p)]=0,(7.15)

由此得到能量的均方涨落

这个恒等式把能量涨落与系统的热容联系起来，它是涨落耗散定理的一个例子。对于宏观系统，⟨H⟩\langle\mathscr{H}\rangle⟨H⟩ 与 CVC_VCV​ 都与粒子数 NNN 成正比。在热力学极限 N→∞N \to \inftyN→∞ 下，相对能量涨落变得可以忽略。因此，系综中几乎所有系统副本都具有相同的能量值，即系统的内能 UUU。这一结果是意料之中的，因为我们在前面已经说明，广延量的相对涨落可以忽略。

下面，我们将给出能量涨落的另一种启发式推导，它展示了微正则系综与正则系综中熵的定义之间的联系。我们从配分函数出发

S=kln⁡ω(U)=−(∂A∂T)V.S = k\ln\omega(U) = -\left(\frac{\partial A}{\partial T}\right)_V.S=klnω(U)=−(∂T∂A​)V​.

外部量与随机量。 对于孤立系统，其总能量是严格守恒的量，不表现出热涨落（注意微正则系综定义中的小量 Δ\DeltaΔ 表示的是能量分辨率宽度，而不是热涨落）。这一能量是固定的，只能通过外部手段调节。我们把这类参量称为外部量。而考虑它的子系统时，每个子系统的能量可以在其平均值（最概然值）附近涨落，同时保持总能量守恒。我们把这类量称为随机变量。温度由所有子系统之间的平衡条件（最概然状态）确定，因而同样构成一个随机变量。相比之下，正则系综中的系统可以看成某个孤立系统的一个宏观子系统。因此，它的内能表现为随机变量，而温度由外部热库固定（其涨落可以忽略），从而充当外部参量。
