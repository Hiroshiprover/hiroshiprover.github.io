关于一级相变的注记​

如图 7.3 的 PPP-vvv 图所示，一级相变发生在区间 v1≤v≤v2v_1 \leq v \leq v_2v1​≤v≤v2​ 上。考虑一个初始处于纯低密度相、v=v2v = v_2v=v2​ 的系统。随着越来越多的分子被逐渐引入固定体积 VVV，系统的响应是把分子从低密度相转移到高密度相。于是，在整个相变区域，压强保持不变，直到系统完全处于纯高密度相。这种转移的次数正比于 VVV。每一次转移对应巨配分函数中的一项，所有这些项都具有相同的值。

小结​

我们按如下步骤描述正则系综中含 NNN 个粒子的系统的热力学。

    QN(V)=∫d3Nq d3NpN!h3N e−βH(q,p),式 (7.5)。Q_N(V) = \int\frac{d^{3N}q\,d^{3N}p}{N!h^{3N}}\,e^{-\beta\mathscr{H}(q,p)},\qquad \text{式 (7.5)。}QN​(V)=∫N!h3Nd3Nqd3Np​e−βH(q,p),式 (7.5)。
