7.6 正则系综与巨正则系综的等价性

若 ∂P/∂v<0\partial P/\partial v < 0∂P/∂v<0，巨正则系综中几乎所有系统都具有相同的粒子数 NNN，因为相对密度涨落很小。此时，巨正则系综与正则系综的等价性是显然的。

为了完整地考察正则系综与巨正则系综之间的等价性，我们必须考虑 ∂P/∂v=0\partial P/\partial v = 0∂P/∂v=0 的那些 vvv 值。我们将说明，在这种情况下式 (7.45) 给出的函数 W(N)W(N)W(N) 不再具有尖锐的极大值；尽管如此，由巨正则系综得到的状态方程仍与由正则系综得到的相符。在这个更广的意义上，两个系综总是等价的。

从物理上看，条件 ∂P/∂v=0\partial P/\partial v = 0∂P/∂v=0 对应一级相变的共存区。在这一区域，式 (7.44) 使我们可以预期，系统给定体积中的密度涨落会很大。这在物理上也是合理的，因为在这种区域中系统由两种或更多密度不同的相组成。因此，任何给定体积中的粒子数都可以取很宽范围内的值，取决于各相所占的比例。在气–液系统的临界点（连续相变），密度涨落同样预期很大，因为整个系统中分子在自发地形成大团簇并瓦解。显然，在这些条件下巨正则系综必须继续给出与正则系综一致的热力学预测。否则，二者中任何一个作为物质描述的可靠性都值得怀疑，因为一个基本的实验事实是：无论我们考察整个系统（对应正则系综）还是只考察它的一个子体积（对应巨正则系综），都能得到相同的热力学信息。

数学上，给定正则配分函数 QN(V,T)Q_N(V,T)QN​(V,T)，我们的目标是计算巨配分函数：

Q(z,V,T)=∑N=0∞zNQN(V,T)\mathcal{Q}(z,V,T) = \sum_{N=0}^{\infty} z^N Q_N(V,T)Q(z,V,T)=N=0∑∞​zNQN​(V,T)

在给定的 zzz、VVV 与 TTT 值下，并回答如下问题：

(a) 对于固定的 zzz，近似式 Q(z,V,T)≈zNQN(V,T)\mathcal{Q}(z,V,T) \approx z^N Q_N(V,T)Q(z,V,T)≈zNQN​(V,T) 是否对某个 NNN 成立？

(b) 是否总存在某个 zzz 值，使得 NNN 可以取任意给定的正值？

显然，对任意函数 QN(V,T)Q_N(V,T)QN​(V,T)，这些问题的答案通常是“否”。不过我们关心的并不是一般的函数 QN(V,T)Q_N(V,T)QN​(V,T)，而是那些对应真实物理系统的配分函数。

为了既能体现物理系统的主要特征、又保持数学上的简单，我们假设系统具有如下性质：

  • 分子被建模为有限直径的硬球，它们之间还通过有限程势相互作用。

  • 亥姆霍兹自由能具有如下形式

    A(N,V)=−1βln⁡QN(V)=−Vβf(v),f(v)=−βva(v).(7.66)A(N,V) = -\frac{1}{\beta}\ln Q_N(V) = -\frac{V}{\beta}f(v),\quad f(v) = -\frac{\beta}{v}a(v). \tag{7.66}A(N,V)=−β1​lnQN​(V)=−βV​f(v),f(v)=−vβ​a(v).(7.66)

    温度 TTT 将在我们的讨论中固定，不再显式写出。函数 f(v)f(v)f(v) 是强度量。根据式 (7.42)，P=−∂va(v)P = -\partial_v a(v)P=−∂v​a(v)；因此 f(v)f(v)f(v) 可以写成正则系综压强 P(v)P(v)P(v) 的积分：

    f(v)=−βva(v)=1v∫v0vβP(v′)dv′.(7.67)f(v) = -\frac{\beta}{v}a(v) = \frac{1}{v}\int_{v_0}^{v}\beta P(v')dv'. \tag{7.67}f(v)=−vβ​a(v)=v1​∫v0​v​βP(v′)dv′.(7.67)

    这里积分沿一条等温线进行，v0v_0v0​ 是任意常数，对应亥姆霍兹自由能中任意的可加常数。

  • 合理的假设是（换句话说，我们只考虑这种物理情形）

    ∂P∂v≤0,(7.68)\frac{\partial P}{\partial v} \leq 0, \tag{7.68}∂v∂P​≤0,(7.68)

    ∂2f(v)∂(1/v)2=βv3∂P∂v≤0.(7.69)\frac{\partial^2 f(v)}{\partial(1/v)^2} = \beta v^3\frac{\partial P}{\partial v} \leq 0. \tag{7.69}∂(1/v)2∂2f(v)​=βv3∂v∂P​≤0.(7.69)
