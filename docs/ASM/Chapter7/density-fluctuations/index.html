7.4 巨正则系综中的密度涨落

本节我们计算巨正则系综中的密度涨落，其表达式为

⟨N2⟩−⟨N⟩2=k2T2Q(z,V,T)∂2∂μ2Q(z,V,T)−[kTQ(z,V,T)∂∂μQ(z,V,T)]2=k2T2∂2∂μ2ln⁡Q(z,V,T)=1β2∂2∂μ2(PVkT)=kTV∂2P∂μ2,(7.39)\begin{aligned} \langle N^2\rangle - \langle N\rangle^2 &= \frac{k^2T^2}{\mathcal{Q}(z,V,T)}\frac{\partial^2}{\partial\mu^2}\mathcal{Q}(z,V,T) - \left[\frac{kT}{\mathcal{Q}(z,V,T)}\frac{\partial}{\partial\mu}\mathcal{Q}(z,V,T)\right]^2\\ &= k^2T^2\frac{\partial^2}{\partial\mu^2}\ln\mathcal{Q}(z,V,T) = \frac{1}{\beta^2}\frac{\partial^2}{\partial\mu^2}\left(\frac{PV}{kT}\right) = kTV\frac{\partial^2 P}{\partial\mu^2}, \end{aligned} \tag{7.39}⟨N2⟩−⟨N⟩2​=Q(z,V,T)k2T2​∂μ2∂2​Q(z,V,T)−[Q(z,V,T)kT​∂μ∂​Q(z,V,T)]2=k2T2∂μ2∂2​lnQ(z,V,T)=β21​∂μ2∂2​(kTPV​)=kTV∂μ2∂2P​,​(7.39)

其中我们用了下面的恒等式

∂2∂x2ln⁡Q=∂∂x(1Q∂Q∂x)=1Q∂2Q∂x2−(1Q∂Q∂x)2.\frac{\partial^2}{\partial x^2}\ln\mathcal{Q} = \frac{\partial}{\partial x}\left(\frac{1}{\mathcal{Q}}\frac{\partial\mathcal{Q}}{\partial x}\right) = \frac{1}{\mathcal{Q}}\frac{\partial^2\mathcal{Q}}{\partial x^2} - \left(\frac{1}{\mathcal{Q}}\frac{\partial\mathcal{Q}}{\partial x}\right)^2.∂x2∂2​lnQ=∂x∂​(Q1​∂x∂Q​)=Q1​∂x2∂2Q​−(Q1​∂x∂Q​)2.

接下来，我们要把密度涨落（更确切地说，是右端出现的二阶导数 ∂2P/∂μ2\partial^2 P/\partial\mu^2∂2P/∂μ2）化成更熟悉、物理意义更透明的形式。作为广延量，亥姆霍兹自由能 A(N,V,T)A(N, V, T)A(N,V,T) 满足标度关系：

A(λN,λV,T)=λA(N,V,T).A(\lambda N,\lambda V,T) = \lambda A(N,V,T).A(λN,λV,T)=λA(N,V,T).

因此，我们可以把它写成：

A(N,V)=Na(v),(7.40)A(N,V) = Na(v), \tag{7.40}A(N,V)=Na(v),(7.40)

其中 v=V/Nv = V/Nv=V/N 为每粒子体积，a(v)a(v)a(v) 为每粒子的亥姆霍兹自由能。为简单起见，我们在记号中省略温度 TTT（一个固定的外部参量）。化学势 μ\muμ 与压强 PPP（两者都是强度量）于是由下式给出：

μ={∂[Na(v)]∂N}V=a(v)+N∂a∂v∂v∂N=a(v)−v∂a(v)∂v(7.41)\mu = \left\{\frac{\partial[Na(v)]}{\partial N}\right\}_V = a(v) + N\frac{\partial a}{\partial v}\frac{\partial v}{\partial N} = a(v) - v\frac{\partial a(v)}{\partial v} \tag{7.41}μ={∂N∂[Na(v)]​}V​=a(v)+N∂v∂a​∂N∂v​=a(v)−v∂v∂a(v)​(7.41) P=−{∂[Na(v)]∂V}N=−N∂a(v)∂v∂v∂V=−∂a(v)∂v.(7.42)P = -\left\{\frac{\partial[Na(v)]}{\partial V}\right\}_N = -N\frac{\partial a(v)}{\partial v}\frac{\partial v}{\partial V} = -\frac{\partial a(v)}{\partial v}. \tag{7.42}P=−{∂V∂[Na(v)]​}N​=−N∂v∂a(v)​∂V∂v​=−∂v∂a(v)​.(7.42)

于是，二阶导数 ∂2P/∂μ2\partial^2 P/\partial\mu^2∂2P/∂μ2 可以计算如下：

(∂P∂μ)V=−∂2a∂v2(∂v∂μ)V=−∂2a∂v2(∂μ∂v)V−1=−∂2a∂v2(−v∂2a∂v2)−1=1v,(∂2P∂μ2)V=−1v2(∂v∂μ)V=1v2(v∂2a∂v2)−1=1v3(∂2a∂v2)−1=−1v3∂P/∂v.\begin{aligned} \left(\frac{\partial P}{\partial\mu}\right)_V &= -\frac{\partial^2 a}{\partial v^2}\left(\frac{\partial v}{\partial\mu}\right)_V = -\frac{\partial^2 a}{\partial v^2}\left(\frac{\partial\mu}{\partial v}\right)_V^{-1} = -\frac{\partial^2 a}{\partial v^2}\left(-v\frac{\partial^2 a}{\partial v^2}\right)^{-1} = \frac{1}{v},\\ \left(\frac{\partial^2 P}{\partial\mu^2}\right)_V &= -\frac{1}{v^2}\left(\frac{\partial v}{\partial\mu}\right)_V = \frac{1}{v^2}\left(v\frac{\partial^2 a}{\partial v^2}\right)^{-1} = \frac{1}{v^3}\left(\frac{\partial^2 a}{\partial v^2}\right)^{-1} = -\frac{1}{v^3\partial P/\partial v}. \end{aligned}(∂μ∂P​)V​(∂μ2∂2P​)V​​=−∂v2∂2a​(∂μ∂v​)V​=−∂v2∂2a​(∂v∂μ​)V−1​=−∂v2∂2a​(−v∂v2∂2a​)−1=v1​,=−v21​(∂μ∂v​)V​=v21​(v∂v2∂2a​)−1=v31​(∂v2∂2a​)−1=−v3∂P/∂v1​.​

我们再次强调，上述推导中温度 TTT 保持不变。回顾等温压缩系数 κT\kappa_TκT​ 的定义

κT≡−1v(∂v∂P)T=−1v(∂P/∂v).(7.43)\kappa_T \equiv -\frac{1}{v}\left(\frac{\partial v}{\partial P}\right)_T = -\frac{1}{v(\partial P/\partial v)}. \tag{7.43}κT​≡−v1​(∂P∂v​)T​=−v(∂P/∂v)1​.(7.43)

利用这一结果，我们最终可以把粒子密度的涨落写成

⟨N2⟩−⟨N⟩2=kTV∂2P∂μ2=kTV1v2κT=⟨N⟩kTκT/v.(7.44)\langle N^2\rangle - \langle N\rangle^2 = kTV\frac{\partial^2 P}{\partial\mu^2} = kTV\frac{1}{v^2}\kappa_T = \langle N\rangle kT\kappa_T/v. \tag{7.44}⟨N2⟩−⟨N⟩2=kTV∂μ2∂2P​=kTVv21​κT​=⟨N⟩kTκT​/v.(7.44)

对大多数物理系统，等温压缩系数 κT\kappa_TκT​ 是正的且有限。在这种情况下，粒子密度的相对涨落可以忽略。当 κT\kappa_TκT​ 发散时，情况不再如此。这种发散可以发生在一级相变处，此时 (∂P/∂v)T=0(\partial P/\partial v)_T = 0(∂P/∂v)T​=0；也可以发生在连续相变的临界点。

式 (7.44) 与式 (7.18) 类似，是涨落耗散定理的另一个例子。该定理指出，物理量的涨落一般与相应的广义感受率相联系。在式 (7.18) 中，能量涨落与定容热容 CVC_VCV​ 相联系；在式 (7.44) 中，密度涨落与等温压缩系数 κT\kappa_TκT​ 相联系。

在巨正则系综中，系统含有 NNN 个粒子的概率正比于：

W(N)=zNQN(V,T)=eβ[μN−A(N,V,T)],(7.45)W(N) = z^N Q_N(V,T) = e^{\beta[\mu N - A(N,V,T)]}, \tag{7.45}W(N)=zNQN​(V,T)=eβ[μN−A(N,V,T)],(7.45)

其中 A(N,V,T)A(N,V,T)A(N,V,T) 是含 NNN 个粒子的正则系综的亥姆霍兹自由能。当密度涨落可以忽略时（远离相变），W(N)W(N)W(N) 在 N=⟨N⟩N = \langle N\rangleN=⟨N⟩ 处尖锐成峰，宽度约为 ⟨N⟩\sqrt{\langle N\rangle}⟨N⟩​。因此最概然粒子数就是平均粒子数，Nˉ=⟨N⟩\bar{N} = \langle N\rangleNˉ=⟨N⟩。此外，

Q(z,V,T)=∑NW(N)≈W(Nˉ).\mathcal{Q}(z,V,T) = \sum_N W(N) \approx W(\bar{N}).Q(z,V,T)=N∑​W(N)≈W(Nˉ).

由式 (7.45)，亥姆霍兹自由能由其最概然粒子数 N=NˉN = \bar{N}N=Nˉ 处的值确定：

A(Nˉ,V,T)≈μNˉ−kTln⁡W(Nˉ)=kT[Nˉln⁡z−ln⁡Q(z,V,T)].(7.46)A(\bar{N},V,T) \approx \mu\bar{N} - kT\ln W(\bar{N}) = kT\left[\bar{N}\ln z - \ln\mathcal{Q}(z,V,T)\right]. \tag{7.46}A(Nˉ,V,T)≈μNˉ−kTlnW(Nˉ)=kT[Nˉlnz−lnQ(z,V,T)].(7.46)

这一结果与欧拉关系 A=U−TS=−PV+μNA = U - TS = -PV + \mu NA=U−TS=−PV+μN 一致。

注： 在相变过程中，等温压缩系数 κT\kappa_TκT​ 发散，密度涨落变得显著（如临界乳光现象所示）。尽管如此，式 (7.46) 仍然成立，这一点将在本章后面说明。
