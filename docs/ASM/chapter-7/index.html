7.1 正则系综​

在实际中，大多数系统并不是孤立的，而是与一个远比它大的热库保持热平衡。热库足够大，以至于尽管系统发生变化，热库的热力学状态仍保持不变。本章我们将探讨适用于这一情形的系综。

图 7.1：与热库处于热平衡的系统。二者构成一个孤立系统。

如图中所示，系统含有 N1N_1N1​ 个粒子，哈密顿量为 H1(q1,p1)\mathscr{H}_1(q_1,p_1)H1​(q1​,p1​)；热库含有 N2N_2N2​ 个粒子，哈密顿量为 H2(q2,p2)\mathscr{H}_2(q_2,p_2)H2​(q2​,p2​)。二者共同构成一个孤立的复合系统，总粒子数为 N=N1+N2N = N_1 + N_2N=N1​+N2​，总能量 E1+E2E_1 + E_2E1​+E2​ 处于如下范围：

E<E1+E2<E+2Δ.(7.1)E < E_1 + E_2 < E + 2\Delta. \tag{7.1}E<E1​+E2​<E+2Δ.(7.1)

设 Σ1(E1)\Sigma_1(E_1)Σ1​(E1​) 与 Σ2(E2)\Sigma_2(E_2)Σ2​(E2​) 分别表示系统与热库所占据的相空间体积。整个孤立系统的总相空间体积 Σ(E)\Sigma(E)Σ(E) 由下式给出：

Σ(E)=∑E1=0EΣ1(E1)Σ2(E−E1),\Sigma(E) = \sum_{E_1=0}^{E}\Sigma_1(E_1)\Sigma_2(E-E_1),Σ(E)=E1​=0∑E​Σ1​(E1​)Σ2​(E−E1​),

其中求和按宽度为 Δ\DeltaΔ 的能量间隔进行。该求和的主要贡献来自最概然能量 Eˉ1\bar{E}_1Eˉ1​ 与 Eˉ2=E−Eˉ1\bar{E}_2 = E - \bar{E}_1Eˉ2​=E−Eˉ1​，从而给出：

Σ(E)≈Σ1(Eˉ1)Σ2(Eˉ2),\Sigma(E) \approx \Sigma_1(\bar{E}_1)\Sigma_2(\bar{E}_2),Σ(E)≈Σ1​(Eˉ1​)Σ2​(Eˉ2​),

或者等价地，

S(E,V)=S1(Eˉ1,V1)+S2(Eˉ2,V2),S(E,V) = S_1(\bar{E}_1,V_1) + S_2(\bar{E}_2,V_2),S(E,V)=S1​(Eˉ1​,V1​)+S2​(Eˉ2​,V2​),

其中 S=kln⁡ΣS = k\ln\SigmaS=klnΣ 为熵。Eˉ1\bar{E}_1Eˉ1​ 与 Eˉ2\bar{E}_2Eˉ2​ 由热平衡条件确定：

∂S1(E1,V1)∂E1∣E1=Eˉ1=∂S2(E2,V2)∂E2∣E2=Eˉ2=1T.\left.\frac{\partial S_1(E_1,V_1)}{\partial E_1}\right|_{E_1=\bar{E}_1} = \left.\frac{\partial S_2(E_2,V_2)}{\partial E_2}\right|_{E_2=\bar{E}_2} = \frac{1}{T}.∂E1​∂S1​(E1​,V1​)​​E1​=Eˉ1​​=∂E2​∂S2​(E2​,V2​)​​E2​=Eˉ2​​=T1​.

由于假设 E1≪E2∼EE_1 \ll E_2 \sim EE1​≪E2​∼E，量级为 E1E_1E1​ 的能量涨落不会改变热库的温度。于是我们作展开：

kln⁡Σ2(E−E1)=S2(E−E1,V2)≈S2(E,V2)−E1∂S2(E2,V2)∂E2∣E2=E≈S2(E,V2)−E1T,⇒  Σ2(E−E1)≈exp⁡[1kS2(E,V2)]exp⁡(−E1kT).(7.2)\begin{aligned} k\ln\Sigma_2(E-E_1) &= S_2(E-E_1,V_2)\\ &\approx S_2(E,V_2) - E_1\left.\frac{\partial S_2(E_2,V_2)}{\partial E_2}\right|_{E_2=E}\\ &\approx S_2(E,V_2) - \frac{E_1}{T},\\ \Rightarrow\ \ \Sigma_2(E-E_1) &\approx \exp\left[\frac{1}{k}S_2(E,V_2)\right]\exp\left(-\frac{E_1}{kT}\right). \end{aligned} \tag{7.2}klnΣ2​(E−E1​)⇒  Σ2​(E−E1​)​=S2​(E−E1​,V2​)≈S2​(E,V2​)−E1​∂E2​∂S2​(E2​,V2​)​​E2​=E​≈S2​(E,V2​)−TE1​​,≈exp[k1​S2​(E,V2​)]exp(−kTE1​​).​(7.2)

当系统足够小时，第一个指数因子相对于 E1E_1E1​ 是常数。

正则系综。 对于系统的一个微观状态，其坐标为 (q1,p1)(q_1,p_1)(q1​,p1​)、能量为 E1=H1(q1,p1)E_1 = \mathscr{H}_1(q_1,p_1)E1​=H1​(q1​,p1​)，该状态的概率正比于热库在能量 E−E1E - E_1E−E1​ 处可及的相空间体积

ρ(q1,p1)∝Σ2[E−H(q1,p1)].(7.3)\rho(q_1,p_1) \propto \Sigma_2[E-\mathscr{H}(q_1,p_1)]. \tag{7.3}ρ(q1​,p1​)∝Σ2​[E−H(q1​,p1​)].(7.3)

由式 (7.2)，我们可以把系统的系综密度定义为

ρ(q,p)=exp⁡[−H(q,p)/(kT)],(7.4)\rho(q,p) = \exp\left[-\mathscr{H}(q,p)/(kT)\right], \tag{7.4}ρ(q,p)=exp[−H(q,p)/(kT)],(7.4)

这里我们省略了标记系统的下标“1”。式 (7.4) 定义了一个新的系综——正则系综，它描述与固定温度的热库处于热平衡的系统。

配分函数。 对于体积 VVV 中含有 NNN 个全同粒子的气体，配分函数定义为 ρ(q,p)\rho(q,p)ρ(q,p) 在系统整个相空间上的积分：

QN(V,T)=∫d3Nq d3NpN!h3N e−βH(q,p)(7.5)Q_N(V,T) = \int\frac{d^{3N}q\,d^{3N}p}{N!h^{3N}}\,e^{-\beta\mathscr{H}(q,p)} \tag{7.5}QN​(V,T)=∫N!h3Nd3Nqd3Np​e−βH(q,p)(7.5)

其中 β=1/(kT)\beta = 1/(kT)β=1/(kT)。

评注： 你可能会注意到，在式 (7.5) 中，系统的能量在理论上可以超过复合系统（系统 + 热库）的总能量。尽管这看起来与最初的假设矛盾，但它是合理的，因为积分的主要贡献来自那些能量 H(q,p)\mathscr{H}(q,p)H(q,p) 处于物理允许范围内的宏观状态。此外，在热力学极限下能量涨落会变得可以忽略。我们将在下一节证明这一点。接下来，我们转向系统的热力学。

由配分函数可以求得亥姆霍兹自由能

A(V,T)=−kTln⁡QN(V,T)或QN(V,T)=e−βA(V,T).(7.6)A(V,T) = -kT\ln Q_N(V,T) \quad\text{或}\quad Q_N(V,T) = e^{-\beta A(V,T)}. \tag{7.6}A(V,T)=−kTlnQN​(V,T)或QN​(V,T)=e−βA(V,T).(7.6)

我们将证明

  1. AAA 是广延量。
  2. A=U−TSA = U - TSA=U−TS。

考虑把系统划分为体积为 V1V_1V1​ 与 V2V_2V2​ 的两个子系统。对单个粒子，相空间积分分解为

∫Vd3q d3p=∫V1d3q d3p+∫V2d3q d3p,\int_V d^3q\,d^3p = \int_{V_1} d^3q\,d^3p + \int_{V_2} d^3q\,d^3p,∫V​d3qd3p=∫V1​​d3qd3p+∫V2​​d3qd3p,

这取决于粒子的位置位于哪个体积之中。对于 NNN 个可分辨粒子，上式推广为

∫Vd3Nq d3Np=∑N1=0NN!N1!N2!∫V1d3N1q1 d3N1p1∫V2d3N2q2 d3N2p2,(7.7)\int_V d^{3N}q\,d^{3N}p = \sum_{N_1=0}^{N}\frac{N!}{N_1!N_2!}\int_{V_1} d^{3N_1}q_1\,d^{3N_1}p_1\int_{V_2} d^{3N_2}q_2\,d^{3N_2}p_2, \tag{7.7}∫V​d3Nqd3Np=N1​=0∑N​N1​!N2​!N!​∫V1​​d3N1​q1​d3N1​p1​∫V2​​d3N2​q2​d3N2​p2​,(7.7)

其中 N2=N−N1N_2 = N - N_1N2​=N−N1​。组合因子 N!N1!N2!\frac{N!}{N_1!N_2!}N1​!N2​!N!​ 计入了把 N1N_1N1​ 个粒子分配到 V1V_1V1​、其余 N2N_2N2​ 个粒子分配到 V2V_2V2​ 的方式数。因此，NNN 个全同粒子的配分函数可以写成对所有可能粒子分配方式的求和：

QN(V,T)=∑N1=0NQN1(V1,T) QN−N1(V2,T)=∑N1=0Nexp⁡{−β[A(N1,V1,T)+A(N2,V2,T)]},(7.8)\begin{aligned} Q_N(V,T) &= \sum_{N_1=0}^{N} Q_{N_1}(V_1,T)\,Q_{N-N_1}(V_2,T)\\ &= \sum_{N_1=0}^{N} \exp\left\{-\beta\left[A(N_1,V_1,T) + A(N_2,V_2,T)\right]\right\}, \end{aligned} \tag{7.8}QN​(V,T)​=N1​=0∑N​QN1​​(V1​,T)QN−N1​​(V2​,T)=N1​=0∑N​exp{−β[A(N1​,V1​,T)+A(N2​,V2​,T)]},​(7.8)

其中 N2=N−N1N_2 = N - N_1N2​=N−N1​。在热力学极限下，V1V_1V1​ 与 V2V_2V2​ 边界处粒子间的相互作用相比体相贡献可以忽略。

与熵广延性的论证类似，式 (7.8) 的右端由对应最概然粒子数 Nˉ1\bar{N}_1Nˉ1​ 与 Nˉ2=N−Nˉ1\bar{N}_2 = N - \bar{N}_1Nˉ2​=N−Nˉ1​ 的那一项主导。这些值通过最小化函数 ln⁡[QN1(V1,T)QN2(V2,T)]\ln\left[Q_{N_1}(V_1,T)Q_{N_2}(V_2,T)\right]ln[QN1​​(V1​,T)QN2​​(V2​,T)] 来确定，最小化对 N1N_1N1​ 与 N2N_2N2​ 进行，并满足约束 N1+N2=NN_1 + N_2 = NN1​+N2​=N：

δln⁡[QN1(V1,T)QN2(V2,T)]=0,δ(N1+N2)=0.(7.9)\delta\ln\left[Q_{N_1}(V_1,T)Q_{N_2}(V_2,T)\right] = 0,\quad \delta(N_1 + N_2) = 0. \tag{7.9}δln[QN1​​(V1​,T)QN2​​(V2​,T)]=0,δ(N1​+N2​)=0.(7.9)

由此得到粒子数平衡条件：

∂ln⁡QN1(V1,T)∂N1∣N1=Nˉ1=∂ln⁡QN2(V2,T)∂N2∣N2=Nˉ2.(7.10)\left.\frac{\partial\ln Q_{N_1}(V_1,T)}{\partial N_1}\right|_{N_1=\bar{N}_1} = \left.\frac{\partial\ln Q_{N_2}(V_2,T)}{\partial N_2}\right|_{N_2=\bar{N}_2}. \tag{7.10}∂N1​∂lnQN1​​(V1​,T)​​N1​=Nˉ1​​=∂N2​∂lnQN2​​(V2​,T)​​N2​=Nˉ2​​.(7.10)

对于宏观系统，N1N_1N1​ 与 N2N_2N2​ 的相对涨落可以忽略。因此，亥姆霍兹自由能是广延量：

ln⁡QN(V,T)=ln⁡QNˉ1(V1,T)+ln⁡QNˉ2(V2,T),A(N,V,T)=A(Nˉ1,V1,T)+A(Nˉ2,V2,T).(7.11)\begin{aligned} \ln Q_N(V,T) &= \ln Q_{\bar{N}_1}(V_1,T) + \ln Q_{\bar{N}_2}(V_2,T),\\ A(N,V,T) &= A(\bar{N}_1,V_1,T) + A(\bar{N}_2,V_2,T). \end{aligned} \tag{7.11}lnQN​(V,T)A(N,V,T)​=lnQNˉ1​​(V1​,T)+lnQNˉ2​​(V2​,T),=A(Nˉ1​,V1​,T)+A(Nˉ2​,V2​,T).​(7.11)

内能 UUU 由哈密顿量的系综平均给出：

U=⟨H⟩=1QN(V,T)∫d3Nq d3NpN!h3N H(q,p)e−βH(q,p)=−∂∂βln⁡QN(V,T)=∂∂β[βA(V,T)]=A(V,T)+β∂A(V,T)∂β=A(V,T)−T∂A(V,T)∂T.(7.12)\begin{aligned} U = \langle\mathscr{H}\rangle &= \frac{1}{Q_N(V,T)}\int\frac{d^{3N}q\,d^{3N}p}{N!h^{3N}}\,\mathscr{H}(q,p)e^{-\beta\mathscr{H}(q,p)}\\ &= -\frac{\partial}{\partial\beta}\ln Q_N(V,T) = \frac{\partial}{\partial\beta}[\beta A(V,T)]\\ &= A(V,T) + \beta\frac{\partial A(V,T)}{\partial\beta}\\ &= A(V,T) - T\frac{\partial A(V,T)}{\partial T}. \end{aligned} \tag{7.12}U=⟨H⟩​=QN​(V,T)1​∫N!h3Nd3Nqd3Np​H(q,p)e−βH(q,p)=−∂β∂​lnQN​(V,T)=∂β∂​[βA(V,T)]=A(V,T)+β∂β∂A(V,T)​=A(V,T)−T∂T∂A(V,T)​.​(7.12)

正则系综中的热力学熵定义为：

S=−(∂A∂T)V.(7.13)S = -\left(\frac{\partial A}{\partial T}\right)_V. \tag{7.13}S=−(∂T∂A​)V​.(7.13)

由此立即得到 A=U−TSA = U - TSA=U−TS，而压强由下式给出：

P=−(∂U∂V)S=−(∂A∂V)T.P = -\left(\frac{\partial U}{\partial V}\right)_S = -\left(\frac{\partial A}{\partial V}\right)_T.P=−(∂V∂U​)S​=−(∂V∂A​)T​.

这些关系都是热力学中的标准结果。

香农熵​

式 (7.13) 中正则系综的熵定义与微正则系综中玻尔兹曼的熵定义之间的等价性将在下一节证明。这里我们先展示这些定义如何与香农熵相联系。香农熵用微观状态 (q,p)(q,p)(q,p) 的归一化概率 ρ~(q,p)=e−βH/QN(V,T)\tilde{\rho}(q,p) = e^{-\beta\mathscr{H}}/Q_N(V,T)ρ~​(q,p)=e−βH/QN​(V,T) 定义为：

SShannon=−k∫d3Nq d3NpN!h3N ρ~(q,p)ln⁡ρ~(q,p)=kβU+kln⁡QN=U−AT=S,\begin{aligned} S_{\text{Shannon}} &= -k\int\frac{d^{3N}q\,d^{3N}p}{N!h^{3N}}\,\tilde{\rho}(q,p)\ln\tilde{\rho}(q,p)\\ &= k\beta U + k\ln Q_N = \frac{U-A}{T} = S, \end{aligned}SShannon​​=−k∫N!h3Nd3Nqd3Np​ρ~​(q,p)lnρ~​(q,p)=kβU+klnQN​=TU−A​=S,​

它与式 (7.12) 和式 (7.13) 中定义的熵完全一致。

类似地，微正则系综中的总相体积 Σ(E)\Sigma(E)Σ(E) 可以通过把密度函数在能量壳层上积分得到，因此也可以看成该系综的一种“配分函数”。在能量范围 E<H(q,p)<E+ΔE < \mathscr{H}(q,p) < E + \DeltaE<H(q,p)<E+Δ 内，每个微观状态的归一化概率是常数：ρ~=1/Σ(E)\tilde{\rho} = 1/\Sigma(E)ρ~​=1/Σ(E)。相应的香农熵为

SShannon=−k∫E<H(q,p)<E+Δd3Nq d3NpN!h3N⋅1Σ⋅ln⁡(1Σ)=kln⁡Σ(E),(7.14)S_{\text{Shannon}} = -k\int_{E<\mathscr{H}(q,p)<E+\Delta}\frac{d^{3N}q\,d^{3N}p}{N!h^{3N}}\cdot\frac{1}{\Sigma}\cdot\ln\left(\frac{1}{\Sigma}\right) = k\ln\Sigma(E), \tag{7.14}SShannon​=−k∫E<H(q,p)<E+Δ​N!h3Nd3Nqd3Np​⋅Σ1​⋅ln(Σ1​)=klnΣ(E),(7.14)

它同样等于玻尔兹曼熵。

由此我们说明了，不同系综中不同的熵定义——包括后面将要引入的巨正则系综——都可以纳入香农给出的普遍公式。当然，香农熵本身就是受物理学中熵的概念启发而提出的。
